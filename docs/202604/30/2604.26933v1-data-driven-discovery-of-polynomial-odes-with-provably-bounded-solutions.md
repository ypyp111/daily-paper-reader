## 摘要
我们介绍了 SILAS，这是一个用于发现具有可证明有界轨迹的多项式常微分方程（ODE）的数据驱动框架。有界性通过由多项式 Lyapunov 函数定义的紧致吸收集来证明。我们利用多项式优化工具构建了一个适定的非凸优化问题，从而联合识别 ODE 向量场和 Lyapunov 函数。我们使用带有凸子问题的交替块坐标优化方案来解决该问题，其可行性由一种新颖的模型无关初始化方法保证，该方法能从数据中识别出候选 Lyapunov 函数。我们的方法将先前针对具有吸收椭球体的二次 ODE 的方法扩展到了更广泛的 ODE 类别和吸收集。包含 100 多个示例的测试集表明，SILAS 能够为广泛的非线性动力系统恢复准确且可证明有界的 ODE 模型。

## Abstract
We introduce SILAS, a data-driven framework for discovering polynomial ordinary differential equations (ODEs) with provably bounded trajectories. Boundedness is certified by compact absorbing sets defined via polynomial Lyapunov functions. We jointly identify the ODE vector field and the Lyapunov function using a well-posed nonconvex optimization problem built using polynomial optimization tools. We solve this problem using an alternating block-coordinate optimization scheme with convex subproblems, whose feasibility is ensured by a novel model-agnostic initialization that identifies a candidate Lyapunov function from data. Our methods extend prior approaches for quadratic ODEs with absorbing ellipsoids to a significantly broader class of ODEs and absorbing sets. A suite of over 100 examples demonstrates that SILAS can recover accurate and provably bounded ODE models for a broad range of nonlinear dynamical systems.

论文的研究动机是利用**李雅普诺夫（Lyapunov）函数**来定义**紧致吸收集（Compact Absorbing Sets）**，从而确保识别出的 ODE 系统在任何初始条件下，其轨迹最终都会进入并停留在一个有界区域内。这为模型的鲁棒性和长期预测提供了理论保障。

### 2. 方法论
SILAS 框架的核心思想是联合识别 ODE 的向量场 $f(x)$ 和证明其有界性的多项式 Lyapunov 函数 $v(x)$。

*   **核心理论**：利用 Lyapunov 判据证明有界性。如果存在强制性函数 $v(x)$ 满足 $b - v(x) - \alpha \langle f(x), \nabla v(x) \rangle \geq 0$，则集合 $\{x : v(x) \leq b\}$ 是一个吸收集。
*   **关键技术细节**：
    *   **多项式参数化**：将向量场 $f$ 和 Lyapunov 函数 $v$ 均表示为多项式基函数的线性组合。
    *   **平方和（SOS）约束**：将非负性约束转化为 SOS 约束，从而利用半正定规划（SDP）工具求解。
    *   **非凸优化求解**：由于 $f$ 和 $v$ 在约束中是双线性耦合的，问题是非凸的。论文采用了**交替块坐标优化方案**：固定 $v$ 优化 $f$，再固定 $f$ 优化 $v$。
    *   **模型无关初始化**：这是本文的关键创新。作者通过近似 Koopman 算子的生成元，直接从数据中预先识别出一个候选 Lyapunov 函数，从而确保后续交替优化步骤的可行性，避免了传统方法从无约束 ODE 开始可能导致的不可行问题。

### 6 主要结论与发现
*   **有界性保障**：SILAS 能够成功识别出具有可证明有界性的模型，即使对于那些在某些初始条件下会发散的原始系统（如 SprottA），SILAS 也能找到其吸引子的有界近似。
*   **准确性**：在 82 个多项式混沌系统中，71 个系统的平均误差低于 1%。对于非多项式系统，如果非线性较平滑，SILAS 也能通过高阶多项式实现良好近似。
*   **降阶建模能力**：在 PDE 降阶建模中，SILAS 生成的模型能够长期捕捉复杂的间歇性动力学，且保证解不会发散。

### 7. 优点
*   **理论严谨**：提供了关于优化问题适定性和解有界性的严格数学证明。
*   **初始化创新**：通过数据驱动的 Lyapunov 初始化解决了双线性优化容易陷入不可行域的痛点。
*   **通用性强**：不局限于二次型 Lyapunov 函数或二次型 ODE，支持任意阶数的多项式。

### 8. 不足与局限
*   **维度灾难**：由于依赖 SOS 优化，随着状态空间维度 $n$ 和多项式阶数的增加，SDP 的规模呈指数级增长，目前难以直接处理超高维系统。
*   **局部最优风险**：交替优化方案虽然保证了可行性，但不能保证收敛到全局最优解。
*   **数据依赖**：需要状态的变化率（$\dot{x}$）数据，虽然可以通过有限差分估计，但在高噪声环境下可能受限（尽管作者提到了未来可扩展至 Flow-map 形式以缓解此问题）。
