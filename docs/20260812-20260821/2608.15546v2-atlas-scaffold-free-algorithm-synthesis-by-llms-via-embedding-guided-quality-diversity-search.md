## 摘要
大多数基于大语言模型的自动化算法设计方法在人指定的脚手架内优化特定组件，固定整体组织和组件交互。我们提出ATLAS，一种嵌入引导的质量-多样性框架，用于组合优化中的无需脚手架的全算法合成。问题规范提供目标和约束；最小I/O接口仅固定实例和解决方案格式；大语言模型选择并重组组件、交互和控制流。这种自由扩大了搜索空间，存在无效候选和过早收敛到单一设计区域的风险。ATLAS独立检测执行、接口和可行性失败，重新计算目标，并应用基于错误条件的修复；基于相似性的存档管理跨嵌入空间区域保留算法，以对抗过早收敛。其三层搜索细化最佳设计，为其他区域提供专门的细化机会，并进行跨区域合成以重组组件及其交互。在四个NP难问题上，ATLAS优于几种最先进的组件合成方法和匹配的全合成基线，同时与强人工设计算法保持竞争力。一次ATLAS运行会从不同嵌入空间区域保留多个性能相当的算法，而非单一设计。代码检查发现，这些多组件设计在其主要构造或全局搜索主干上有所不同。我们的结果表明，嵌入引导的质量-多样性搜索可以使扩大的全算法设计空间实际可搜索。源代码和精确可执行提示可在https://github.com/Danial-Yazdani/ATLAS获取。

## Abstract
Most LLM-based automated algorithm design methods optimize a designated component within a human-specified scaffold, fixing overall organization and component interactions. We present ATLAS, an embedding-guided quality-diversity framework for scaffold-free full-algorithm synthesis in combinatorial optimization. The problem specification supplies objectives and constraints; a minimal I/O interface fixes only instance and solution formats; the LLM chooses and restructures components, interactions, and control flow. This freedom enlarges the search space, risking invalid candidates and premature convergence to one design region. ATLAS independently detects execution, interface, and feasibility failures, recomputes objectives, and applies error-conditioned repair; similarity-based archive management preserves algorithms across embedding-space regions to counter premature convergence. Its three-layer search refines the best design, gives other regions dedicated refinement opportunities, and performs cross-region synthesis to recombine components and their interactions. Across four NP-hard problems, ATLAS outperforms several state-of-the-art component-synthesis methods and a matched full-synthesis baseline while remaining competitive with strong human-designed algorithms. One ATLAS run retains several algorithms with comparable performance from distinct embedding-space regions rather than a single design. Code inspection finds that these multi-component designs differ in their primary construction or global-search backbone. Our results suggest that embedding-guided quality-diversity search can make the enlarged full-algorithm design space practically searchable. Source code and exact executable prompts are available at https://github.com/Danial-Yazdani/ATLAS .

### 一、核心问题与整体含义（研究动机与背景）

- **背景**：近年来，大语言模型（LLM）已被广泛用于自动化算法设计（Automated Algorithm Design）。主流方法（如 FunSearch、EoH、ReeVo）均为“组件合成”范式，即在人类预先定义好的算法脚手架（scaffold）内，只对某一指定组件（如优先选择规则、构造启发式、评分函数）进行优化。脚手架的固定意味着整体控制流、组件间交互、算法结构均被预先锁定，限制了探索空间。
- **核心问题**：能否打破脚手架限制，让 LLM 在不预设算法内部结构的前提下，从头合成一整套完整的、可执行的优化算法？这种“无脚手架全算法合成”（scaffold-free full-algorithm synthesis）虽能极大扩大搜索空间，却也带来了无效候选、执行/接口/可行性失败、以及过早收敛至单一设计区域等新挑战。
- **本文回答**：ATLAS 通过引入“嵌入引导的质量-多样性搜索”（embedding-guided quality-diversity search），将全算法设计空间组织为语义嵌入空间中的多个区域，既保持覆盖率、避免过早收敛，又能在多个区域间进行跨区重组，从而使这一扩大后的设计空间变得实际可搜索。

### 二、方法论：核心思想、关键技术细节与算法流程

#### 1. 总体框架
- ATLAS 仅固定三个外部要素：**问题规范**（目标、约束、有效解要求）、**最小 I/O 接口**（入口函数与实例/解的格式）、**统一评测协议**（资源上限），不规定任何内部组件清单、功能角色或控制流。
- 生成的算法负责完整地构造解、处理约束、管理内部状态并控制自身停止逻辑；外部评估器只做独立验证与目标值重算，不代替候选算法补全或修复解。

#### 2. 嵌入引导的相似性结构（Embedding-Based Similarity）
- 每个算法表示为三元组：**名称 n、描述 d、源代码 c**。
- 采用预训练嵌入模型 **mGTE-Large-EN-v1.5**，将名称、描述和预处理后的代码拼接为单一文本输入，得到语义嵌入（"semantic" 指嵌入空间相似性，非程序执行语义）。
- 维护增量距离矩阵 D，用于：k 近邻检索、聚类以定义操作区域、基于相似性的去重与剪枝。

#### 3. 覆盖保持存档（Coverage-Preserving Archive）
- 维护有界存档 A（容量 N_max=100），以语义嵌入空间中的覆盖率为组织原则：
  - **严格去重**：相似度 > 0.95 的对直接移除其一；
  - **软去重**：相似度 > 0.90 且性能差小于容差 ε 时移除较差者；
  - **容量剪枝**：超出容量时，优先移除最相似对中性能较差者，但保护精英区域 G*（当前最优 a* 及其 k-NN），避免破坏精细化的锚点。

#### 4. 语义搜索算子（Semantic Search Operators）
- **零参考（Create）**：从问题规范直接生成初始算法。
- **单参考精化**：Improve（保持核心方法改进逻辑）、Tune（固定结构调参）、Simplify（代码简化，抑制代码膨胀）。
- **多参考合成**：Combine（整合多个参考算法的互补思想）、Diverge（生成与参考区域明显不同的算法，用于大跳跃）。
- **错误条件修复（Repair）**：针对六类失败模式（内存超限、部分失败、超时、约束违反、运行时错误、接口违规）进行确定性分类路由，并据此生成修复后的完整代码，再全量重评。

#### 5. 两阶段初始化
- **阶段一**：用 Create 生成 20 个候选（温度 T=1.0），作为初始种子。
- **阶段二**：用 Diverge 迭代生成 30 个候选，参考从当前存档均匀采样，以显著扩大嵌入空间覆盖。

#### 6. 三层搜索策略
- 每轮迭代先对存档进行 k-medoids 聚类（基于嵌入距离，K 由 Silhouette 自动选择，K_min=3），并分离出精英区 G*（a* 及其 4 个近邻）。
- **Layer 1（精英区精化）**：对 a* 执行多轮 Improve/Tune/Simplify 强化，对 G* 中其他成员做概率性精化，并在 G* 内部做局部 Combine。
- **Layer 2（非精英区成熟化）**：对每个非精英聚类的代表执行单参考精化，并在其簇内做 Combine。
- **Layer 3（跨区发现）**：在代表之间进行跨簇 Combine、质量锚定的 a*+代表 Combine、以及包含 a* 的 Diverge。
- 每轮候选经评估/修复/嵌入后并入存档，重新去重、剪枝、聚类，循环直至预算耗尽。

#### 7. 形式化目标
- 给定问题 P 与训练集 I_train，寻找使平均成本最小化的算法：a_opt = argmin_{a∈V} (1/m) Σ Cost(a(x_i))。

### 四、主要结论与发现

1. **主结果**：ATLAS 在全部四个默认基准上统计显著优于所有 LLM 基线（EoH、ReeVo、MCTS-AHD、EoH-Full）。
2. **人工基线对比**：ATLAS 与最强人工算法相当——FSS 差距 0.347%、CVRP 0.094%、CVRPTW 0.000%、QAP 0.460%；在 CVRP 上与 PyVRP 无统计显著差异。
3. **全合成 vs 组件**：EoH-Full 显著优于组件版 EoH，说明“全算法 + 配套算子/评估”的变革具有实际增益；ATLAS 进一步优于 EoH-Full，证明嵌入引导质量-多样性搜索的价值。
4. **多模态保留**：单次 ATLAS 运行能在最终存档中保留多个来自不同嵌入区域的性能相当算法；代码检查表明这些算法在构造方法或全局搜索主干上确实存在差异（如遗憾插入、savings 构造、聚类、ruin-and-recreate、memetic 等），验证了多模态搜索行为。
5. **泛化**：在 n25/n100 尺度上，ATLAS 仍为最优 LLM 方法，且在部分小尺度设置与 IG-TB/PyVRP 持平。
6. **设计启示**：Diverge 双相初始化显著优于随机采样和人格提示变化；嵌入引导优于适应度/随机引导；三层完整配置优于任何缺层变体；低推理强度是最优性价比选择。

### 五、优点

- **彻底的无脚手架范式**：仅固定问题规范与最小 I/O 接口，给予 LLM 完全的结构设计自由度，能够探索传统组件方法无法覆盖的算法族。
- **嵌入空间组织的质量-多样性搜索**：将语义嵌入、聚类、检索、去重、剪枝统一在一致表征下，无需人工行为描述符，且能动态重组区域。
- **三层资源分配**：兼顾精英区强化、非精英区成熟化与跨区重组，避免过早收敛并支持跨区杂交。
- **独立评估与错误条件修复**：对执行、接口、格式、可行性失败做分类路由并定向修复，解决了全算法合成的关键工程问题。
- **实验设计严谨**：统一 token 预算、共享脚手架与评估器、配对的统计检验（Wilcoxon）、训练-测试严格隔离、失败即记录不重试，降低了偏差。
- **丰富的设计分析**：对嵌入模型选择、初始化策略、搜索引导、推理强度等系统关键旋钮做了系统消融，提供了可复现的工程指导。

### 六、不足与局限

- **算力与训练成本未明确**：论文仅报告 API 成本与单次运行时长，未说明 RTX 5090 在其中的具体用途（推测主要用于本地嵌入计算与并行评估），也未披露电耗、机器月租等效成本。
- **样本量有限**：LLM 合成方法仅 5 次独立运行，统计功效受限于合成成本；且未对候选算法在更多随机种子下做大规模重复验证。
- **基准规模偏小**：默认规模均为 n=50 的合成均匀实例，未涉及更大规模（如 CVRP n500、FSS n500）或真实世界数据集；n100 时差距扩大至 1.6%–1.8%，大尺度表现仍需验证。
- **实现语言偏差**：路由类人工基线（PyVRP、OR-Tools）以 C++ 内核执行，而 ATLAS 生成的算法为纯 Python，同等时间上限下有语言级劣势；作者虽指出这一点，但这意味着“竞争性强”的结论在公平计算资源下可能略有折扣。
