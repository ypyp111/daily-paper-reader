## 摘要
物理信息神经网络（PINNs）将控制偏微分方程直接嵌入训练损失中，为非定常流动提供了一种有前景的替代昂贵CFD求解器的方法。然而，为提高PINN训练而提出的技术清单不断增长，但通常一次只验证一种技术，这些技术是否真正组合使用仍未有定论。我们在DFG/Schafer-Turek非定常圆柱尾流基准上深入研究了这个问题。在孤立情况下，几乎每种技术都不比未处理的基线更好。然而，将周期（SIREN）激活函数与因果加权相结合，解锁了以前无法达到的状态，相对于OpenFOAM参考解，速度和压力场的平均相对L2误差在4.1%以内。进一步增加技术反而导致灾难性的性能下降，这表明单独有效的PINN干预措施可能以非线性方式相互作用，更复杂的训练方案不一定更好。

## Abstract
Physics-informed neural networks (PINNs) embed governing partial differential equations directly into the training loss, offering a promising alternative to costly CFD solvers for unsteady flows. Yet the growing list of techniques proposed to improve PINN training is typically validated one at a time, leaving open whether these techniques actually compose. We study this question in depth on the DFG/Schafer-Turek unsteady cylinder wake benchmark. In isolation, nearly every technique performs no better than an untreated baseline. However, combining periodic (SIREN) activations with causal weighting unlocks a previously inaccessible regime, reconstructing velocity and pressure fields to within 4.1% average relative L2 error against an OpenFOAM reference solution. Adding further techniques instead causes catastrophic performance degradation, demonstrating that individually effective PINN interventions can interact nonlinearly and that more elaborate training recipes are not necessarily better.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：物理信息神经网络（PINNs）通过将控制偏微分方程（PDE）嵌入训练损失来求解物理系统，为替代昂贵的计算流体力学（CFD）求解器提供了可能。然而，PINN 在非定常、高雷诺数流动等问题上训练不稳定，且常失败。
- **问题**：社区提出了大量改进 PINN 训练的技术（如改变激活函数、损失加权、边界条件处理等），但这些技术通常孤立验证，**它们组合在一起时是否仍然有效、是否能够叠加增益，尚不清楚**。
- **核心含义**：论文通过系统实验发现，多数单独技术几乎无效；但 **周期激活（SIREN）+ 因果加权（Causal Weighting）** 的组合可以显著解锁涡脱落学习；而在此基础上继续堆叠更多技术（如 Fourier 特征、自适应权重）反而导致灾难性退化。这表明 **PINN 技术的效果是非线性的、非累积的**——复杂配方并不必然更好。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

论文采用**标准 PINN 公式**，并未提出新的专用架构或损失，而是系统组合已有技术并分析其交互效应。

### 2.1 基础 PINN 设置（Re=100 前先在 Re=20 上验证）

- **架构**：8 层全连接 MLP，宽度 128，激活函数为 tanh，Xavier 均匀初始化权重，零初始化偏置。输入为归一化坐标（x, y, t），输出为速度（u, v）和压力 p。
- **损失函数**：
  \[
  \mathcal{L} = \lambda_{\text{phys}}\mathcal{L}_{\text{phys}} + \lambda_{\text{bc}}\mathcal{L}_{\text{bc}} + \lambda_{\text{ic}}\mathcal{L}_{\text{ic}}
  \]
  其中 \(\lambda_{\text{phys}}=3.0, \lambda_{\text{bc}}=5.0, \lambda_{\text{ic}}=0.2\)。
- **损失项**：
  - \(\mathcal{L}_{\text{phys}}\)：连续性方程和动量方程的残差，通过自动微分计算。
  - \(\mathcal{L}_{\text{bc}}\)：入口（解析抛物型剖面）、出口（零压力）、壁面与圆柱表面（无滑移）的边界条件。
  - \(\mathcal{L}_{\text{ic}}\)：初始时刻速度为零。
- **采样**：每训练步重新采样 8000 个配点、各边界 500 点、初始条件 300 点。
- **训练**：AdamW，学习率 \(10^{-3}\)，余弦退火，125K 步，梯度裁剪 1.0。

### 2.2 候选技术

1. **Fourier 特征编码（Fourier Features）**：将输入通过 \(\gamma(x)=[\sin(2\pi Bx),\cos(2\pi Bx)]\) 提升到高频基，\(B\) 从 \(\mathcal{N}(0,\sigma^2)\) 采样并固定。实验中采用空间和时间两个独立编码器（\(\sigma_{\text{spatial}}=2.0, \sigma_{\text{time}}=1.0\)），旨在缓解 spectral bias。
2. **因果加权（Causal Weighting）**：将时间分成 20 个区间，每个区间权重由之前所有区间残差累积决定：
   \[
   w_k = \exp\left(-\epsilon \sum_{j<k} \bar{r}_j\right)
   \]
   其中 \(\bar{r}_j\) 为第 j 个时间区间平均物理残差，\(\epsilon=1.0\)。这强制模型先学会早期时间，再关注后期时间。
3. **硬边界条件（Hard Boundary Conditions）**：使用距离函数构造圆柱表面掩码 \(d(x,y)=\tanh(10(r_{\text{dist}}-r)/r)\)，将其乘入速度输出，使圆柱表面无滑移条件被架构精确满足，而非通过损失软约束。
4. **周期激活（SIREN）**：用 \(\sin(\omega z)\) 替换 tanh，首层 \(\omega=30\)，其他层 \(\omega=1\)，并采用相应初始化。周期函数保证了高阶导数仍然有界，适合流体 PDE 中多次微分。
5. **自适应损失权重（Self-Adaptive Weights）**：将损失权重参数化为 \(\lambda_k=\exp(\ell_k)\)，通过 min-max 更新（网络最小化损失，权重梯度上升），并限制 \(\ell_k \in [-3, 5]\)。
6. **L-BFGS 微调**：在 Adam 训练后，用 L-BFGS（强 Wolfe 线搜索，历史 100 步）进行二阶优化微调。

### 2.3 实验基线

- 基础配方在 Re=100 时完全失败（误差高达 68%-118%），因此引入**数据监督项** \(\mathcal{L}_{\text{data}}\)：从 OpenFOAM 结果中抽取 1% 样本（40,000 点）进行监督训练。该配置作为后续实验的基线。
- 所有实验保持固定计算预算，不刻意追求完全收敛，依赖相对比较得出结论。

## 3. 实验设计：数据集 / 场景、benchmark、对比方法

- **数据集生成**：
  - 使用 OpenFOAM v2512 生成参考数据，网格为 50,184 个六面体单元（Gmsh 生成），采用 icoFoam 求解器与 PISO 压力-速度耦合。

  - **Re=100**（非定常涡脱落）：模拟 \(t\in[0,8]\) s，\(\Delta t=0.0002\) s，每 0.1 s 输出一个快照，共 80 个快照，总计约 401 万个数据点。平均阻力系数误差 7.8%，升力振幅和 Strouhal 数误差 <1%。
  - 三个物理场 u、v、p 均来自 OpenFOAM 内部单元格中心值。
- **对比方法**：
  - 基线（物理损失 + 数据监督）。
  - 5 种个别技术单独替换/添加。
  - 多种组合：Fourier + 因果加权、SIREN + 因果加权（及不同超参）、SIREN + 因果加权 + 自适应权重、Fourier + SIREN + 因果加权。
  - 在最佳组合上进一步测试：增加训练 epoch、增大模型宽度（6 层×256）、L-BFGS 微调。
  - 另设有纯数据监督控制实验（移除物理损失）以检验物理损失的作用。
- **评估指标**：
  - 主要指标：相对 L2 误差（全场，分 Ux、Uy、p）。
  - 辅助指标：预测 Strouhal 数、尾流探针（x/D = 2, 4, 6）的振幅比、时间相关。

## 6. 论文的主要结论与发现

1. **单独技术无效**：Fourier 特征、因果加权、SIREN、硬边界、自适应权重单独使用时，相比基线几乎无提升，甚至更差（自适应权重使误差显著增大）。
2. **特定组合有效**：**SIREN 激活 + 因果加权** 是解锁涡脱落的关键组合，恢复正确 Strouhal 数（0.300）并实现强相位锁定（尾流相关 0.988）。Fourier + 因果加权次之，但不如 SIREN 组合。单独加数据监督也只能部分恢复 Ux 和 p，无法解决 Uy。
3. **更强性能需要容量和训练**：SIREN + 因果加权 + 加深模型（6×256）并训练至收敛，相对 L2 误差降至 Ux=3.0%, Uy=4.8%, p=4.6%，平均约 4.1%，压力降和速度剖面与 OpenFOAM 几乎不可区分。
4. **非累积效应**：在有效组合上继续添加其他技术导致崩溃：
   - 添加 **自适应权重**：所有损失权重早期依次升至上限，造成优化不稳定，训练冻结。
   - 添加 **Fourier 特征**：其与 SIREN 的复合频率导致初始物理残差放大 ~79 倍，网络选择塌缩到常数解（输出层范数减小 21 倍），所有导数归零，物理损失被“假满足”。
5. L-BFGS 微调在这种问题上“一步崩溃”，破坏 SIREN 的高频表示能力，而非渐进漂移。
6. 总体结论：**PINN 技术是互补的而非累积的**——关键在于找到正确组合，而非堆叠尽量多的技巧。

- **算力限制**：所有实验在 T4 GPU 上且固定预算下进行，未训练至收敛；虽然相对比较仍然有效，但绝对性能可能低估。
