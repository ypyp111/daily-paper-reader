## 摘要
卷积积分在应用中广泛存在，为了实现快速且准确的计算，本文引入了两种通用的多阶段神经算子学习框架。第一种是深度配置神经算子（DCNO），这是一种监督方法，通过从输入-输出数据对中学习残差来迭代改进算子逼近。第二种是深度伽辽金神经算子（DGNO），这是一种无监督框架，适用于目标算子可以用偏微分方程表示的情况，利用偏微分方程残差的弱形式进行训练。两种方法都通过多个训练阶段逐步构建基算子以丰富逼近空间，相较于标准的一次性算子学习，精度显著提高。我们对其逼近能力进行了理论分析，并将其应用于学习卷积。大量数值实验表明，DCNO和DGNO均能达到高精度，在单精度浮点下卷积问题接近机器精度，并且相比传统求解器，在大量查询或参数变化情况下提供了显著的效率提升。我们还将这些框架扩展到处理涉及卷积密度和核均变化的多输入算子学习场景。

## Abstract
Convolution integrals widely exist in applications, and to enable fast and accurate computations, this paper introduces two general multi-stage neural operator learning frameworks. The first, Deep Collocation Neural Operator (DCNO), is a supervised approach that iteratively refines the operator approximation by learning residuals from input-output data pairs. The second, Deep Galerkin Neural Operator (DGNO), is an unsupervised framework applicable when the target operator can be represented by a PDE, leveraging the weak form of the PDE residual for training. Both methods progressively construct basis operators through multiple training stages to enrich the approximation space, leading to significantly improved accuracy over standard one-shot operator learning. We provide theoretical analysis for their approximation capabilities and implement them for learning convolutions. Extensive numerical experiments demonstrate that both DCNO and DGNO achieve high accuracy, approaching machine precision under single float for convolution problems, and offer substantial efficiency gains for numerous queries or parametric variations compared to traditional solvers. We also extend these frameworks to handle multi-input operator learning scenarios involving variations in both the density and kernel of a convolution.

## 一、论文的核心问题与整体含义（研究动机和背景）

卷积积分（Convolution integrals）在静电势计算、引力粒子模拟、信号处理、图像处理等大量科学与工程应用中普遍存在，其核心计算形式为：

\[
\phi(x) = \mathcal{G}(\rho)(x) = \int_{R} K(x,\tilde{x})\rho(\tilde{x}) d\tilde{x}
\]

- 尽管该映射是线性的，但其**非局部性**导致直接离散计算开销极大，传统快速求解器（如快速多极子、层次矩阵、高斯求和、核截断等）一般需要 \(O(N\log N)\) 的复杂度。
- 传统方法**每次针对新输入密度都要重新计算**，在大量查询或参数变化场景中成本高昂；并且只能在预设网格上输出解，新点的取值需要额外插值。
- 神经算子学习（如 DeepONet、FNO 等）可将输入函数空间映射到输出解空间，训练完成后可快速预测。但已有方法大多依赖**一次性（one-shot）监督训练**，精度有限，难以与传统快速求解器竞争。

**核心动机**：
1. 通过**多阶段残差驱动的渐进式构造**，克服一次性训练精度受限的问题。
2. 提出一个**无监督**方案，避免依赖标签数据（生成高精度标签本身成本很高）。

## 二、论文提出的方法论

### 2.1 总体思想

论文提出两种通用的**多阶段神经算子学习框架**，通过多个训练阶段逐步构造“基算子”，将目标算子表示为基算子的线性组合，从而丰富逼近空间、逐级降低残差、提高精度。

### 2.2 DCNO（Deep Collocation Neural Operator）——监督式方法

- **适用条件**：存在输入-输出数据对 \(\{(\rho^{(b)}, \phi^{(b)})\}\)，即目标算子可由数据驱动的监督学习描述。
- **核心流程**：
  1. 初始算子 \(\mathcal{G}_0 = 0\)。
  2. 在第 \(s\) 阶段，计算当前残差 \(e_{s-1} = \mathcal{G} - \mathcal{G}_{s-1}\)，用 DeepONet 基算子 \(\mathcal{G}_{\theta_s}\) 逼近**归一化残差**。
  3. 通过最小化加权损失函数（残差缩放至 O(1)）训练网络。
  4. 更新近似算子：\(\mathcal{G}_s = \sum_{j=1}^{s} \beta_{j-1}\mathcal{G}_{\theta_j}\)。
  5. 迭代至残差范数小于容差 \(\epsilon\)（或达到最大阶段数）。
- **实现细节**：
  - 使用 DeepONet 作为基算子网络：分支网络接收输入函数采样值，主干网络接收空间坐标，二者内积输出连续函数表示。
  - 网络宽度、latent dimension 随阶段数递增（如 \(W = W_0 + 20(s-1)\)）。
  - 采用 Adam 优化器 + Xavier 初始化，激活函数用 \(\sin\) 或 \(\tanh\)。

### 2.3 DGNO（Deep Galerkin Neural Operator）——无监督方法

- **适用条件**：目标算子可由 PDE 表示，通过弱形式残差训练，无需任何标注输出数据。
- **核心思想**：类比 Galerkin 神经网络（GNN），对每个输入 \(f\)，PDE 残差泛函 \(R_{s-1}(f,v)\) 的最大方向等价于归一化误差 \(\phi_{s-1}(f)\)。因此可将优化目标推广到算子层面：

\[
\mathcal{G}_{\theta_s} \in \arg\max_{\mathcal{G}_\theta \in \mathcal{D}} \mathbb{E}_{f\sim\mu} \left[ \frac{R_{s-1}(f, \mathcal{G}_\theta(f))}{\|\mathcal{G}_\theta(f)\|_X} \right]
\]

- **训练流程**：
  - 逐阶段训练基算子网络（DeepONet），损失函数为负的归一化残差期望（4.3）。
  - 每阶段末，用 Galerkin 投影求解线性系统（4.4）确定组合系数 \(\beta(f)\)，更新近似解。
- **配套技巧**：对于整个空间上的卷积问题，结合**矩匹配（moment-matching）**策略，将无限域问题精确截断到有界域，转化为带零边界条件的局部 PDE。

## 六、论文的主要结论与发现

1. **多阶段构造显著提升精度**：以 2D Poisson 为例，标准 DeepONet（阶段 1）测试误差约 \(8.17\times 10^{-3}\)，经过 5 个阶段后 DCNO 降至 \(5.47\times 10^{-7}\)，DGNO 降至 \(6.17\times 10^{-7}\)，接近单精度浮点机器精度。
2. **DCNO 与 DGNO 均具有理论保证**：
   - Theorem 3.2：DCNO 的误差随阶段数呈指数递减（\(\tau^s\)），并给出含数据误差的全局误差界。
   - Theorem 4.6：DGNO 的误差单调递减，并给出残差与误差的双向不等式。
3. **DGNO 无监督但精度不劣**：在相同阶段数和 epoch 下，DGNO 泛化误差略低于 DCNO，但训练耗时更长。
4. **计算效率优势显著**：在 1000 个测试样本的 1D 卷积问题上，DCNO 评估时间约 0.021s，而传统 SOE 需 670.44s（加速约 3 万倍）；在 Schrödinger-Poisson 模拟中，DGNO 大幅减少了 Poisson 求解时间。
5. **方法可扩展到多输入**：结合 MIONet，DCNO 可同时学习密度与核变化，DGNO 可同时学习 PDE 的系数与源项，最终误差分别达到 \(1.40\times 10^{-5}\) 和 \(7.08\times 10^{-5}\)。

## 七、优点

1. **创新性**：将深度学习求解 PDE 的“残差驱动多阶段精化”思想推广到算子学习，弥补一次性训练的精度瓶颈。
2. **两个互补框架**：DCNO（监督）与 DGNO（无监督）分别适配有/无 PDE 表述的问题，适用面广。
3. **理论分析扎实**：给出误差递推界、Sobolev 范数下的 DeepONet 通用逼近引理，以及含噪声时的鲁棒误差界。
4. **工程应用价值强**：集成矩匹配可将无限域卷积精确截断；实际应用于 Schrödinger-Poisson 动力学加速，验证了方法的实效性。
5. **实验结果丰富**：至少 25 页论文，多组数值表格与图像，覆盖精度、噪声鲁棒性、计算效率和多输入扩展。

## 八、不足与局限

1. **函数分布局限**：训练/测试输入函数几乎均为高斯型或人工构造的解析形式，缺乏对不规则、随机场、分片不光滑函数的验证。
2. **无监督适用范围有限**：DGNO 要求目标算子能写成 PDE（弱形式），对没有 PDE 表述的卷积（如 Example 5.2 中的 multiquadric 核）失效，只能退化为 DCNO。
3. **理论假设较强**：误差定理假设每阶段训练足够充分、能逼近理想残差方向到给定阈值 \(\tau\)，实际操作中依赖优化器调参，可能难以严格满足。
4. **多输入实验规模偏小**：多输入样本仅 20×20，且参数维度低（1D 随机参数），无法充分反映高维函数空间下的性能。
5. **硬件/算力细节不明确**：未明确给出模型参数量、训练时的内存/能源消耗、GPU 与 CPU 方法的划分细节，也不清楚“单个 CPU”和“单个 GPU”分别用于哪些实验。
6. **对比方法覆盖有限**：未与传统神经算子方法（FNO、标准 DeepONet、MIONet 等）做系统的“同条件”对比，除 Example 5.1/5.4 外，多数对比只针对传统数值方法。
