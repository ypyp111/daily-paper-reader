## 摘要
从观测数据中发现控制微分方程是科学机器学习中的一个基本挑战。现有的符号回归方法主要依赖于定量指标；然而，现实世界的微分方程建模还需要结合领域知识以确保物理上的合理性。为了填补这一空白，我们提出了 DoLQ，一种基于大语言模型（LLM）定性与定量评估的常微分方程发现方法。DoLQ 采用多智能体架构：采样智能体（Sampler Agent）提出动力系统候选方案，参数优化器（Parameter Optimizer）对方程进行精细化以提高准确性，科学家智能体（Scientist Agent）则利用 LLM 进行定性和定量评估，并综合评估结果以迭代地引导搜索。在多维常微分方程基准测试上的实验表明，与现有方法相比，DoLQ 取得了更优越的性能，不仅获得了更高的成功率，而且能更准确地恢复出真实方程的正确符号项。我们的代码可在 https://github.com/Bon99yun/DoLQ 获取。

## Abstract
Discovering governing differential equations from observational data is a fundamental challenge in scientific machine learning. Existing symbolic regression approaches rely primarily on quantitative metrics; however, real-world differential equation modeling also requires incorporating domain knowledge to ensure physical plausibility. To address this gap, we propose DoLQ, a method for discovering ordinary differential equations with LLM-based qualitative and quantitative evaluation. DoLQ employs a multi-agent architecture: a Sampler Agent proposes dynamic system candidates, a Parameter Optimizer refines equations for accuracy, and a Scientist Agent leverages an LLM to conduct both qualitative and quantitative evaluations and synthesize their results to iteratively guide the search. Experiments on multi-dimensional ordinary differential equation benchmarks demonstrate that DoLQ achieves superior performance compared to existing methods, not only attaining higher success rates but also more accurately recovering the correct symbolic terms of ground truth equations. Our code is available at https://github.com/Bon99yun/DoLQ.

*   **核心问题**：如何从观测数据中推导出既具有高数值精度，又符合物理逻辑的控制方程。
*   **研究动机**：传统的符号回归（SR）方法（如 SINDy 或基于遗传算法的方法）主要依赖均方误差（MSE）等定量指标。然而，数值拟合效果好并不代表物理意义正确（即“异式同果”现象）。
*   **背景**：现有的基于 LLM 的方程发现方法虽然引入了先验知识，但仍缺乏对候选方程项的系统性物理合理性评估，导致生成的方程往往过于冗余或物理上不可解释。

### 2. 方法论：DoLQ 框架
DoLQ 采用多智能体协作架构，通过迭代循环不断精炼方程：
*   **采样智能体 (Sampler Agent)**：利用 LLM 根据系统描述（如“空气阻力”、“重力”）和科学家智能体的反馈，提出候选的数学项（Term Skeletons）。
*   **参数优化器 (Parameter Optimizer)**：采用**混合优化策略**。先通过**差分进化算法（Differential Evolution）**进行全局搜索以确定参数的大致范围，再利用 **BFGS 算法**进行局部精炼，从而最小化残差 MSE。
*   **科学家智能体 (Scientist Agent)**：这是核心组件，进行双重评估：
    *   **定量评估**：通过**消融实验（Ablation Test）**，逐一将方程项系数设为零，观察误差变化，判断该项是否真正对拟合有贡献。
    *   **定性评估**：利用 LLM 判断该项是否符合系统描述中的物理原理（如符号是否正确、函数形式是否合理）。
*   **反馈合成**：综合两项评估结果，将项标记为“保留（Keep）”、“持有（Hold）”或“移除（Remove）”，并记录“禁言列表（Ban List）”以防止采样智能体重复提出错误的项。

### 8. 不足与局限
*   **噪声敏感性**：参数优化依赖于数值微分，在处理高噪声数据时，精度会受到显著影响。

*   **扩展性**：目前仅限于常微分方程（ODE），尚未扩展到更复杂的偏微分方程（PDE）。
