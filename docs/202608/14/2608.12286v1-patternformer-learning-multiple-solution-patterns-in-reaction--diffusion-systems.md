## 摘要
许多物理、化学和生物学中的非线性模型在相同参数下表现出多个解，而捕捉整个解集对于理解模式形成系统至关重要。然而，现有的学习代理模型从根本上来说是单值的：神经算子将每个参数映射到单一输出，物理信息神经网络则收敛到单一分支。我们开发了PatternFormer（PF），一个基于大语言模型的框架，用于学习非线性偏微分方程的多个解。通过将无序的共存解转换为规范序列，PF在单次自回归过程中生成结构化的解集，对于有限族自动终止，并对无界族施加物理残差约束。在非线性椭圆问题上，它通过一次推理步骤恢复所有解分支；在Gray--Scott问题上，它生成共存的图灵模式，包括参考数据中不存在且超出训练范围的物理有效状态。PF还可以跨多稳态系统进行顺序微调，朝着解景观的通用基础模型发展。

## Abstract
Many nonlinear models across physics, chemistry, and biology exhibit multiple solutions for the same parameters, and capturing this entire solution set is essential for understanding pattern-forming systems. Yet existing learned surrogates are fundamentally single-valued: neural operators map each parameter to a single output, and physics-informed neural networks converge to one branch. We develop \textbf{PatternFormer} (PF), a large language model-based framework for learning the multiple solutions of nonlinear partial differential equations. By transforming unordered coexisting solutions into canonical sequences, PF produces structured solution sets in a single autoregressive pass, terminating automatically for finite families and enforcing physical residual constraints for unbounded ones. On nonlinear elliptic problems it recovers all solution branches in one inference step; on Gray--Scott it generates coexisting Turing patterns, including physically valid states absent from the reference data and beyond training. PF can also be sequentially fine-tuned across multistable systems, toward general foundation models for solution landscapes.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想：将集合值算子学习转化为序列生成

- **集合值算子定义**：
  \[
  G: p \mapsto S(p) = \{u_1, \ldots, u_{K(p)}\}
  \]
  其中 \( S(p) \) 为参数 \( p \) 下完整共存稳态解集合，\( K(p) \) 为解的个数（随参数变化）。
- **关键转化**：由于共存解是无序集合，PF 基于单调标量泛函 \(\Phi(u)\)（如一维问题的 \(\int_0^1 u dx\)、Gray–Scott 的活化子场空间均值）施加**规范排序**（canonical ordering），将无序解集转化为有序序列，从而适配自回归生成模型。

### 2.2 模型架构

PF 以**冻结的 Qwen2.5-7B** 为骨干，通过 **LoRA（秩 r=16）** 微调，具体包含六个组件：

1. **冻结卷积自编码器**：将解场 \(u\) 压缩为 256 维潜变量 \(z = E(u)\)，解码器 \(D\) 重构解场。
2. **结构化嵌入（可学习）**：包括块起始嵌入 \(v_s\)、解分隔符嵌入 \(v\)、终止嵌入 \(v_p\)。
3. **输入匹配层 \(g_{in}\)**：两层 MLP（GELU 激活），将拼接的参数-潜变量向量 \([z; p]\) 投影到大语言模型的嵌入空间。
4. **冻结 Qwen2.5-7B Transformer**：通过因果注意力处理连续嵌入序列。
5. **输出匹配层 \(g_{out}\)**：将隐状态映射回潜变量维度。
6. **双预测头**：潜变量回归头 + 标记分类头（用于自适应终止，当解的数量已知时）。

### 2.3 序列构造与训练

- **序列块构造**：
  \[
  B(p) = [v_s, g_{in}(0, p), v, \tilde{z}_1, v, \tilde{z}_2, \ldots, v, \tilde{z}_K, v_p]
  \]
- **训练方式**：自回归训练 + teacher forcing。训练分三阶段：
  1. 预训练自编码器（重建损失，随后冻结）；
  2. 带上下文示例（in-context prompts）训练完整模型；
  3. 移除上下文的微调阶段（no-context），使模型从纯参数直接生成。
- **带上下文示例的输入**：\(B(p_1), \ldots, B(p_M), B(p^*)\)，为模型提供解景观的示范；Gray–Scott 系统中上下文参数在目标参数附近局部选择。

### 2.4 两种生成策略（按解的个数是否已知区分）

- **停止标记策略（Stop-token）**：当解的个数理论上可知（如椭圆问题），模型通过分类头预测终止位置，训练损失为：
  \[
  L_{stop} = \sum_{k=1}^{K(p)} [\lambda_{mse}\|\hat{u}_k - u_k\|^2 + \lambda_{pde}\text{ReLU}(R(\hat{u}_k;p)-\epsilon)] + \lambda_{ce} L_{marker}
  \]
- **固定预算策略（Fixed-budget）**：当解的个数不可知（如 Gray–Scott），固定生成 K=24 个解槽位：前 \(K_t\) 个槽位用参考解 teacher-force（数据损失），剩余槽位自由生成（仅受物理残差约束），损失为：
  \[
  L = \sum_{k=1}^{K} \left[ (\lambda_{mse}\|\hat{u}_k-u_k\|^2 + \lambda_{lat}\|\hat{z}_k-z_k\|^2)\mathbb{1}[k \le K_t] + \lambda_{pde}\text{ReLU}(R(\hat{u}_k;p)-\epsilon) \right]
  \]
- **物理残差约束**：采用**hinged 惩罚** \(\lambda_{pde}\text{ReLU}(R(\hat{u}_k;p)-\epsilon)\)，避免模型坍缩到平凡解（trivial solution），同时鼓励生成物理有效的解——这是发现训练集之外新解的关键。
- **多重性加权采样**（multiplicity-weighted sampling）：增加高解数参数的采样概率，避免罕见的高多重性参数被忽略。

### 2.5 推理策略

- **确定性单次生成**：一次前向传播拟合所有共存解（公式 7）。
- **噪声增强探索**：对潜变量注入高斯噪声（公式 9），多条噪声轨迹经 Newton 细化后去重（相对 L2 距离 > 0.15 视为不同解），累积发现更多解。
- **Newton 细化**：生成解作为初始值，用经典求解器细化至残差 \(\|F\| < 10^{-9}\)。
- **外推与延拓**：用 PF 预测的边界解集合作为 Newton 的种子，支持单跳（single jump）和逐步推进（stepped march），可将解结构传输到更远参数。

## 6. 主要结论与发现

1. **一次推理恢复完整解集**：在非线性椭圆问题上，PF 一次前向传播即可恢复全部解分支（如 7 个共存解），中位相对 L2 误差 \(2.3\times10^{-2}\)，Newton 细化 3 轮后降至 \(2.9\times10^{-8}\)，99.9% 测试参数收敛。
2. **学习到全局解景观结构**：PF 重构了分歧图（bifurcation diagram），准确再现分支结构和 fold 分歧点位置。
3. **分辨率泛化**：在 N=1024 训练的模型可直接用于 N=2048/4096，无需重训。
4. **开放式的 Gray–Scott 图灵斑图发现**：在代表参数处，确定性生成 + 噪声增强发现 63 个不同稳态斑图，其中 61 个为训练数据之外的新物理有效态（残差 < \(10^{-9}\)）。测试集平均每参数发现 8.39 个解（对比传统随机启动求解器 0.91、停止标记设计 1.86、无噪声固定 K 2.90）。
5. **外推能力**：
   - 直接生成可在训练边界附近恢复完整解集；渐进延拓（stepped march）可将解结构传输到远超训练范围的参数。
   - 所有生成解经 Newton 细化均收敛到真实解，无虚假分支。
   - Gray–Scott 在 144 个 OOD 参数单元中 9 个产生非平凡解，且与参考求解器的模式形成区间一致。
6. **预训练与热启动的增益显著**：预训练 LLM 比随机初始化收敛更快、精度更高；跨方程热启动（Example 2 → Example 3）降低验证损失和测试误差；Gray–Scott 上热启动将每参数解数从 3.23 提升至 5.18。
7. **解发现与数值细化分离**：PF 执行核心的解发现，Newton 细化仅提升数值精度（3-4 轮迭代），不改变分支归属。
