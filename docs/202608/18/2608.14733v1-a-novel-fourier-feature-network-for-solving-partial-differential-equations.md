## 摘要
在单隐层神经网络的基础上，提出了傅里叶特征网络（FENs），该网络使用$\cos$、$\sin$或两者的组合来引入傅里叶特征。与极限学习机（ELMs）类似，FENs采用单隐层架构来生成一组基函数。目标函数随后被近似为这些基函数的线性组合，系数通过最小二乘法确定。然而，与通常依赖仿射变换来提升表示能力的ELMs不同，FENs无需对输入变量进行此类变换即可实现高精度解。为了评估这些网络的表示能力，我们在预定义范围内搜索随机初始化并固定的权重和偏置的最优缩放因子。通过调整该缩放因子，我们确保FENs与使用各种激活函数（如$\text{sigmoid}$、$\tanh$和$\text{swish}$）的ELMs之间进行公平比较。我们的数值实验表明，FENs consistently achieves higher accuracy than ELMs.

## Abstract
Building on the foundation of single-hidden-layer neural networks, Fourier Feature Networks (FENs) are proposed, which incorporate Fourier features using $\cos$, $\sin$, or a combination of both. Similar to Extreme Learning Machines (ELMs), FENs employ a single-hidden-layer architecture to generate a set of basis functions. The target function is then approximated as a linear combination of these basis functions, with the coefficients determined using the least squares method. However, unlike ELMs, which often rely on affine transformations to improve representational power, FENs can achieve high-precision solutions without requiring such transformations on the input variables. To evaluate the representational capacity of these networks, we search for an optimal scaling factor within a predefined range for the randomly initialized and fixed weights and biases. By adjusting this scaling factor, we ensure a fair comparison between FENs and ELMs using various activation functions, such as $\text{sigmoid}$, $\tanh$, and $\text{swish}$. Our numerical experiments demonstrate that FENs consistently achieve higher accuracy than ELMs.

## 2. 论文提出的方法论

### 核心思想
- 借鉴傅里叶特征思想，**在单隐层 ELM 的基础上，将激活函数替换为三角函数（$\cos$、$\sin$ 或组合），从而天然地引入傅里叶特征**，使网络无需仿射变换即可逼近目标函数的频域结构。
- 权重和偏置随机初始化后**固定不变**，仅通过最小二乘求解输出层线性组合系数 $\boldsymbol{w}$。

### 关键技术细节

**三种 FEN 变体：**
1. **FEN-cos**：$u_M(\boldsymbol{x}) = \boldsymbol{w}^T \cos(\boldsymbol{W}\boldsymbol{x} + \boldsymbol{b})$
2. **FEN-sin**：$u_M(\boldsymbol{x}) = \boldsymbol{w}^T \sin(\boldsymbol{W}\boldsymbol{x} + \boldsymbol{b})$
3. **FEN-cos&sin**：$u_M(\boldsymbol{x}) = (\boldsymbol{w}^{(1)})^T \cos(\boldsymbol{W}^{(1)}\boldsymbol{x} + \boldsymbol{b}^{(1)}) + (\boldsymbol{w}^{(2)})^T \sin(\boldsymbol{W}^{(2)}\boldsymbol{x} + \boldsymbol{b}^{(2)})$，其中 $M = 2p$

**求解线性 PDE 的流程：**
- 构造基函数矩阵 $\boldsymbol{A}$，对内部配点应用 PDE 算子 $\mathcal{L}$，对边界配点应用边界算子 $\mathcal{B}$，得到形如 $\boldsymbol{A}\boldsymbol{w} = \boldsymbol{F}$ 的线性方程组，再用最小二乘求解。
- 时间相关问题时，初始/边界条件统一作为边界约束处理，不额外加权。

**最优缩放因子搜索（Algorithm 1）：**
- 均匀分布初始化权重和偏置。
- 在给定范围 $(\rho_{min}, \rho_{max}]$ 内按步长 $\rho_s$ 枚举缩放因子 $\rho$，对每个 $\rho$ 计算损失 $\|\boldsymbol{A}\boldsymbol{w} - \boldsymbol{F}\|$，取损失最小的 $\rho$ 为最优缩放因子 $\rho_{opt}$。
- 定理 3.2 证明了最优缩放因子的存在性。

**近似理论：**
- 定理 3.3–3.5 给出了三种 FEN 的 $L^2$ 近似误差界，均为 $O(1/M)$ 量级（或 $O(1/p)$，对 cos&sin 组合），表明 FEN 对可傅里叶表示的函数类 $\mathbb{F}_{C,\Omega}$ 具有理论收敛保证。

## 6. 论文的主要结论与发现

1. **FEN 一致优于 ELM**：在所有数值实验中，FEN（三种变体）在最优缩放因子下的 $L^\infty$ 和 $L^2$ 误差均显著低于 ELM（sigmoid/tanh/swish）。

2. **无需仿射变换**：FEN 不需要像 ELM 那样对输入做仿射变换即可达到甚至超过 ELM 加入仿射变换的精度。例如：
   - 二维函数逼近：FEN-cos&sin 最小误差 $L^\infty = 6.48\times10^{-15}$，ELM-tanh 最小 $L^\infty = 1.98\times10^{-10}$，差距约 4-5 个数量级。
   - 热度方程：FEN-sin 最小 $L^\infty = 2.61\times10^{-14}$，ELM-swish 最小 $L^\infty = 2.44\times10^{-12}$。
   - 波动方程：FEN-cos 最小 $L^\infty = 2.44\times10^{-15}$，ELM-swish 最小 $L^\infty = 1.44\times10^{-12}$。

3. **可达到机器精度**：FEN 在多数问题中达到 $10^{-14}$–$10^{-15}$ 量级误差，远超 ELM（一般 $10^{-10}$–$10^{-12}$ 量级）。

4. **非线性问题同样有效**：在非线性 Helmholtz 方程和 Burgers 方程中，FEN 依然优于 ELM、且误差更低；但 Burgers 方程因解存在大梯度，所有方法精度均有下降。

5. **高维性能**：$d=5$ 时 FEN 明显优势（FEN-cos 最小 $L^\infty=1.24\times10^{-13}$ vs ELM-swish $1.60\times10^{-12}$）；$d=7,10,15$ 时 FEN 与 ELM 的精度差距缩小，两者基本相当（约 $10^{-6}$–$10^{-9}$ 量级）。FEN 的计算时间低于 ELM，因为 cos/sin 导数解析形式简单。

6. **激活函数的关键作用**：在非线性 Helmholtz 方程中，tanh 激活的 ELM 明显优于 sigmoid/swish 激活的 ELM，但仍不及 FEN。这显示激活函数的选择对随机化神经网络求解 PDE 至关重要。

## 7. 优点

- **简单而有效**：FEN 仅将 ELM 的激活函数替换为三角函数，架构仍是单隐层，避免了域分解、数值积分、额外隐藏层等复杂性增加。
- **理论支撑**：给出了近似误差理论保证（定理 3.3–3.5），并证明了最优缩放因子的存在性（定理 3.2）。
- **计算效率高**：无迭代训练；导数可用解析形式计算，无需自动微分；高维问题计算时间很短。
- **公平对比设计**：通过缩放因子搜索使各方法在最优配置下对比，较为公平。
- **实验覆盖广泛**：从简单函数逼近到非线性、高频、高维 PDE，场景多样性高；且与 FEM 对比体现了 FEN 的显著优势。

## 8. 不足与局限

- **对缩放因子非常敏感**：网络精度高度依赖缩放因子 $\rho$ 的选择；若范围或步长选取不当，难以获得高精度解。作者在结论中也承认这一点，并建议未来研究更高效的 $\rho$ 搜索方法。
- **高维性能瓶颈**：$d=10, 15$ 时 FEN 与 ELM 的精度差距明显缩小，误差退化为 $10^{-5}$–$10^{-6}$ 量级，表明 FEN 尚不能实质解决维度灾难问题。
- **对陡峭/大梯度解精度下降**：Burgers 方程实验中 FEN 的误差也达到 $10^{-4}$ 量级，远高于其他问题，表明对局部剧烈变化的函数，FEN 的表示能力受限。
- **对比范围有限**：未与 RFM、RNN-PG、HLConcELM、PINN 等主流方法进行系统对比，结论的说服力有一定局限。
- **理论分析有待深化**：作者仅给出了关于 $\cos$ 基的近似误差理论；三角函数优于 sigmoid/tanh/swish 的频域优势尚未得到严格理论解释（作者在结论中承认是未来工作）。
- **实验数据可复现性细节不完整**：训练/测试集相同（同源数据评估），对泛化能力的评估可能偏乐观；随机初始化时仅跑单次实验，未报告多次随机运行的标准差或置信区间。
