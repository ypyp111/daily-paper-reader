## 摘要
基于梯度的贝叶斯推断方法需要高效访问高维正演模型的雅可比算子和伴随雅可比算子。虽然多重网格求解器为椭圆型偏微分方程提供了接近最优的复杂度，但它们很少以与自动微分（AD）兼容的形式提供。我们为稳态扩散-吸收问题开发了一种可微分的多重网格求解器，并通过完整的多重网格层次结构解析地推导了其伴随操作。所得到的求解器DMGS采用C++实现，并与JAX接口相连，以为NIFTy框架中的变分推断提供高效的雅可比-向量和向量-雅可比乘积。我们在一项涉及组织中漫射辐射传输的三维反问题中验证了该方法，从蒙特卡洛模拟数据中重建有效的辐射源。重建结果以约化卡方为1.1重现了数据，并推广到32个独立的验证数据集。与JAX原生的多重网格实现相比，基准测试显示手推伴随的运行时间相当，且峰值内存持续更低，反向模式开销适度。这些结果确立了可微分多重网格求解器作为偏微分方程约束问题中变分推断的实用构建模块。

## Abstract
Gradient-based Bayesian inference methods require efficient access to Jacobian and adjoint-Jacobian operators of high-dimensional forward models. While multigrid solvers provide near-optimal complexity for elliptic partial differential equations, they are rarely available in forms compatible with automatic differentiation (AD). We develop a differentiable multigrid solver for steady-state diffusion-absorption problems and derive its adjoint operations analytically through the full multigrid hierarchy. The resulting solver, DMGS, is implemented in C++ and interfaced with JAX to provide efficient Jacobian-vector and vector-Jacobian products for variational inference in the NIFTy framework. We validate the approach on a 3D inverse problem involving diffuse radiative transfer in tissue, reconstructing an effective radiative source from Monte Carlo-simulated data. The reconstruction reproduces the data at a reduced chi-squared of 1.1 and generalizes to 32 independent validation datasets. Benchmarks against a JAX-native multigrid implementation show comparable runtimes and consistently lower peak memory for the hand-derived adjoint, with modest reverse-mode overhead. These results establish differentiable multigrid solvers as practical building blocks for variational inference in PDE-constrained problems.

## 2. 论文提出的方法论

### 2.1 核心思想
将多重网格求解器抽象为一系列线性操作 g1, g2, …, gl 的复合映射：

- **正演模式**：S = gl ◦ gl−1 ◦ ··· ◦ g1，即对源项 q 求解（Lρ = q 中的 ρ = S(q)）。
- **反向模式**：S† = ḡ1 ◦ ḡ2 ◦ ··· ◦ ḡl，即按相反顺序应用各操作，得到伴随映射 S†(ρ̄) = q̄。

关键在于：由于求解器对 q 是线性的（固定光学系数、固定边界条件、固定MG调度），**雅可比矩阵就是求解器本身**（J = S），JVP可直接通过S实现；而VJP（S†）则需要逐层解析推导各组件算子（RB-GS、缺陷、限制/延拓）的伴随形式。

### 2.2 关键技术细节

**（1）物理模型**：稳态扩散-吸收方程

```
Lρ = (−∇·(D·∇) + λ)ρ = q
```

- ρ：辐射通量（fluence）；q：辐射源；D：空间变化的各向同性扩散系数；λ：吸收系数。
- 用二阶有限差分离散化（沿用PICARD求解器的离散形式）。

**（2）多重网格结构**：
- 多层笛卡尔网格（finest level 0 → coarsest level nlev−1），网格间距逐层加倍。
- 使用**Red–Black Gauss–Seidel (RB-GS) 平滑器**、全加权限制算子（full-weighting restriction R）、以及与之匹配的延拓算子（I = 2n R†）。
- V-cycle 固定执行 **15 次**，保证正向与反向模式调用匹配、基准测试确定性。

**（3）伴随算子推导（一维形式示意）**：

- **RB-GS 伴随**：
  - ρ̄k(xi) = Lki [ρ̄k(xi−1)/Lki−1 + ρ̄k(xi+1)/Lki+1]
  - q̄k(xi) = −ρ̄k(xi)/Lki
- **缺陷操作（Defect）伴随**：
  - ρ̄k(xi) = Lki [ēk(xi) − ēk(xi−1) − ēk(xi+1)]
  - q̄k(xi) = ēk(xi)
- **传输算子伴随**：I† = 2n R，R† = 2−n I（对全加权限制算子成立）。

**（4）实现细节**：

- C++ 实现核心求解器与手推伴随算子。
- 通过 **JAXbind** 库封装为JAX外源算子（custom JAX primitive），暴露JVP和VJP接口。
- 集成至 **NIFTy.re** 的MGVI和geoVI变分推断流水线。
- 伴随计算采用固定V-cycle次数的模式（15次），避免正向/反向模式不一致。

## 3. 实验设计

### 3.1 物理场景与数据集

- **应用背景**：光声成像（optoacoustic imaging）中的漫射辐射传输问题。在扩散占主导的近似条件下（λa ≪ λs），扩散-吸收方程近似辐射传输方程，目标是从观测数据中重建**有效辐射源 q**。
- **主数据集**：由蒙特卡洛（MC）辐射传输模拟生成，空间域为 (7.5 × 3.5 × 3.5) cm³，原始分辨率 (512, 256, 256)。重建时三线性插值至 **（128, 64, 64）** 网格，并添加与体素相关的Gaussian噪声：

  ```
  σi = max(0.05 Le,i, 0.01 maxj Le,j)
  ```

- **数据掩码**：由于扩散近似在外部弹道占优区域和Dirichlet边界附近失效，数据边缘 **0.2 cm深度** 被掩码，不参与拟合。

### 3.2 正演模型与先验

- **正演模型**：R(q) = M(λ S(q))，即源→DMGS求解通量→乘λ得到吸收能量密度Le→掩码选择未掩码体素。
- **先验模型**：源分布由 3D 解析剖面（2D高斯基 × 深度方向上两个Logistic函数的差）乘以指数化的相关高斯场扰动构成。所有先验参数（归一化常数、中心、宽度、陡度、场振幅、核参数等）分配log-normal先验并联合推断。

### 3.3 Benchmark与对比

- **对比对象**：DMGS（手写伴随，C++实现） vs JMGS（纯JAX原生实现，依赖自动微分）。
- **基准维度**：2D（网格点数 2^19 至 2^26）和3D（至 2^28）。
- **评估模式**：Solve（直接求解）、JVP（前向模式）、VJP（反向模式）。
- **硬件环境**：双路 Intel Xeon 8358（Ice Lake）32核CPU，JAX 0.9.0，float64精度，JIT编译时间不纳入计时。每组配置重复 **20次**。
- **统计指标**：峰值驻留内存（RSS）与运行时间。

### 3.4 验证实验

- **主数据重建**：约化卡方 χ² ≈ 1.1。
- **泛化验证**：额外生成 **32个独立验证数据集**，光学系数（λa、λs）由不同的高斯随机场实现生成，使用与主数据相同的分辨率、网格规格、外部光源。逐一对比预测的Le与MC参考值的体素级RMSE。

- **填补真实空白**：首次将具有显式伴随算子的多重网格求解器集成到基于度量的变分推断框架（NIFTy/MGVI/geoVI）中，打通了"高效PDE求解器—可微编程—贝叶斯推断"的链条。

- **开源生态友好**：通过JAXbind绑定JAX，可融入现代概率编程生态。

## 8. 不足与局限

- **前向模型局限**：扩散-吸收方程仅适用于散射远强于吸收（λa ≪ λs）的介质。Dataset 17的失败案例表明，在高吸收界面附近扩散近似失效时，重建误差显著（归一化残差可达0.2以上）。这限制了方法在复杂介质（强吸收、弹道占优区域）中的适用性。

- **边界效应系统性偏差**：Dirichlet边界条件和掩码区域的设置使有效源被推向边界附近以补偿未建模的贡献，可能引入系统性偏差。
- **GPU与大规模扩展未验证**：论文明确将“GPU加速的更大3D运行”列为未来工作，目前仅展示了CPU上的中规模实验。
- **不确定性量化可能不够充分**：仅8个后验样本，且MGVI/geoVI本身是近似推断，所报1σ不确定性区间可能低估真实后验不确定性。
- **缺少可重复性细节**：蒙特卡洛模拟软件/参数细节、JAX-native MG实现（JMGS）的具体结构未详细介绍（称在后续论文中），增加了复现难度。
