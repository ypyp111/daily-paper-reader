## 摘要
可复用技能封装了解决现实世界专业任务所需的过程性知识，为基于LLM的智能体提供了一条在专家领域实现自我进化的路径。现有的自我进化技能方法从模型的参数化知识或轨迹中内部构建技能，因此受到模型已知知识的限制。然而，专业技能背后的领域惯例和标准流程往往超出这一边界，且难以仅从智能体自身引出。为解决这一问题，我们提出了一种新框架Search2Skill，它能够自动识别智能体的能力缺口，搜索外部资源以弥补这些缺口，并将检索到的证据提炼为结构化、可复用的技能。具体而言，Search2Skill通过基于量规的强化学习方案进行优化，该方案共同改进何时搜索、如何搜索以及如何生成技能。在来自三个基准的八个专家级领域上的实验表明，在流式（streaming）和保留（held-out）两种评估协议下，Search2Skill始终优于搜索增强和基于轨迹的技能学习基线。进一步分析表明，性能提升源于技能抽象而非原始检索证据，并且所获得的技能可跨模型规模迁移。

## Abstract
Reusable skills, which encapsulate the procedural knowledge required to solve real-world professional tasks, offer LLM-based agents a path toward self-evolution in expert domains. Existing self-evolving skill methods construct skills internally from the model's parametric knowledge or trajectories, and are therefore bounded by what the model already knows. However, the domain conventions and standard procedures underlying professional skills often lie beyond this boundary and are hard to elicit from the agent alone. To address this issue, we therefore propose a novel framework, Search2Skill, that automatically identifies the agent's capability gaps, searches external sources to address them, and distills the retrieved evidence into structured, reusable skills. Specifically, Search2Skill is optimized by a rubric-based reinforcement learning scheme that jointly improves when to search, how to search, and how to generate skills. Experiments on eight expert-level domains from three benchmarks show that Search2Skill consistently outperforms both search-augmented and trajectory-based skill-learning baselines under both streaming and held-out evaluation protocols. Further analyses show that the gains arise from skill abstraction rather than raw retrieved evidence, and that the acquired skills transfer across model scales.

然而，现有自进化技能学习方法（如 Trace2Skill、ReasoningBank 等）存在根本性局限——**它们是"向内看"的**：

- 仅从模型自身的参数知识或执行轨迹中归纳技能
- 因此被模型已有的知识边界（knowledge boundary）所束缚
- 无法获取专业领域中的惯例（conventions）、标准流程（standard procedures）和专家实践经验——这些往往恰恰落在模型知识边界之外

- **自我认知缺口蕴含着巨大的提升空间**：若将"已触发探索且正确诊断出缺失能力"的问题计入上界，Qwen3 各规模模型的平均执行准确率尚存 **14.3% 的提升空间**，缩小该缺口可使 14B/32B 模型逼近甚至超越 235B 模型

## 二、方法论

### 2.1 核心思想

提出 **Search2Skill 框架**，在"能力缺口识别 → 外部搜索 → 技能蒸馏"之间构建闭环：

- 智能体先用参数知识与技能库推理
- 识别到能力缺口后进入探索状态，形成目标化查询
- 从外部来源收集证据，并将其蒸馏为结构化技能写回技能库
- 技能既服务当前问题，也服务未来相关问题

### 2.2 任务形式化

将自进化技能获取形式化为元组 `(q, M)`：q 为输入问题，M 为持久技能库。智能体的交互轨迹为：

```
τ = (o₁, r₁, a₁, o₂, r₂, a₂, ..., o_T, r_T, a_T)
```

动作空间包含三类核心决策：
1. **搜索动作**：搜索/访问网页，在识别到能力缺口时调用
2. **技能生成动作**：将检索证据蒸馏为结构化技能 s，更新库 M ← M ∪ {s}
3. **最终回答动作**：终止回合

### 2.3 基于量规的强化学习（Rubric-Based RL）

针对 GRPO 仅依赖最终结果奖励、缺乏对中间决策细粒度监督的缺陷，设计了三种量规奖励：

| 奖励项 | 监督对象 | 核心机制 |
|--------|---------|---------|
| R_when | 何时搜索 | 组对比门控：在 rollout 组内比较探索子集与直接回答子集的准确率差 Δ，仅当 Δ > τ₀（探索明显更优）时，探索轨迹才获得质量奖励资格 |
| R_search | 如何搜索 | LLM 法官按两个维度评判查询质量：查询抽象度（针对可复用原理而非实例细节）、证据增益（检索内容是否解决关键不确定性）；差查询产生惩罚项 p_q ∈ [0, 0.3] |
| R_skill | 如何生成技能 | 双重评分：复用度 s_reuse（冻结骨干在相似问题上使用技能前后准确率增益）+ 接地性 s_ground（技能是否忠实于检索证据而非幻觉） |

**统一决策奖励公式**：

```
sc(τ) = q(τ)  (Δ > τ₀ 且 τ ∈ G_exp)
        1      (Δ < −τ₀ 且 τ ∈ G_direct)
        0      (其他情况)

q(τ) = max(0, ½(s_reuse + s_ground) − p_q(τ))
```

**最终奖励**：
```
R(τ) = clip[0,1]( λa·R_base + λc·sc(τ) )
```
其中 λa = 0.7，λc = 0.3。通过门控机制自然校准探索决策，避免鼓励无差别搜索。

### 2.4 训练流程

1. **SFT 冷启动**：用 DeepSeek-V3.2 和 GLM-5 教师模型在开源问题上执行完整智能体循环，拒绝采样保留 8K 条验证正确的轨迹
2. **GRPO 强化学习**：在 2K 条过滤后的高质量问题上训练，覆盖物理、化学、金融、商业、经济五个领域

## 六、主要结论与发现

1. **外部搜索是突破知识边界的关键**：仅靠内部轨迹蒸馏无法获得专业领域所需的惯例和标准流程，向外搜索能将"之前不可解的任务"变为"已解决的任务"
2. **三种决策需要联合优化**："何时搜索、如何搜索、如何生成技能"三个维度缺一不可，仅靠任务成功奖励（GRPO）无法解决信用分配问题
3. **增益来自技能抽象而非原始证据**：直接缓存检索内容仅带来 +1.8% 提升，而将其抽象为可复用技能带来 +6.3%（4.5% 的抽象增益）
4. **技能可跨模型规模迁移**：技能编码的是可复用的程序性知识而非模型特定行为，小模型能够借助外部技能库匹敌甚至超越更大规模模型
5. **RL 修复了全流水线而非单一环节**：5 种失败模式的占比在 RL 训练后均有下降

## 七、优点

- **问题定位精准**：识破了自进化技能学习"向内看"的根本局限，提出"向外看"的新视角，动机充分且用预实验数据支撑
- **奖励设计精细**：量规式 RL 通过组对比门控避免了无差别搜索的激励偏移；质量奖励被门控在"已验证能力缺口"之后，设计巧妙
- **技能评估多元**：s_reuse 用冻结骨干在相似问题上的准确率增益衡量泛化性，s_ground 用声明级审计衡量忠实性，两个维度互补
- **评估协议完备**：流式（持续积累）与保留（固有可复用性）两种协议互补，前者贴近现实使用、后者剥离搜索干扰直接检验技能质量
- **分析层层递进**：从最终准确率 → 失败模式分解 → 效率曲线 → 奖励贡献 → 跨模型迁移，回答"为什么有效"而非止步于"是否有效"
- **工程细节扎实**：原始问题屏蔽机制有效防止测试集泄漏，实现层面考虑周全

## 八、不足与局限

- **基准覆盖局限**：全部基准均为多选 QA/答案式任务，未覆盖多步骤交互型任务（如具身智能、代码执行环境；EvoAgentBench 的 sandbox splits 被排除），因此"自我进化"的边界仅体现在知识填充层面，未触及更复杂的技能组合与规划能力
- **训练-评估域不完全对齐**：训练数据集中于物理、化学、金融等 5 个领域，评估域部分重叠，可能存在一定程度的域偏置

- **搜索策略相对基础**：查询生成、页面选择较为直接，未涉及高级搜索策略（如多轮查询规划、跨源交叉验证）

- **训练-评估规模有限**：RL 训练仅基于 2K 条锚点问题，技能库容量上限 300 条且无长期压缩机制，对于大规模、长时程持续进化的效果尚未得到验证
- **结论主要面向知识密集型问答**：与论文宣称“自我进化”的宏大叙事相比，实验所覆盖的任务形态仍以单轮知识问答为主，技能组合、多步规划等更高级的智能行为未被纳入验证范围

## 九、总结与综合评价

Search2Skill 的核心贡献在于重新定义了自进化智能体的技能获取范式：从“向内看”的参数知识归纳，转向“向外看”的外部证据搜索与结构化蒸馏。这一视角转换直击现有自进化方法的根本局限——模型无法从自身知识边界之外获取专业领域真正需要的惯例与标准流程。论文通过精心设计的量规奖励机制，将“何时搜索、如何搜索、如何生成技能”三个决策维度联合优化，并通过两种互补的评估协议、多组消融实验与跨模型迁移验证，较为完整地证明了该方法在突破知识边界、积累可复用技能方面的有效性。

尽管存在基准覆盖类型单一、技能库管理策略简单、依赖 LLM 法官等不足，该工作在问题定位的精准性、方法论设计的自洽性、实验分析的层层递进性方面均展现了较高的成熟度，是“智能体通过外部世界自我进化”这一方向上具有代表性的研究，也为后续工作探索更复杂的技能库管理机制、更广泛的交互任务类型以及更高效的技能评估手段提供了清晰的切入点。
