## 摘要
实时预测和控制数字孪生需要快速的数据同化。对于许多物理系统，数据同化任务需要求解受物理约束的逆问题，而使用传统物理求解器通常难以实时计算。本研究提出了一种基于降基神经算子的方法，以实现数字孪生环境中的实时逆问题求解。我们的方法特别针对一大类由偏微分方程（PDE）控制的时空动力学问题，这些方程相对于模型参数$m$是非线性的，而相对于反演参数$q$是线性的。基于这种物理结构，我们的神经算子在降维子空间中逼近从模型参数$m$到参数-观测算子$\mathcal{F}(m)$的非线性映射。由于神经算子的输出是参数-观测算子本身（以矩阵形式体现），我们将该方法称为神经矩阵算子（NEMO）。对于新给定的$m$，NEMO使得我们能够在降维子空间中以闭式形式求解$q$的逆问题。我们将NEMO应用于两个实际场景：污染物输运初始条件识别和高超声速飞行器载荷识别。结果表明，NEMO能够实时提供高质量的数据同化逆问题解，与使用PDE求解器构建降维算子相比，加速超过三个数量级。此外，NEMO在逆问题求解性能上与最先进的多输入神经算子相当，同时将在线计算复杂度降低了一个数量级以上，并提供实时不确定性量化。

## Abstract
Rapid data assimilation is required for real-time prediction and control in digital twins. For many physical systems, the data assimilation task requires the solution of a physics-constrained inverse problem, which is often computationally intractable in real time using traditional physics solvers. This work presents a reduced-basis neural operator approach to enable real-time inverse problem solutions in the digital twin setting. Our approach specifically targets the large class of problems with spatiotemporal dynamics governed by partial differential equations (PDEs) that are parameterized nonlinearly with respect to model parameters $m$, and linearly with respect to inversion parameters $q$. Based on this physical structure, our neural operator approximates the nonlinear map from the model parameters $m$ to the parameter-to-observable operator $\mathcal{F}(m)$ in a reduced subspace. Since the output of the neural operator is the parameter-to-observable operator itself (manifested as a matrix), we refer to this approach as NEural Matrix Operator (NEMO). With NEMO, for new given $m$, we enable a closed-form inverse problem solution for $q$ in a reduced subspace. We apply NEMO in two real-world applications: contaminant transport initial condition identification, and hypersonic vehicle load identification. We show that NEMO delivers high quality inverse problem solutions for data assimilation in real time, with over three orders of magnitude speedup compared to constructing the reduced operator with the PDE solver. Further, NEMO demonstrates comparable inverse performance to a state-of-the-art multiple-input neural operator, while reducing online computational complexity by over an order of magnitude and providing real-time uncertainty quantification.

- **问题结构假设**：论文聚焦于一大类PDE系统，其控制方程相对于模型参数 \(m\)（如风速场、温度场）为非线性参数化，而相对于反演参数 \(q\)（未知源/初值/边界条件）为线性。这一结构使得参数到观测（p2o）算子在给定 \(m\) 后对 \(q\) 呈线性映射，从而逆问题在固定 \(m\) 下退化为线性最小二乘问题。
- **核心创新含义**：现有神经算子方法要么作为前向替代模型并要求在线求解非线性优化（有收敛风险、成本高），要么直接学习逆映射（不利用物理结构、缺乏泛化与可解释性）。本文提出的神经矩阵算子（NEMO）通过直接学习 \(m \mapsto \mathcal{F}(m)\) 的降维算子映射，保留物理线性结构，使得逆问题存在**闭式最小二乘解**，实现真正的实时反演。

### 2. 方法论

**（1）逆问题数学形式**
- 逆问题定义为带正则化的加权最小二乘问题：
  \[
  \min_{q} \frac{1}{2}\|\mathcal{F}(m)q - d\|_{\Gamma^{-1}}^2 + \frac{\gamma}{2}\|q\|_{\mathcal{Q}}^2
  \]
  其中状态方程 \(\mathcal{A}(m)u = Cq\)，参数到观测算子 \(\mathcal{F}(m) = \mathcal{B}\mathcal{A}^{-1}(m)C\)。
- 给定观测噪声 \(d = \mathcal{F}(m)q + \epsilon\)（\(\epsilon \sim \mathcal{N}(0, \Gamma)\)），精确解以闭式表达：
  \[
  q^* = [\mathcal{F}(m)^*\Gamma^{-1}\mathcal{F}(m) + \gamma I]^{-1}\mathcal{F}(m)^*\Gamma^{-1}d
  \]
- 直接用PDE求解器计算 \(\mathcal{F}(m)\) 极为昂贵，因每次算子作用都需求解一次PDE。

**（2）NEMO核心思想**
- NEMO的核心是学习映射 \(m \mapsto \mathcal{F}(m)\)，但输出不是向量或函数值，而是**线性算子的降维矩阵表示**。
- 采用标准正交基对 \(q\) 和 \(m\) 做截断展开（POD/PCA/KL展开）：
  - \(q_r = \Phi_r \Phi_r^* q\)，系数 \(q_r \in \mathbb{R}^{r_q}\)；
  - \(m_r = \Psi_r \Psi_r^* m\)，系数 \(m_r \in \mathbb{R}^{r_m}\)。
- 构造全连接神经网络 \(F_\theta: \mathbb{R}^{r_m} \to \mathbb{R}^{d \times r_q}\)，训练目标为最小化期望Frobenius范数误差：
  \[
  \min_{\theta} \mathbb{E}_{m\sim\mu} \left[\|F_\theta(\Psi_r^* m) - \mathcal{F}(m)\Phi_r\|_F^2\right]
  \]
  输出为截断系数矩阵，即“矩阵算子”。
- 神经网络训练数据来自：对 \(m\) 采样 → 用PDE求解器计算 \(\mathcal{F}(m)\Phi_r\)。

**（3）子空间逆问题与快速闭式解**
- 将反演限制在子空间 \(\text{span}(\Phi_r)\) 中，降维正规方程为：
  \[
  q_r^\ddagger = [F_\theta(\Psi_r^* m)^*\Gamma^{-1}F_\theta(\Psi_r^* m) + \gamma I_r]^{-1}F_\theta(\Psi_r^* m)^*\Gamma^{-1}d
  \]
- 计算复杂度仅为 \(O(d r_q^2 + r_q^3)\)，与Q的离散维度无关，适合边缘计算和实时部署。
- 理论保证（Theorem 2.1）：逆问题解的误差与NEMO算子逼近误差同阶；在光滑映射前提下，可实现与离散维度无关的近似收敛率 \(O(N^{-\alpha})\)。

**（4）不确定性量化**
- 将正则项解释为高斯先验时，子空间后验协方差有闭式表达：
  \[
  H_r^{-1} = [F_\theta^*\Gamma^{-1}F_\theta + \gamma I_r]^{-1}
  \]
  可实时计算并借助 \(\Phi_r\) 提升到原空间，支持概率分析和风险感知决策。

### 7. 优点

- **物理结构保持**：显式利用"\(m\) 非线性、\(q\) 线性"的PDE结构，输出为矩阵算子而非函数值，保留了逆问题的线性最小二乘闭式解，具有可解释性。
- **实质性实时性**：计算复杂度 \(O(dr_q^2 + r_q^3)\) 与PDE网格自由度无关，非常契合边缘计算/实时控制场景。
- **理论完备性**：包含一致性定理、误差传播界、无限维光滑映射下的维度无关近似率证明，兼有概率测度下算子约简误差分析。
- **降维与正则化协同**：子空间结构本身即为一种正则化（截断SVD思想），与L-curve等正则化选择方法兼容。
- **闭式不确定性量化**：无需MCMC或变分采样即可获得后验协方差，这是大多数神经算子方法不具备的能力。
- **实验结果清晰**：两个物理场景、多组训练数据量、多个噪声水平、多个正则化水平的系统对比，并展示可视化重建结果。

### 8. 不足与局限

- **应用范围受限**：方法依赖 \(q\) 在低维子空间中可被良好表示这一前提，即低秩/快速谱衰减假设。对于强双曲波动等问题（Kolmogorov n-width大），需非线性编码扩展，方法当前对此类问题的普适性不足。
- **模型参数 \(m\) 假设完备**：论文假设 \(m\) 由外部观测或天气预报等手段已知，未纳入 \(m\) 的不确定性及其对反演精度的影响（作者已指出此为未来工作）。
- **网络规模对输出维度敏感**：NEMO输出维度为 \(d \times r_q\)，对于高时间频率的大量观测或高维 \(r_q\)，单一全连接网络可能变得很大，需更复杂架构。
- **训练数据生成成本高**：生成训练数据需要对每个 \(m\) 样本求解 \(r_q\) 个PDE右端项，初始离线训练成本较大；论文未讨论该成本在实际场景中的可行性细节。
