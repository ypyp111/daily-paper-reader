## 摘要
大型语言模型（LLMs）使得AI科学家系统能够自动化科学发现，然而现有方法大多依赖静态提示或固定工作流，无法积累经验以实现持续改进。我们提出HypoForge，一个经验引导的多智能体框架，通过学习可复用的科学技能来实现自动化假设生成与假设测试。HypoForge基于两个阶段涉及不同监督信号的观察而构建。对于假设生成阶段（该阶段缺乏显式反馈），HypoForge采用对抗式生成器-判别器机制，通过比较性批判来改进推理。对于假设测试阶段（该阶段可获得经验反馈），HypoForge从执行结果和真实结果中学习测试技能。通过将技能学习策略与阶段特定的监督信号相匹配，HypoForge在无需微调基础模型的情况下实现了持续改进。在假设生成和测试基准上的实验表明，HypoForge始终优于现有的AI科学家框架和技能级变体。进一步分析证明了所提出的阶段特定技能学习范式的有效性。

## Abstract
Large language models (LLMs) have enabled AI scientist systems to automate scientific discovery, yet existing approaches most rely on static prompting or fixed workflows and fail to accumulate experience for continual improvement. We propose HypoForge, an experience-guided multi-agent framework that learns reusable scientific skills for automated hypothesis generation and hypothesis testing. HypoForge is built on the observation that these two stages involve different supervision signals. For hypothesis generation, where explicit feedback is unavailable, HypoForge adopts an adversarial generator--discriminator mechanism to improve reasoning through comparative critique. For hypothesis testing, where empirical feedback is available, HypoForge learns testing skills from execution outcomes and ground-truth results. By matching skill learning strategies with stage-specific supervision, HypoForge enables continual improvement without fine-tuning foundation models. Experiments on hypothesis generation and testing benchmarks show that HypoForge consistently outperforms existing AI scientist frameworks and skill-level variants. Further analysis demonstrates the effectiveness of the proposed stage-specific skill learning paradigms.

## 2. 方法论

### 核心思想

HypoForge建立在两个关键观察之上：

1. **假设生成与假设测试具有本质不同的监督信号**：

### 总体架构

HypoForge是一个由多种智能体组成的协作系统，核心流程如下：
- **输入**：研究问题（P）+ 数据源（D）

### 阶段一：对抗式假设生成（Adversarial Hypothesis Generation）

**灵感来源**：借鉴生成对抗网络（GANs）的对抗学习思想，将假设生成建模为对抗性技能学习问题。

**核心组件**：
1. **假设生成器（Generator）**：根据研究问题、数据源和当前技能状态，批量生成候选假设。每个假设被表示为结构化科学声明，描述变量间可检验关系及其预期方向。
2. **多维假设判别器（Multi-Dimensional Discriminator）**：与传统GAN的二元判别器不同，它被设计为**多维评分函数**，评估假设分布与人类高质量科学假设特征的接近程度。

**七维判别标准**（公式4-5）：
- D₁ ∈ [0,1]：经验基础（Empirical grounding）
- D₂ ∈ [0,1]：因果合理性（Causal plausibility）
- D₃ ∈ {0,1}：可证伪性（Falsifiability，硬约束）
- D₄ ∈ {0,1}：理论一致性（Theoretical consistency，硬约束）
- D₅ ∈ [0,1]：结构清晰性（Structural clarity）
- D₆ ∈ [0,1]：科学新颖性（Scientific novelty）
- D₇ ∈ {0,1}：经验可验证性（Empirical verifiability，硬约束）

综合评分为：s_i = D₃D₄D₇ × (D₁D₂D₅D₆)^(1/4)

**关键机制**：
- **分布级优化**（而非实例级优化）：判别器评估整个假设集合的质量：
  Q(H_t) = (1/N) Σ s_i

- **技能蒸馏**（公式9）：判别器将生成的假设集的优势与不足，连同累积经验，蒸馏为可复用的程序性知识，更新生成技能：
  S^{h}_{t+1} = Distill(S^h_t, H_t, Q(H_t), C(H_t))
- **生成器目标**（公式8）：最大化整体科学质量分数 max L_G = Q(H_t)

**核心优势**：相比逐项修订的Reviewer/Critic多智能体框架，HypoForge在**分布层面**进行优化，学到的技能捕捉的是可迁移的生成策略（变量选择、因果推理、假设构建、常见失败规避），而非针对特定假设的改进。

### 阶段二：经验引导的假设测试（Experience-Guided Hypothesis Testing）

**核心观察**：与假设生成不同，假设测试提供明确的显式监督——真实结果（ground-truth outcomes），允许评估完整测试轨迹。

### 方法上的亮点

1. **阶段特定监督信号匹配的精细设计**：论文抓住了假设生成（无显式反馈）和假设测试（有经验反馈）的监督本质差异，为不同阶段设计不同的技能学习范式，这比统一的“经验-反馈”提炼方法更合理、更有效。

2. **对抗式生成器-判别器的创造性应用**：将GAN的精髓（对抗与分布匹配）引入假设生成，但改进了两个关键点：
   - 用多维评分函数替代二元分类器，使得判别更具科学性
   - 用LLM蒸馏的**可读、可迁移技能**替代基于梯度的隐式参数更新，提高了技能的透明性和可复用性

3. **分布级而非实例级的反馈机制**：相比逐项修订型的Critic框架，分布级优化使得学到的技能更泛化，避免假设特定的纠正，从而带来跨任务的迁移能力。

4. **无需微调的实现路径**：在不改动底层基础模型的前提下实现持续改进，使得方法在计算资源受限环境下更可行，且基础模型升级后可兼容迁移。

5. **完整的发现循环整合**：将假设生成与测试整合进统一发现流程，突破了现有系统阶段割裂的局限。

### 实验上的亮点
- 同时比较系统级和技能级基线，形成了多层次验证
- 特别关注了“执行成功但科学无效”的陷阱（对比POPPER时指出），评估指标选取具有洞察力
- 提供技能学习进化曲线，直观展示学习过程而非仅展示终点结果
