## 摘要
大型语言模型（LLM）智能体在科学研究中越来越多地被用于组织和调用专业计算工具。然而，它们对具有静态语义的预定义工具空间的依赖，限制了其在开放世界科学工作流中的适用性，因为这些工作流中的工具需求、能力和边界是动态演化的。为此，我们提出了SciToolAgent-Evo，一种用于开放世界科学工具获取的本体感知自进化智能体。它由不断演化的技能、经验记忆和本体化工具图驱动，在累积过程中从对比轨迹中提炼可泛化知识，而在推理过程中则制定主动请求，并利用基于LinUCB的臂控门控机制动态平衡探索与利用。一旦获取到新工具，其科学本体将在线完善，以无缝集成到已知图中。此外，我们引入了OpenSciToolBench，一个包含四个难度级别共900个真实任务的基准。大量评估表明，SciToolAgent-Evo实现了最先进的性能，验证了其鲁棒性和泛化能力。

## Abstract
Large language model (LLM) agents have been increasingly adopted in scientific research for organizing and invoking specialized computational tools. However, their reliance on predefined tool spaces with static semantics limits their applicability to open-world scientific workflows, where tool requirements, capabilities, and boundaries evolve dynamically. To this end, we propose SciToolAgent-Evo, an ontology-aware self-evolving agent for open-world scientific tool acquisition. Driven by an evolving memory of skills, experiences, and an ontologized tool graph, it distills generalizable knowledge from contrastive trajectories during accumulation, whereas during inference, it formulates active requests and utilizes a LinUCB-based bandit gate to dynamically balance exploration and exploitation. Once a novel tool is acquired, its scientific ontology is completed online for seamless integration into the known graph. Moreover, we introduce OpenSciToolBench, a benchmark containing 900 realistic tasks across four difficulty levels. Extensive evaluations show that SciToolAgent-Evo achieves state-of-the-art performance, validating its robustness and generalization.

## 2. 论文提出的方法论（核心思想、关键技术细节、算法流程）

### 2.1 核心思想

- 提出 **SciToolAgent-Evo**，一种**本体感知的自进化智能体**，通过构建"进化记忆"（skill library + experience pool + 本体化工具图）实现工具知识的持续积累与复用。
- 采用两阶段设计：**知识累积阶段**（离线）与**本体感知推理阶段**（在线），形成闭环自进化。

### 2.2 关键的四大组件定义

1. **本体（Ontology）** `o_t = (b_t, h_t)`：刻画工具语义、调用约束与科学适用场景。已知工具拥有完整本体；未知工具初始只暴露最小基本属性。
2. **技能（Skill）** `k_i = (N_i, Z_i, E_i)`：任务级工具链指导单元，提供可泛化的任务工作流。
3. **经验（Experience）** `e = (d_e, s_e, a_e, h_e)`：非参数化提示，提供细粒度工具选择指导，包含领域、适用情境、工具选择建议和检索嵌入。
4. **臂控门控（Bandit Gate）**：基于 **LinUCB** 的决策模块，平衡开放世界的探索–利用权衡，其4维上下文向量 `x_j = [f_j, m_j, s_j, p_j]^T` 分别表示 top-1 已知工具可行性、top-2 候选置信度差、本体对齐分数、未知工具探索历史先验。

### 2.3 算法流程

**阶段一：知识累积（Knowledge Accumulation）**
- 对每个训练任务先生成确定性基线轨迹（T=0）；若失败则以不同温度（0.2/0.5/0.8）并行采样 3 个探索轨迹。
- 若探索轨迹成功，则与失败基线构造**对比轨迹对**，通过轨迹批判定位关键分歧点、诊断失败原因，蒸馏出**领域特定经验**与**通用经验**（用余弦相似度阈值实现去重）。
- 成功轨迹还被抽象为**可复用技能**存入技能库。整个过程无需更新 LLM 参数。

**阶段二：本体感知推理（Ontology-Aware Inference）**
1. **技能与任务路由**：先在技能库中匹配已有技能，命中则直接执行；否则根据期望工具数与实体数评估难度——简单任务用轻量 CoT，复杂任务进入主动工具获取流程。
2. **主动工具获取**：检索相关经验增强上下文，通过本体引导推理生成一组**主动工具请求** `R_q`（原子化的工具能力需求描述），将工具获取从昂贵的原始查询匹配转化为"需求条件化检索"。
3. **本体引导检索**：对每个请求 `r_j` 在已知工具图中进行 TopK 检索 + 子图扩展 + 组合重排，得到候选集 `C_j`。
4. **LinUCB 门控决策**：利用4维上下文向量，通过 `a_j = argmax_a(θ̂_a^T x_j + α√(x_j^T A_a^{-1} x_j))` 在利用已知工具与探索未知工具之间做动态决策；α 随失败率自适应缩放（初始0.8，衰减率0.01，最小值0.2，窗口动态调整至 [0.7, 1.3]）。
5. **知识更新**:工具链执行成功后，对用到的未知工具在线补全其科学本体并迁移入已知图；同时用执行结果更新 LinUCB 参数（`A_a ← A_a + x_j x_j^T, b_a ← b_a + r x_j`），并将成功轨迹蒸馏为新技能存入技能库——由此形成自进化闭环。

## 6. 论文的主要结论与发现

1. **SOTA 性能**：在 OpenSciToolBench 上，SciToolAgent-Evo 将总体答案准确率提升至 66.76%（GPT-5.4-mini）和 69.53%（Gemini-3-flash），较第二名分别高 **12.11** 和 **9.55** 个百分点；在 SciToolEval 上分别提升 **6.11** 和 **2.89** 个百分点。相比 SciToolAgent 优势达 17%~31%。
2. **复杂度越高的任务提升越明显**：Level-3 上超越 Reflexion 和 ReAct 达 20 和 30 个百分点。简洁的局部逐步推理方法（ReAct/Reflexion）在长工具链场景缺乏全局策略，开放工具空间中探索成本高、规划精度下降。
3. **各组件均不可缺失**：去除知识累积导致 14.87 点下降；未知工具迁移（持续整合）是最关键的模块；技能与经验两种知识形态各有不可替代的作用。
4. **鲁棒性**：即便 70% 工具初始未知，仍能达到 59.01% 的整体准确率，表明框架具备强开放世界适应能力。
5. **知识积累呈"快速起步、平滑增长"规律**：0%→25% 进度阶段收益最大，说明少量数据即可建立可靠的开放世界适应先验。
6. **跨域泛化能力**：在 m&m's 和 RestBench 上均取得最佳结果，证明方法可推广至更广泛的工具使用场景。

## 7. 优点

- **问题框架具有前瞻性**：将"静态工具选择"提升为"动态工具获取"，更贴合真实科学研究的开放性和不确定性。
