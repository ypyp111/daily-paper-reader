## 摘要
非局部偏微分方程在许多应用中广泛出现，但由于非局部算子的存在，其建模和学习通常较为困难。我们提出了一种流图学习（FML）框架，用于直接从解数据中学习未知的非局部PDE。该方法不学习或逼近底层非局部算子，而是在模态空间或节点空间中学习有限时间演化算子。针对谱方法和网格基解表示，我们开发了两种互补的公式。在一维和二维分数阶扩散及波动方程上的数值实验表明，仅使用较短的观测窗口即可实现准确且稳定的长时间预测。所提出的方法为学习未知的非局部动力学提供了一种有效的数据驱动框架，而无需显式评估非局部算子。

## Abstract
Nonlocal partial differential equations arise in many applications but are often difficult to model and learn because of the presence of nonlocal operators. We present a flow-map learning (FML) framework for modeling unknown nonlocal PDEs directly from solution data. Rather than learning or approximating the underlying nonlocal operators, the proposed approach learns the finite-time evolution operator in either modal or nodal space. Two complementary formulations are developed for spectral and grid-based solution representations. Numerical experiments on one- and two-dimensional fractional diffusion and wave equations demonstrate accurate and stable long-time prediction using only short observation windows. The proposed approach provides an effective data-driven framework for learning unknown nonlocal dynamics without explicit evaluation of nonlocal operators.

## 论文核心问题与整体含义

非局部偏微分方程（nonlocal PDEs）能够模拟长程相互作用和反常输运现象，在很多领域有重要应用，如反常扩散、近场动力学、多孔介质流等。然而这类方程在建模和学习上存在显著困难：

- 从物理第一性原理推导出精确的非局部控制方程往往不可行，因为涉及复杂的多尺度相互作用或不完整的物理知识；
- 即使控制方程已知，非局部算子（如分数阶拉普拉斯算子）通常包含奇异核或积分算子，数值评估和自动微分均较困难；
- 现有数据驱动方法（如稀疏回归、PINNs、分数阶PINNs、神经算子等）大多需要显式或隐式地表示/逼近非局部算子，或在训练过程中反复求值，从而增加了实现和计算难度。

本文的核心思路是**绕过对非局部算子的直接表示**，采用**流图学习（Flow Map Learning, FML）**框架，直接从解的时序快照中学习有限时间演化算子（flow map）。该方法不试图恢复控制方程，而是学习一个“输入当前解状态 → 输出 Δt 后解状态”的映射，然后通过递归应用该映射实现长期预测。

论文整体意义在于：提供了一种对未知非局部PDE系统进行数据驱动建模的新途径，无需显式构造、离散或评估非局部算子，从而避开了传统方法的瓶颈。

## 论文提出的方法论

### 核心思想

假设系统满足自治非局部PDE：

∂u/∂t = L(u), (x,t) ∈ Ω × R⁺

其中L未知。定义精确流图 E_Δt：u(·, t+Δt) = E_Δt(u(·, t))。FML的目标是利用观测数据直接近似该流图，而不是学习L本身。学习完成后，通过迭代应用近似流图实现长期预测。

### 两种互补的公式

#### 1. 模态空间 FML（Modal-space FML）

- **适用场景**：周期性边界问题，尤其是涉及分数阶拉普拉斯算子的情形。因为分数阶拉普拉斯在 Fourier 空间中表现为乘法算子，模态系数（Fourier 系数）是天然的表征。
- **表征方式**：选取有限维基函数空间 V_n = span{φ₁,…,φ_n}，通过投影算子将解表示为 u_n(x,t) = Σ v_j(t) φ_j(x)，其中 v(t) ∈ Rⁿ 为模态系数向量。
- **学习目标**：近似有限维模态流图 M_Δt : Rⁿ → Rⁿ，满足 v(t+Δt) = M_Δt(v(t))。
- **模型结构**：采用残差网络（ResNet），形式为 M̂_Δt = I_n + N(·; Θ)，其中 N 是全连接DNN。
- **训练数据**：将解快照投影得到模态系数序列，随机取连续样本对或长度 n_r 的连续子序列。
- **损失函数**：使用多步（roll-over）损失：对预测轨迹与真实轨迹的逐时间步均方误差求和，增强数值稳定性与精度。单步损失是多步损失的特例（n_r=1）。
- **预测**：对新初始条件 v₀，循环应用 M̂_Δt 得到所有预测时刻的模态系数，再通过系数到函数的映射Π重构空间解。

#### 2. 节点空间 FML（Nodal-space FML）

- **适用场景**：几何复杂、无法方便使用模态基函数的问题；直接处理空间网格上的解值向量 u(t) ∈ R^N。
- **表征方式**：半离散系统 du/dt = F(u)，一步精确演化可写为 u(t_{n+1}) = G_Δt(u(t_n))，其中 G_Δt 为节点流图。
- **模型结构**：同样采用残差形式，但残差部分使用“**拆解-组装网络**”（disassembly–assembly network），结构包括：
  - 拆解块（Disassembly block）：J 个并行全连接通道，每个通道把 N 维输入映射到 n_w 维；
  - 组装层（Assembly layer）：对拆解块的输出逐分量操作，将 J 维输入映射为标量，从而把 n_w × J 的中间张量压缩为 n_w 维向量；
  - 输出层（Output layer）：把 n_w 维向量映射回 N 维节点空间。
  - 该结构的动机来自非局部算子离散后可用多个微分矩阵 D_α 乘积表示，拆解-组装网络可模拟这种混合作用。
- **训练数据**：直接使用原始解快照序列，无需投影。
- **损失函数**：同样采用多步递归损失，比较模型迭代 ℓ 步输出与真实第 ℓ 步解。
- **优点**：训练过程中只使用解快照，完全不需构造分数阶微分矩阵或求值奇异积分。

## 实验设计

论文针对三类非局部PDE进行了测试，所有训练和验证数据均由已知控制方程生成（解析或高精度数值求解），仅用于评估FML模型性能。

### 实验 1：一维反常扩散方程

- 方程：∂u/∂t = −(−Δ)^{α/2}u，周期边界，α = 1.5。
- 空间离散：Fourier伪谱法，N_x = 51，时间精确积分，Δt = 0.05。
- 训练数据：N_train = 10⁵ 条序列，每条包含6个连续快照（对应5步递归预测），初始条件为随机Fourier级数（随机项数、随机系数）。
- 模型：
  - 节点FML：拆解-组装网络（J = 3, n_d = n_a = 1, n_w = 51）；
  - 模态FML：单块ResNet，6个隐层，每层50个神经元。
- 训练：五步递归损失，循环学习率（10⁻⁷ 到 10⁻³，指数衰减因子0.9999997），训练10,000 epochs，batch size 50。
- 验证：独立生成100个测试样本，用10个独立训练的模型预测500步（至T=25）。

### 实验 2：一维非局部波动方程

- 方程：u_tt = −D(−Δ)^{α/2}u，周期边界，α = 0.5, D = 1。
- 状态表示：z(t) = [u(t); u̇(t)] ∈ R^{2N_x}，N_x = 51。
- 训练数据：N_train = 10⁶ 序列；初始位移和速度由周期高斯随机场采样（协方差为高斯核），并加均匀随机平移。
- 节点FML：拆解-组装网络，输入为102维，J = 3, n_d = n_a = 1, n_w = 51，使用单步训练对。
- 模态FML：双块ResNet，每块3个隐层、每层40个神经元，五步递归损失。
- 验证：100个测试样本，10个独立模型，预测500步（T=25）。

### 实验 3：二维混合非局部扩散方程

- 方程：∂u/∂t = −c₁(−Δ)^{α/2}u − c₂(−Δ)^{β/2}u，周期边界，α=1.5, β=0.5, c₁=c₂=0.05。
- 空间离散：Fourier伪谱法，N_x = N_y = 80。
- 训练数据：N_train = 10⁶ 序列，每条6个快照，初始条件为随机二维三角级数。
- 节点FML：拆解-组装网络，J = 5, n_d = n_a = 2, n_w = 441。
- 模态FML：四块ResNet，每块3个隐层、每层50个神经元。
- 验证：100个测试样本，5个独立模型，预测1000步（T=50）。

### 参数恢复实验

作为额外验证，论文利用“模态FML”预测得到的模态轨迹，尝试恢复分数阶指数：

- 一维扩散：利用模态解满足 û(k,t) = û(k,0) e^{−|k|^α t} 对每个非零模态进行点态估计 α(t,k)，结果表明在早期与真值1.5接近，后期因模态振幅衰减趋于零而估计失真。
- 一维波动：由二阶ODE û_tt + c|k|^α û = 0，用中心差分离散二次导数并估计α，估计在较长时间内保持接近真值。
- 二维扩散：用MATLAB fit 对多个模态拟合（α, β），得到四组估计，因为c₁=c₂较小、衰减慢，估计可用时间窗口较长。

## 论文的主要结论与发现

1. FML框架能够有效地扩展到未知非局部PDE系统，无论是在模态空间还是节点空间，均可仅从短时间解快照中学习有限时间演化算子。
