## 摘要
预训练的偏微分方程（PDE）基础模型能够泛化到不同的方程，但将其适配到未见过的PDE系统通常需要密集的解数据，而这些数据往往成本高昂或难以获取。为解决这一局限，我们提出了一种基于无监督PDE的微调框架，消除了对真实解的需求。我们首先在涵盖不同空间尺度的多种时间相关PDE上预训练一个邻域注意力Transformer，从而在异构方程间产生可迁移的表征。在适配阶段，我们利用PDE残差和边界条件构建基于物理的目标函数，并通过低秩自适应（LoRA）在未见方程上微调模型。针对标准LoRA中物理量间学习不均衡的问题，我们引入了NSLoRA，一种牛顿-舒尔茨正交化变体，以重新平衡自适应。我们的方法在无需任何真实解的情况下，达到了与有监督LoRA微调相当的性能，同时在涵盖多个空间维度的异构PDE基准上，持续优于竞争性神经算子基线和近期PDE基础模型。

## Abstract
Pretrained partial differential equation (PDE) foundation models can generalize across different equations, but adapting them to unseen PDE systems typically requires dense solution data, which is often expensive or unavailable. To address this limitation, we propose an unsupervised PDE-based finetuning framework that eliminates the need for ground-truth solutions. We first pretrain a neighborhood attention Transformer on diverse time-dependent PDEs spanning varying spatial scales, yielding transferable representations across heterogeneous equations. In the adaptation stage, we construct a physics-based objective using the PDE residual and boundary conditions, and finetune the model on unseen equations via low-rank adaptation (LoRA). To address the uneven learning across physical quantities in standard LoRA, we introduce NSLoRA, a Newton-Schulz orthogonalized variant that rebalances adaptation. Our method achieves performance comparable to supervised LoRA finetuning without requiring any ground-truth solutions, while consistently outperforming competitive neural operator baselines and recent PDE foundation models across heterogeneous PDE benchmarks spanning multiple spatial dimensions.

## 1. 论文的核心问题与整体含义

PDE基础模型（如 Poseidon、PDE-Transformer 等）能够跨方程泛化，但将预训练模型适配到**未见过的PDE系统**时，传统方法高度依赖**稠密的真实解（ground-truth solution）数据**作为微调监督。然而在真实物理场景中：

- 高保真仿真数据获取成本极高，单个样本就可能需要耗费大量算力；
- 很多实际部署场景下，**方程本身与边界条件是已知的**，但缺乏内部点真解。

该工作要解决的核心问题正是：**如何仅利用物理规律（控制方程 + 边界条件），在完全没有内部真解的前提下，将预训练PDE基础模型适配到新方程上？**

这一问题的意义在于：将PDE基础模型的适配范式从"数据驱动"推进到"物理驱动"，降低成本并拓展其实际部署边界。

## 2. 论文提出的方法论

### 2.1 总体框架：两阶段流程

**阶段一：预训练（Supervised Pretraining）**
- 在 PDEBench 的 6 个子数据集（1D/2D/3D 可压缩 Navier-Stokes、浅水方程、扩散-反应、不可压缩 Navier-Stokes）上，通过监督式 next-step prediction 训练一个**邻域注意力（Neighborhood Attention, NA）Transformer** 骨干网络。
- 预训练目标为 MSE 损失，使模型获得跨异构方程的可迁移表征。

**阶段二：无监督适配（UPAO, Unsupervised PDE-based Adaptation Objective）**
- 冻结预训练骨干，将 LoRA 适配器注入每个注意力层与 SwiGLU 前馈模块；
- 仅利用 PDE 残差项和边界条件项构建损失，在未见方程上微调，**完全不使用内部真解**。

### 2.2 核心组件一：邻域注意力 Transformer 骨干

- 采用 **patch-based encoder-decoder** 结构，天然兼容不同空间分辨率输入；
- 邻域注意力将每个 token 的注意力限制在局部窗口中（时间维 1 + 空间维 d），复杂度为 O(L·M·Tin·k^(d+1))，随 token 数线性扩展；
- 沿时间轴强制**因果掩码**，防止信息泄漏（否则模型退化为恒等映射）；
- 统一 18 通道表征（3 个速度槽 + 15 个标量槽），通过二进制掩码适配不同物理量的数据集。

### 2.3 核心组件二：无监督 PDE 适配目标（UPAO）

UPAO 由两项损失组成：

**(1) 边界条件项 L_BC**：监督预测在边界带 S_b 上的值与边界参考场 u* 一致，采用 MSE。

**(2) PDE 残差项 L_PDE**：在内部区域 S_p 上，通过**有限差分离散化**计算残差 R(û)，并进行**逐方程归一化**：

```
L_PDE = sqrt( (1/K) Σ_k (1/s_k²) · (1/|S_p|) Σ_x ‖R_k(û)(x)‖² )
```

其中 s_k² 为第 k 个子方程残差的量级估计，防止不同量级的子方程互相压制梯度。

总损失：**L = λ_BC · L_BC + L_PDE**，λ_BC 是唯一需要调节的超参数（默认 10⁴）。

### 2.4 核心组件三：NSLoRA（Newton-Schulz 正交化低秩适配）

**动机**：标准 LoRA 在无监督物理目标下存在**秩塌缩**问题（有效秩远低于名义秩 r），导致非主导物理量学习不充分。

**方法**：
- 先进行标准 LoRA 热身训练（使 A、B 进入任务相关子空间）；
- 切换至 NSLoRA 前向路径：对每个低秩矩阵 A、B 分别执行 **5 步 Newton-Schulz 迭代**（X ← aX + b(XXᵀ)X + c(XXᵀ)²X），使其近似正交，再以 Frobenius 范数缩放：
  ```
  ΔW = ‖A‖_F · ‖B‖_F · NS(B) · NS(A)
  ```
- NSLoRA 相比 SVD 正交化**前向快 1.38 倍**（避免 cuSOLVER 核启动开销）。

## 6. 论文的主要结论与发现

1. **UPAO 有效消除内部真解依赖**：在 8 个 2D 基准中的 7 个，无监督适配与有监督 LoRA 上界的差距在 **2.5 倍以内**；在 11 个数据集中有 9 个**超越至少一个有监督神经算子基线**。

2. **显著优于 PDE-Transformer 同条件下的无监督适配**：在相同 UPAO 目标下，本方法 VRMSE 相比 PDE-Transformer + 标准 LoRA 的**几何平均降低 9.9 倍**。

3. **NSLoRA 确实缓解了秩塌缩**：稳定秩平均提升 5.2%（最高 15.6%），改进集中在**非主导物理量**（如 Shear Flow 示踪物 -14.1%、TG 压力 -5.6%、Burgers Vx -10.4%），验证了物理再平衡的设计动机。

4. **预训练是 UPAO 有效的前提**：从随机初始化全参数训练在 UPAO 下性能退化 1.2–5.3 倍（Exact-Solution 数据集达一个数量级以上）。

5. **UPAO 的收益取决于骨干架构**：在 TFNO 上改善所有 26 个迁移组合，在 CNextU-Net 上仅改善 14/26，而本方法获得最大且最一致的提升。

6. **零样本 → UPAO 微调持续增益**：在 The Well 四个基准上 VRMSE 降低 1.4×–7.0×。

## 8. 不足与局限

### 8.1 方法论层面的固有局限

- **需要已知方程与连续边界观测**：论文明确说明，"必须已知目标 PDE 的控制方程，且边界观测在整个轨迹上可用"——若这些条件无法满足则方法失效；
- **有限差分残差对数据质量敏感**：数据若携带明显离散化误差，PDE 残差项提供的监督信号会严重弱化；这限制了方法在 PDEArena、PDEGym 等含显著数值误差的公共基准上的适用性；
- **冷启动问题未解决**：方法需要 Tin=8 帧的历史窗口，无法处理仅给定初始条件和方程参数的冷启动场景。

### 8.2 实验覆盖不足

- **仅评估单步预测**：未做自回归滚动评估，长期稳定性未知，实际部署价值存疑；
- **数据集规模受限**：每个下游数据集仅 50–200 条轨迹，小样本下的统计置信度有限，未报告多次运行的标准差；
- **未做广泛的跨骨干验证**：NSLoRA 与 UPAO 的普适性只在单一体系架构上得到验证；
- **NSLoRA 的秩预算利用仍不充分**：即使提升后，稳定秩仍远低于名义秩 r=16，方法只是缓解了秩塌缩而非解决。

### 8.3 对比公平性风险

- Poseidon 仅做监督微调，未能做 UPAO 无监督对比（受其 FFT 重采样限制），在"最公平对比"上留有缺口；
- PDE-Transformer 与 Poseidon 的 checkpoints 为公开资源但适配期算力、数据集划分是否与本文严格一致，描述上仍有模糊空间。

**总结**：这是一篇高质量的创新性工作，首次系统性地将物理约束作为独立的无监督适配目标用于预训练 PDE 基础模型，并通过精心设计的消融实验论证了各组件的必要性。尽管存在数据规模、长期稳定性与通用性等方面的局限，其核心思想（物理即监督，Physics as Supervision）为 PDE 基础模型在数据稀缺场景下的落地提供了可行的范式，对未来研究具有很强的启发意义。
