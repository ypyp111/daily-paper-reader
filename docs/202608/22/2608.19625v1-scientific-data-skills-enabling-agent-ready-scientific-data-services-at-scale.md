## 摘要
科学数据正越来越多地被人工智能智能体使用，然而现有的数据集表示方式对自主发现、解读和调用支持有限。这一局限性源于科学数据在异构存储库中的碎片化，以及数据集表示主要面向人类使用而设计。为解决这一问题，我们引入了科学数据技能（SciDSK），一种智能体就绪的表示方式，将数据集特定知识与操作指导打包为可复用的智能体技能。SciDSK 整合了数据集描述、科学背景、文件组织、使用流程、质量检查和溯源信息，同时将底层数据保留在其原始存储库中。我们定义了结构化的 SciDSK 规范，并开发了系统化的构建流程，使每个 SciDSK 以权威数据集记录及相关支持材料为基础。我们进一步建立了科学数据技能库，这是一个统一平台，发布涵盖六个科学学科的 SciDSK 资源，并支持包访问、持久标识和源数据集追溯。我们通过数据集发现检索基准和数据集解读受控案例对 SciDSK 进行了评估。结果表明，SciDSK 提升了智能体驱动的数据集发现能力，并为数据集解读提供了更精确、更可操作的支撑。这些发现支持了以智能体就绪表示方式组织数据集特定知识的价值。

## Abstract
Scientific data are increasingly used by AI agents, yet existing dataset representations provide limited support for autonomous discovery, interpretation, and invocation. This limitation stems from the fragmentation of scientific data across heterogeneous repositories and from dataset representations designed primarily for human use. To address this limitation, we introduce the Scientific Data Skill (SciDSK), an agent-ready representation that packages dataset-specific knowledge and operational guidance as a reusable agent skill. A SciDSK integrates dataset descriptions, scientific context, file organization, usage procedures, quality checks, and provenance information while retaining the underlying data in its original repository. We define a structured SciDSK specification and develop a systematic construction pipeline that grounds each SciDSK in authoritative dataset records and associated supporting materials. We further establish the Scientific Data Skill Bank, a unified platform that publishes SciDSK resources across six scientific disciplines and supports package access, persistent identification, and traceability to source datasets. We evaluate SciDSK through a retrieval benchmark for dataset discovery and controlled cases for dataset interpretation. The results show that SciDSK improves agent-driven dataset discovery and provides more precise and actionable support for dataset interpretation. These findings support the value of organizing dataset-specific knowledge in an agent-ready representation.

# 论文总结：Scientific Data Skills: Enabling Agent-Ready Scientific Data Services at Scale

## 1. 核心问题与整体含义（研究动机和背景）
- 科学数据正越来越多地被 AI 智能体（agent）使用，但现有数据集表示方式主要面向人类阅读，缺乏对智能体自主发现、解读和调用的支撑。
- 具体障碍有三：
  1. **发现难**：数据分散在异构存储库中，元数据模式、搜索接口和访问机制各不相同；
  2. **解读难**：数据集级元数据缺少文件组织、文件科学角色及文件间关系的细节，智能体容易选错文件或误解内容；
  3. **调用难**：数据使用需要任务特定的文件选择、预处理、计算流程和约束，而现有文档未明确提供这些操作指导。
- 论文提出核心问题：**如何表示科学数据集，使智能体能够可靠地发现、解读并调用它们？**
- 核心思路：借鉴智能体技能（Agent Skill）的“渐进式披露”机制，将数据集特定知识和操作指导封装为可复用的“科学数据技能”（SciDSK），使数据集对智能体“就绪”。

## 2. 方法论：SciDSK 的表示与构建
- **核心表示**：每个 SciDSK 是一个技能包，核心文件为 `SKILL.md`，包含两部分：
  - **YAML frontmatter（智能体可读）**：提供数据集发现、关联、版本和溯源描述，包括技能常规字段（name、description、license、compatibility）以及嵌套的数据集元数据块（数据集身份、来源与访问位置、持久标识、许可证、数据范围、对象结构、快照信息等）。
  - **Markdown 指令主体（智能体可执行）**：包含六个组件：
    - 数据集概述（dataset overview）
    - 数据访问（data access）
    - 数据字段与结构（data fields and structure）
    - 使用指南（usage guidance）
    - 质量检查（quality checks）
    - 溯源与引用（provenance and citation）
- **数据集关联与版本化**：SciDSK 与底层数据分离，数据保留在原仓库；通过源 URL、持久标识符等显式关联；每个 SciDSK 对应一个特定数据集快照，由 `snapshot_id` 标识。
- **构建流水线（三阶段）**：
  1. **数据集接地（Dataset Grounding）**：识别权威数据源和具体快照，收集元数据、文档、文件清单、数据字典、论文、许可证、版本记录等支持材料，形成带溯源证据的基础。
  2. **规范引导编写（Specification-guided Authoring）**：将证据按 SciDSK 规范映射到 frontmatter 和指令主体；不能支持的信息省略，必要且缺失的信息标记为“不可用”。
  3. **验证与修订（Validation and Revision）**：检查结构一致性、内容与证据一致性、frontmatter 与正文一致性；发现问题则重新审查材料并修订，直至满足规范。
- **发布平台**：建立 Scientific Data Skill Bank（https://scidsk.cn/），支持按学科浏览、搜索、查看详情和下载技能包；发布前经四维审查（源真实性、表示保真度、技能安全性、智能体兼容性）；每个 SciDSK 分配独立 CSTR（中国科技资源标识），并记录源数据集标识符，实现独立引用与追溯。

## 3. 实验设计
### 3.1 数据集发现基准
- 目标集：从六个学科（物理、化学、地球科学、生物学、材料、计算机科学与技术）中选 72 个数据集。
- 查询构造：每个数据集两个查询，共 24 开发查询 + 120 初始测试查询；经人工评审后剔除 16 个模糊查询，最终测试集 104 个查询（每个查询仅一个相关数据集）。
- 检索语料库：规模约为公开 SciDSK 集合的 4 倍；每个候选数据集同时提供传统数据集记录和对应 SciDSK 表示，保证同一底层数据集身份。
- 对比方法：
  - `BM25-Raw`：对传统元数据记录做词法检索；
  - `Agent-Raw`：智能体对传统记录进行迭代搜索与候选检查；
  - `Agent-SciDSK-Text`：将完整 SKILL.md 当作普通文本，智能体检索；
  - `Agent-SciDSK`：SciDSK 注册为智能体技能，智能体先选两个最相关学科，再在该学科内检索已注册技能。
- 指标：Hit@1、Recall@5、MRR、nDCG@5。

### 3.2 数据集解读受控案例
- 选取 4 个代表案例：CT 头颅重建图像序列、GIS 栅格及 sidecar 文件、图像形式的科学表格、微博谣言事件标签与文本内容的跨文件关联。
- 每个案例设置 6 个原子评估标准，共 24 个标准。
- 对比三种证据条件：
  - `Agent-Page`：使用 ScienceDB 着陆页快照；
  - `Agent-Raw`：直接提供传统元数据和文件树；
  - `Agent-SciDSK`：通过原生技能机制访问完整 SKILL.md。
- 外部信息源被禁用；每个条件使用相同模型、请求、提示模板和运行约束。

### 3.3 实验环境
- 使用真实智能体环境，底层语言模型为 qwen3.6-plus，关闭思考模式，启用自动工具选择，温度设为 0，请求超时 120 秒，最多重试 3 次。
- 工具基于 MCP 实现并采用严格白名单；禁用 Shell、浏览器、Web 搜索等原生能力。
- 使用 2026 年 7 月的 SciDSK 平台快照。

## 6. 主要结论与发现
- **发现任务**：端到端 SciDSK 工作流（Agent-SciDSK）在所有检索指标上最优：Hit@1 80.77%、Recall@5 94.23%、MRR 86.41%、nDCG@5 88.40%；明显高于 BM25-Raw（Hit@1 47.12%）和 Agent-Raw（Hit@1 71.15%）。
- **解读任务**：Agent-SciDSK 满足 23/24 条标准，优于 ScienceDB 页面的 22/24；在具体案例中，SciDSK 能正确识别文件数量（如 196 张 TIFF 切片）、区分可见文件与总数、提供明确的跨文件关系和更具体的校验步骤。
- **总体结论**：将数据集特定知识组织为智能体就绪的表示（SciDSK），能够显著提升智能体驱动的数据集发现，并为数据集解读提供更精确、更可操作的支撑。
