## 摘要
物理信息神经网络（PINNs）将控制方程融入神经网络训练，能够在无需大规模观测数据集的情况下近似偏微分方程（PDE）解。参数化PINNs（ParamPINNs）进一步将物理参数作为输入，使得单一模型能够表示参数域上的一族PDE解。然而，现有的ParamPINNs仍面临训练效率低、参数间精度不均衡以及对有限采样参数任务的过拟合等问题，这可能损害对未采样参数的泛化能力。为解决这些问题，我们提出了一种持续学习物理信息神经网络（CL-PINN），将不同参数值下的PDE实例视为相关任务，并顺序学习它们。CL-PINN结合了基于贝叶斯优化的主动参数选择、任务级动态损失加权、稀疏物理约束回放以及可选参数子网络，以在有限主动任务容量下改进任务分配和知识保留。它无需观测数据，旨在有限计算资源下在较宽参数域上求解参数化PDE。在五个基准上的多种子评估（包括一个连续函数和四个参数化PDE）表明，贝叶斯选择相对于网格贪婪搜索大幅减少了目标损失查询次数，而稀疏回放缓解了对早期任务的遗忘。在规定的案例内资源协议下，CL-PINN通常比固定采样和网格贪婪基线提供更高且更均衡的求解精度。CL-PINN为学习跨物理参数泛化的PDE解提供了一条实用途径，并有望支持大规模工程参数研究中可复用的物理信息代理模型。

## Abstract
Physics-informed neural networks (PINNs) incorporate governing equations into neural-network training and can approximate PDE solutions without requiring large observational datasets. Parameterized PINNs (ParamPINNs) further take physical parameters as inputs, allowing a single model to represent a family of PDE solutions over a parameter domain. Existing ParamPINNs, however, still face inefficient training, uneven accuracy across parameters, and overfitting to a limited set of sampled parameter tasks, which can impair generalization to unsampled parameters. To address these issues, we propose a continual-learning physics-informed neural network (CL-PINN), which treats PDE instances at different parameter values as related tasks and learns them sequentially. CL-PINN combines Bayesian-optimization-based active parameter selection, task-wise dynamic loss weighting, sparse physics-constrained replay, and an optional parameter subnetwork to improve task allocation and knowledge retention under bounded active-task capacity. It requires no observational data and is designed to solve parameterized PDEs over relatively broad parameter domains under limited computational resources. Multi-seed evaluations on five benchmarks, including one continuous function and four parameterized PDEs, show that Bayesian selection substantially reduces objective-loss queries relative to grid-greedy search, while sparse replay mitigates forgetting of earlier tasks. Under the prescribed within-case resource protocols, CL-PINN generally provides higher and more balanced solution accuracy than fixed-sampling and grid-greedy baselines. CL-PINN offers a practical route toward learning PDE solutions that generalize across physical parameters and has the potential to support reusable physics-informed surrogates for large-scale engineering parameter studies.

- **核心问题**：现有ParamPINNs存在三大缺陷：
  - **训练效率低**：需要在大量参数点上重复训练或联合训练，计算开销大；
  - **参数间精度不均衡**：不同参数值对应的PDE实例难度不同，导致模型在某些参数区域精度高、在另一些区域精度差；
  - **过拟合有限采样参数任务**：仅对有限个采样参数进行训练时，模型容易过拟合这些离散任务，损害对未采样参数的泛化能力。
- **整体含义**：该研究旨在解决"如何在有限计算资源下，在较宽参数域上高效求解参数化PDE并获得均衡、可泛化的精度"这一核心挑战，为大规模工程参数研究提供可复用的物理信息代理模型。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想

将不同参数值下的PDE实例视为**相关但不同的持续学习任务**，按顺序学习这些任务，利用持续学习中的知识保留与任务分配机制，改善对参数域的覆盖与泛化。

### 关键技术细节

- **贝叶斯优化主动参数选择（BO-based Active Parameter Selection）**：
  - 不采用固定采样或网格贪心搜索来选择下一个训练参数；
  - 利用贝叶斯优化（BO）在参数域中主动选择信息量最大的下一个参数任务；
  - 相比网格贪心搜索，大幅减少目标损失（objective-loss）的查询次数。
- **任务级动态损失加权（Task-wise Dynamic Loss Weighting）**：
  - 对不同参数任务分配动态权重，避免新任务主导训练、旧任务被遗忘；
  - 根据任务难度或训练状态自适应调整各任务的损失贡献。
- **稀疏物理约束重放（Sparse Physics-constrained Replay）**：
  - 从早期任务中保留少量物理约束（PDE残差）样本用于重放；
  - 缓解顺序学习过程中的"灾难性遗忘"（catastrophic forgetting）；
  - 重放的是物理约束而非观测数据，因此**无需任何观测数据**。
- **可选参数子网络（Optional Parameter Subnetwork）**：
  - 作为可选项，为不同参数任务分配参数子网络，改善任务分配与知识隔离。

### 算法流程（文字说明）

1. 初始化一个PINN模型（含物理参数作为额外输入）；
2. 在每一轮训练中，使用贝叶斯优化从参数域中选择下一个最具信息量的参数值；
3. 将该参数值对应的PDE实例作为当前任务，进行顺序学习；
4. 训练过程中施加任务级动态损失加权，平衡当前任务与历史任务；
5. 从历史任务中抽取少量物理约束样本进行重放训练，缓解遗忘；
6. （可选）使用参数子网络为不同任务分配专用参数；
7. 重复上述过程，直至达到预定的主动任务容量或资源预算；
8. 最终模型能够在整个参数域上为未见参数提供PDE解的预测。

## 6. 主要结论与发现

1. **贝叶斯选择显著降低查询成本**：相对于网格贪心搜索，贝叶斯优化主动参数选择大幅减少了目标损失查询次数，训练效率更高；
2. **稀疏重放有效缓解遗忘**：从早期任务中重放少量物理约束可缓解顺序学习中的灾难性遗忘；
3. **精度更高且更均衡**：在限定资源协议下，CL-PINN通常提供比固定采样和网格贪心基线**更高且更均衡**的求解精度；
4. **无需观测数据**：CL-PINN在纯物理约束驱动下工作，适合无标签数据的实际场景；
5. **实用价值**：CL-PINN为跨物理参数泛化的PDE求解提供了实用路径，有潜力支持大规模工程参数研究中可复用的物理信息代理模型。

## 7. 优点与亮点

- **问题定位准确**：精准指出了现有ParamPINNs的三大痛点（效率低、精度不均、过拟合采样任务），且这些确实是该领域的关键挑战；
- **创新性融合**：将持续学习（continual learning）引入参数化PINN训练框架，在任务分配与知识保留上提供了新视角；
- **无需观测数据**：完全基于物理约束，避免了对标注数据的依赖，实用性强；
- **工程友好的资源约束设计**：明确在"有限资源"前提下设计方法，贴近实际工程应用场景；
- **贝叶斯主动选参**：将贝叶斯优化与主动学习结合，显著减少昂贵的损失查询次数，是一种高效的参数采样策略；
- **多种子评估与消融**：实验设计包含多种子、组件消融，结果的可信度较好；
- **可扩展性**：提出可选的参数子网络机制，允许用户根据需求在模型容量与任务隔离之间权衡。

## 8. 不足与局限

### 实验覆盖方面的局限

- **基准数量有限**：仅有5个基准，未涵盖高维参数空间、复杂几何域或实际工程级PDE问题；
- **PDE类型信息缺失**：摘要中未阐明四个参数化PDE的具体类型、参数维度和任务序列长度；
- **缺少与主流方法对比**：未与Meta-learning PINNs、DeepONet、FNO等前沿代理模型方法进行系统比较。

### 偏差风险

- **资源协议可能偏向方法**：由于采用"案例内资源协议"，可能对CL-PINN的设计更有利，需更多第三方验证；
- **贝叶斯优化的开销未充分讨论**：虽然减少了目标损失查询次数，但BO本身的计算开销未被量化分析；
- **评估指标单一**：主要报告精度与遗忘缓解，未涉及不确定性量化、收敛速度、模型复杂度等维度的分析。

### 应用限制

- **参数域大小有限**：方法在"相对较宽"但并非大规模参数域上验证，对于极高维参数空间的有效性尚未证实；
- **顺序学习的调度问题**：任务顺序对最终性能的影响（持续学习中的经典问题）未被讨论；
- **可选子网络的额外开销**：参数子网络在提升任务隔离的同时引入额外参数，其内存开销与收益的权衡未量化；
- **可复现性**：算力信息、超参数设置、代码公开情况等未在摘要中明确，可能影响复现性。
