## 摘要
含参数时变偏微分方程（PDEs）的高效求解是计算科学与工程的核心问题。现有的基于深度学习的加速方法覆盖从物理到数据的谱系，从具有强物理一致性但计算成本高的物理信息求解器，到推理高效但高度依赖高保真数据集的数据驱动替代模型。这些方法在很大程度上是孤立发展的，通常仅通过显式解场标签相互关联。我们提出PHD-SF，一个紧凑的物理到数据谱系框架，用于加速含参数时变PDEs。通过将SD-TPD分离策略与微分算子学习相结合，PHD-SF允许可复用的模型信息（包括空间特征、潜动力学特征和空间微分算子）在统一的基于DON的架构内的三种运行模式（PIDON、HIDON和DIDON）中生成、继承和丰富。该设计无需预计算的满场解标签或模式间的显式标签转移即可实现无标签谱系建模。PHD-SF进一步建立了分离求解、类超降阶的丰富化和直接推理加速路径，降低了对大规模高保真数据生成及其离线成本的依赖。在四个基准时变PDE上的结果表明，在初始物理信息阶段仅使用一个或两个代表性参数案例即可实现准确的跨参数求解和直接推理。总端到端成本低于训练单个参数案例的传统PINN所需的成本，同时支持可复用的跨参数推理。因此，PHD-SF为多查询参数化PDEs提供了一种高效的求解路径。

## Abstract
Efficient solution of time-dependent parametric partial differential equations (PDEs) is central to computational science and engineering. Existing deep-learning-based accelerators span a physics-to-data spectrum, from physics-informed solvers with strong physical consistency but high computational cost to data-driven surrogates with efficient inference but strong dependence on high-fidelity datasets. These methods have largely evolved in isolation and are often connected only through explicit solution-field labels. We propose PHD-SF, a compact physics-to-data spectrum framework for accelerating time-dependent parametric PDEs. By combining an SD-TPD separation strategy with differential-operator learning, PHD-SF allows reusable model information, including spatial features, latent dynamical features, and spatial differential operators, to be generated, inherited, and enriched across three operating modes, PIDON, HIDON, and DIDON, within a unified DON-based architecture. This design enables label-free spectrum modeling without precomputed full-field solution labels or explicit label transfer among modes. PHD-SF further establishes a separated-solving, hyper-reduction-like enrichment, and direct-inference acceleration path, reducing the dependence on large-scale high-fidelity data generation and its offline cost. Results on four benchmark time-dependent PDEs show accurate cross-parameter solution and direct inference using only one or two representative parameter cases in the initial physics-informed stage. The total end-to-end cost is lower than that required to train a conventional PINN for a single parameter case, while supporting reusable cross-parameter inference. PHD-SF therefore provides an efficient solution path for many-query parametric PDEs.

## 方法论

### 核心思想
PHD-SF 是一个紧凑的"物理—数据"谱系框架，包含三种运行模式（同一 DON 架构下的三种操作状态，而非三个独立模型）：

| 模式 | 全称 | 功能 | 训练内容 |
|------|------|------|----------|
| PIDON | Physics-Informed Differential Operator Network | 求解少量代表性参数案例，学习空间特征与微分算子信息 | 训练 SpatialNet + TPNet |
| HIDON | Physics-and-Data Hybrid Informed DON | 在更广参数域上丰富潜动力学特征，求解降阶潜 ODE 系统 | 仅训练 TPNet（冻结 SpatialNet） |
| DIDON | Data-Driven DON | 继承训练好的两个子网络，进行直接推理 | 无训练 |

### 关键技术细节

1. **SD–TPD 分离策略（空间域—时间参数域分离）**
   - 近似解表示为：`u(x, t, μ) = Φ(x)ᵀ A(t, μ)`，其中：
     - SpatialNet 输出基函数 BFs：`Φ(x) = [φ₁(x), …, φ_nₑ(x)]`
     - TPNet 输出基坐标函数 BCFs：`A(t, μ) = [a₁(t, μ), …, a_nₑ(t, μ)]`
   - 计算复杂度由传统 PINN 的 `O(Nₓ × N_z)` 降至 `O(Nₓ + N_z)`（Nₓ 为空间配点数，N_z 为时间—参数配点数）；
   - 附有稠密性证明（Stone–Weierstrass 定理 + 神经网络万能逼近定理），保证该可分离函数类能一致逼近任意连续参数 PDE 解。

2. **微分算子学习策略（Differential-Operator Learning）**
   - 时间微分转移到 BCFs：`∂_t u = Φ ∂_t A`；
   - 空间微分转移到 BFs：`L(u) = LΦ A`，其中 `LΦ` 为空间微分算子（SDOs）；
   - 对 BFs 和 BCFs 分别施加自动微分（AD），而非直接对近似解 u 施加 AD；
   - 该策略使学习到的 BFs 天然携带导数信息，便于下游继承复用，且缓解了 PINN 中高阶微分带来的梯度刚性。

3. **PIDON：物理约束求解与空间特征学习**
   - 加权 MSE 损失 `L = λ_r L_r + λ_b L_b + λ_i L_i + λ_orth L_orth`，包含 PDE 内部残差、边界条件、初始条件、正交化正则（改善 BFs 子空间质量，增强跨参数泛化）。

4. **HIDON：继承—丰富策略与潜动力学学习**
   - 继承 PIDON 学习到的 BFs、SDOs 和 SpatialNet，将高维 PDE 重写为降阶潜 ODE 系统；
   - 仅在**稀疏空间采样集**上施加控制方程约束（类超降阶 hyper-reduction 效果），计算成本与原始空间分辨率解耦；
   - 仅更新 TPNet 参数，在广参数域上丰富 BCFs 中编码的潜动力学特征；
   - 物理约束强度可通过稀疏点数 nₛ 连续调节，使模型沿物理—数据谱系连续变化。

5. **DIDON：直接推理**
   - 直接继承 PIDON 训练好的 SpatialNet 与 HIDON 丰富后的 TPNet，在 HIDON 已丰富的参数域内进行零成本在线推理。

6. **算法流程（Algorithm 1）**：
   - 步骤 1：PIDON 求解代表性案例并学习空间特征；
   - 步骤 2：预计算 HIDON 所需的稀疏基函数值与 SDOs；
   - 步骤 3：HIDON 求解潜 ODE 系统并学习潜动力学特征；
   - 步骤 4：DIDON 直接推理。

## 核心结果与关键洞察

### 效率与精度双赢

- **训练成本大幅下降**：PIDON 单案例求解耗时相比 PINN 降低约 1～2 个数量级（扩散-反应约 9 倍，波动约 82 倍，Burgers 约 34 倍，热传导约 41 倍）。这得益于空间–时间分离将高维耦合配点计算解耦为两个低维子网络操作。
- **多案例 HIDON 总耗时仍显著低于 PINN 单个案例**：例如热传导 HIDON 训练 108 个参数案例仅需 10,534 秒，而 PINN 求解单个案例需 1,034,780 秒，相差约 98 倍。即便将 PIDON+HIDON 的完整框架训练时间相加，也远低于 PINN 单案例成本，体现了“以一小时代价换取广泛参数域覆盖”的范式优势。
- **在线推理近乎实时**：DIDON 推理时间在 0.03～0.53 秒量级，完全满足实时控制与反问题等在线计算需求。

### 强物理约束提升数据效率

- PIDON 仅用 1 个案例训练的 BFs 能在未训练参数域上保持高表达性，跨参数残差能量比解析 POD 模态低 3～4 个数量级。这证明**空间特征可以跨参数迁移**，且物理约束比纯数据构建的 POD 更能捕获与参数无关的底层结构。
- HIDON 继承 BFs 后只需拟合低维潜 ODE 的 BCFs，参数域丰富成本极低；且其误差与 DIDON 推理误差几乎一致（说明 HIDON 学到的潜动力学已充分覆盖推理域），验证了“继承—丰富—推理”三步走的信息流无显著损耗。

### 空间尺度无关性的机制

- 当空间配点数 Nₓ 增大时，PINN/PIDON 误差下降但耗时与内存随之增长；而 HIDON/DIDON 误差几乎不随 Nₓ 变化。因为 HIDON 仅依赖稀疏空间采样集（约等于基函数个数 n_b）进行潜 ODE 求解，HIDON 的训练成本与空间分辨率解耦——这正是超降阶思想与神经网络结合的产物，也是框架能扩展到高维空间的关键机制。

## 主要贡献总结

1. **提出“物理—数据”统一谱系框架 PHD-SF**：首次将强物理约束求解（PIDON）、混合建模（HIDON）和纯数据驱动推理（DIDON）纳入同一架构，三种模式共享同一 DON 结构，通过训练阶段差异实现谱系贯通。
2. **提出 SD–TPD 分离架构与微分算子学习策略**：以可证明的稠密性保证支持可分离近似，并通过将空间/时间微分分别转移到 BFs/BCFs 的方式，使学习到的空间特征天然携带算子信息，为跨参数信息复用奠定基础。
3. **实现无需大规模高保真标签的快速跨参数推理**：通过“少量代表性案例训练 → 潜动力学丰富”替代“海量解标签采集”，显著降低数据生成成本，同时保持与传统 PINN 可比（甚至更优）的精度。
4. **建立可解释的泛化机制**：通过 BFs 与 POD 的对比、HIDON 稀疏采样分析等实验，揭示了“空间特征跨参数不变性”这一核心假设在时变 PDE 中的有效性，为后续物理增强降阶模型提供了理论依据。

## 局限性

- **可分离近似的固有约束**：虽然 Stone–Weierstrass 理论保证稠密性，但实际有限基函数下的近似能力仍受问题特性限制。对于参数强耦合、解呈现剧烈移动稀疏结构（如强对流、激波）的 PDE，可分离形式的表达能力可能不足，需要大量基函数或更精细的基函数自适应策略。
- **两阶段训练依赖误差累积**：PIDON 学习到的 BFs/SDOs 误差会直接影响 HIDON 的潜 ODE 建模，若 PIDON 求解不精确（如二维热传导案例），后续环节无法补偿；论文未设计误差反馈或端到端微调机制。
- **DIDON 推理域受限**：DIDON 只能在 HIDON 已训练的参数范围内操作；若推理参数超出该范围，TPNet 的插值外推能力未知，且论文未给出参数域边界失效分析。
- **缺少对 PDE 扰动/非线性更强场景的验证**：基准均基于经典线性/拟线性方程，未覆盖如 Navier–Stokes 方程、相场方程等强非线性时变问题，也未见随机初始条件或边界条件的泛化测试。
- **工程实现待完善**：仅单 GPU 实验，未讨论批量参数训练、并行化或大规模参数域的分布式实现；代码或预训练模型的公开可用性未在论文中明确提及。

## 对领域的影响与启示

- PHD-SF 重新定义了“数据”在科学机器学习中的角色：不再必须将高保真解作为显式标签，而是可将**求解过程中产生的中间表征（空间基、微分算子）作为可复用信息资产**，为“物理引导的数据生成”提供了新范式。
- 该框架为传统降阶模型（ROM）与深度神经网络之间架起桥梁：HIDON 的潜 ODE 本质上是一种**基于神经网络基函数的非线性超降阶模型**，但其训练无需离线快照库，而是用控制方程残差做约束，这启发了 ROM 社区与 PINN 社区的融合方向。
- 对于实时仿真、材料多尺度模拟、数字孪生等应用，PHD-SF 提供了一条“单次高成本训练 + 极低延迟推理”的可行路径，其在单 GPU 上即可支撑数千参数实时查询，具有很强的工程落地潜力。

## 总体结论

论文针对参数化时变 PDE 的快速求解问题，提出了一个结构清晰、理论可证、实验充分的统一框架 PHD-SF。核心洞察在于将物理信息求解与数据驱动建模的关联从“标签中介”深化为“模型信息继承”：先通过 PIDON 以极低成本学习跨参数可迁移的空间特征与微分算子，再利用 HIDON 在稀疏采样下丰富潜动力学，最终由 DIDON 实现实时推理。四个基准实验的一致结果表明，该框架在精度、训练效率和推理速度上均展现出相比传统 PINN 的显著优势，且无需大规模高保真数据。虽然存在可分离形式泛化能力、二维问题精度不足、外推域受限等局限，但 PHD-SF 的思想与机制设计具有很强的启发性和实用性，为科学计算与机器学习的深度融合提供了重要参考。
