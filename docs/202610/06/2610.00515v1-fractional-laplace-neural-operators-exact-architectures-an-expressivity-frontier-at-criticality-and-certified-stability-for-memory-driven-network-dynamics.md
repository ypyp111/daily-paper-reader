## 摘要
神经算子学习函数空间之间的映射，而遗传网络动力学由具有非有理拉普拉斯符号的 Volterra 预解式描述。我们引入分数阶拉普拉斯神经算子（fLNO），将这一结构嵌入到所学映射中。对于可交换的激励—拉普拉斯对，一个分块图谱层即可精确表示完整的线性 Volterra 解算子。我们为有限有理实现建立了一条表达能力前沿：它们在紧频率窗口上以几何速率逼近分数阶记忆，但无法再现由支点产生的非整数临界渐近行为，而在半直线上最佳有理逼近速率为根指数型。同一理论产生了可训练参数化，其构造上强制满足预设稳定性裕度，并给出一个 graphon 迁移定理，将真正的算子一致性与参数共享区分开来。在共同数据基准上，正有理算子在有限时域内可以达到或超过 fLNO 的精度，而在受控的近临界实验中，fLNO 能以少得多的参数更忠实地恢复分支坐标；无约束的有理拟合可能越过稳定性边界，而可认证参数化则不会。一个四参数谱律无需重新训练即可从规模 48 的图迁移到规模 192 的图，相对误差为 0.51--0.62%。对智利余震序列以及智利和意大利 21 个地区的更新模型的应用，展示了带有显式不确定性的结构化推断。本文的贡献是一种算子学习架构，其中精确的记忆结构、物理坐标和稳定性保证与有竞争力的精度并存。

## 速览
**TLDR**：遗传网络动力学由带非有理Laplace符号的Volterra预解式描述，传统神经算子难以刻画分数阶记忆。本文提出分数阶Laplace神经算子（fLNO），对可交换激励—拉普拉斯对，单个图谱层即可精确表示线性Volterra解算子。理论上给出有理实现的可表达性边界：只能几何式逼近，无法复现分支点临界渐近，半直线上最优速率为根指数；同时构造保稳定性参数化并证明图极限迁移定理。近临界实验中fLNO以更少参数更准确恢复分支坐标，四参数谱律跨图规模迁移误差仅0.51–0.62%。 \
**Motivation**：记忆驱动的网络动力学本质是带非有理Laplace符号的Volterra预解式，现有神经算子难以在保证稳定性的同时精确刻画分数阶记忆结构。 \
**Method**：提出fLNO，将分数阶Laplace结构嵌入学习映射；对可交换激励—拉普拉斯对，单层图谱层即可精确表示线性Volterra解算子，并给出保稳定性参数化。 \
**Result**：有理实现无法复现分支点临界渐近，半直线上最优速率为根指数；近临界下fLNO以更少参数更准确恢复分支坐标，四参数谱律跨图规模迁移误差0.51–0.62%。 \
**Conclusion**：构建了精确记忆结构、物理坐标与稳定性保证共存的算子学习架构，并在智利余震序列及智利与21个意大利地区更新模型上实现带显式不确定性的结构化推断。

## Abstract
Neural operators learn maps between function spaces, while hereditary network dynamics are described by Volterra resolvents with non-rational Laplace symbols. We introduce a fractional Laplace neural operator (fLNO) that embeds this structure in the learned map. For commuting excitation--Laplacian pairs, one block graph-spectral layer represents the full linear Volterra solution operator exactly. We establish an expressivity frontier for finite rational realizations: they approximate fractional memory geometrically on compact frequency windows, but cannot reproduce the non-integer critical asymptotics generated by a branch point, and on the half-line the best rational rate is root-exponential. The same theory yields trainable parametrizations that enforce a prescribed stability margin by construction, and a graphon-transfer theorem separates genuine operator consistency from parameter sharing. In a common-data benchmark, positive rational operators can match or exceed fLNO accuracy on finite horizons, whereas in controlled near-critical experiments fLNO recovers the branching coordinate more faithfully with far fewer parameters; unconstrained rational fits can cross the stability boundary, while certified parametrizations cannot. A four-parameter spectral law transfers without retraining from graphs of size 48 to 192 with 0.51--0.62% relative error. Applications to Chilean aftershock sequences and to renewal models for Chile and 21 Italian regions illustrate structured inference with explicit uncertainty. The contribution is an operator-learning architecture in which exact memory structure, physical coordinates and stability guarantees coexist with competitive accuracy.
