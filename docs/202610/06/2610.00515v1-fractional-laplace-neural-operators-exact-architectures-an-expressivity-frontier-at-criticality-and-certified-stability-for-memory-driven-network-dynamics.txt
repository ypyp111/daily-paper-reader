Abstract
Neural operators learn maps between function spaces, while hereditary network dynamics are
naturally described by Volterra resolvents with non-rational Laplace symbols. We introduce a
fractional Laplace neural operator (fLNO) that embeds this structure directly in the learned map.
For commuting excitation–Laplacian pairs, one block graph-spectral layer represents the full
linear Volterra solution operator exactly. We establish an expressivity frontier for finite rational
realizations: they approximate fractional memory geometrically on compact frequency windows,
but finite pole sets cannot reproduce the non-integer critical asymptotics generated by a branch
point; on the half-line the best rational rate is root-exponential. The same theory yields signed-
modal and Perron-normalized trainable parametrizations that enforce a prescribed stability
margin by construction. A graphon-transfer theorem distinguishes genuine operator consistency
from parameter sharing alone. In a common-data benchmark, positive rational operators can
match or exceed fLNO accuracy on finite horizons, whereas fLNO retains a more faithful explicit
branching coordinate near criticality with substantially fewer parameters. A scarce/noisy stress
test shows that unconstrained rational fits can cross the stability boundary, while certified
parametrizations cannot. A fixed four-parameter spectral law transfers without retraining from
graphs of size 48 to 192 with 0.51–0.62% relative error. Applications to four quality-controlled
Chilean aftershock sequences and renewal models for Chile and 21 Italian regions illustrate
structured inference with explicit uncertainty and out-of-sample checks. The contribution is not
universal predictive superiority, but an operator-learning architecture in which exact memory
structure, parsimonious physical coordinates, and spectral stability guarantees coexist with
competitive finite-horizon accuracy.
Keywords: neural operators; fractional Volterra equations; rational approximation; certified sta-
bility; graphon transfer; Hawkes processes.

Introduction
Neural operators learn maps between functions rather than maps between finite-dimensional vectors.
Fourier neural operators (FNOs) [13, 15], DeepONet [21], and more recent geometry-aware and
physics-informed variants have established this viewpoint as a general framework for discretization-
aware scientific learning. The Laplace neural operator (LNO) [7] is especially relevant to transient
systems because it parameterizes the temporal stage through a pole–residue representation in the

Laplace domain. Finite-dimensional linear state-space sequence models realize the same rational
transfer-function class. Neural operators are also beginning to be used for system-level tasks such
as fixed-point, stability, and bifurcation analysis rather than only as time-stepping surrogates [19].
Our objective is therefore not to claim that stability analysis is absent from operator learning.
The narrower question addressed here is whether the exact long-memory singularity and the exact
Volterra branching threshold can be encoded by construction in a learned operator.

The key observation is analytic. A tempered fractional memory kernel has Laplace symbol
bgα,θ(ξ) = (ξ + θ)α−1,
0 < α < 1,
which has a branch point rather than finitely many poles. A free rational LNO or a finite linear
state-space model can approximate this symbol very well on a bounded frequency interval, but it
cannot represent its branch singularity exactly. That distinction is negligible for some interpolation
tasks and decisive at criticality, where the non-analytic low-frequency structure determines the long-
time universality class. We therefore build the non-rational component into the layer as a dedicated
fractional atom and reserve rational terms for finite-memory corrections.
A second observation concerns certification. In this model class the stability boundary is already
known exactly. Rather than learning an unconstrained operator and testing stability afterward, the
trainable gains can be parameterized so that every point visited by optimization remains inside a
prescribed Volterra stability margin. This is stronger than a frequency-grid diagnostic and more
specific than a generic spectral regularizer: it enforces the analytic threshold of the underlying
hereditary system.

1.2
Related work
Neural operators. FNO [15], DeepONet [21], and the general neural-operator framework [13] moti-
vate the function-to-function viewpoint. LNO [7] is the closest architectural precursor because its
Laplace pole–residue stage is a rational transfer function designed for transients and extrapolation.
Recent work has made memory and state-space structure increasingly explicit in operator learning:
MemNO combines S4 and FNO to exploit history in time-dependent PDEs [6], while the Mamba
Neural Operator develops a direct connection between neural operators and structured state-space
models [8]. These approaches motivate finite-dimensional learned memory; our expressivity result
instead isolates the non-integer branch structure that finite rational realizations can approximate
on compact windows but cannot reproduce exactly at criticality. PINO [16], PINTO [22], and other
physics-informed operators incorporate governing structure into learning. In particular, the recent
Physics-Informed Laplace Neural Operator augments the LNO pole–residue backbone with PDE,
boundary, and initial-condition residuals [14]; this is complementary to the present architectural
use of an exact fractional atom and an analytic branching-stability certificate. Geometric operator
learning addresses transfer across varying geometries [20]. Fabiani et al. [19] recently showed that
local neural operators can support fixed-point, stability, and bifurcation analysis. The distinction
here is narrower: the stability certificate is not extracted from a learned time-stepper; it is enforced
analytically by the exact branching threshold of a completely monotone Volterra operator.
Rational and state-space approximations. Deep linear state-space models such as S4 [11] and

Approximation theory. The compact-window construction is a positive Gauss approximation of
a Markov function. The half-line reduction uses Stahl’s rational approximation of fractional powers

The empirical section builds on the Volterra–Hawkes calibration in Herrera-

graph or matrix excitation operator whose spectral edge determines stability. In a transferable
graph-filter realization the modal gains may be parameterized with a size-independent function
aj = fϑ(ℓj), rather than as one free parameter per mode. This distinction is important: free {aj}
gives exact finite-graph representation, whereas fϑ gives a fixed-dimensional family suitable for
transfer across discretizations.

Common-data operator benchmark
We next test whether the structural advantages above survive a direct operator-learning comparison.
Every model receives exactly the same maps “forcing history 7→response history,” generated from
the fractional Volterra system with
∆t = 0.1,

(α, θ, cλ, ρ) = (0.65, 0.12, 1, 0.90).
The common split contains 96 training, 24 validation, and 32 test trajectories. Reference trajectories
are generated directly by the causal time-domain recurrence, using an implicit local-state update
and midpoint quadrature of the fractional memory kernel; no impulse-response convolution is used
to synthesize arbitrary forcings. The forcing is a smooth random mixture of low-frequency Fourier
components, Gaussian pulses, and piecewise biases and is set to zero after the training horizon,
so evaluation on (Ttrain, 2Ttrain] is genuine autonomous extrapolation. We report two independent
training seeds. The structured models and FNO-1D are optimized with a 500-epoch cap, whereas
DeepONet uses a 1000-epoch cap; in every case the reported checkpoint is selected by validation
loss. The comparison is therefore common-data and convergence-oriented rather than an equal-
wall-clock benchmark.
The baselines are deliberately named by what was actually implemented. The “positive rational”
model is a 12-pole positive pole–residue operator, the “unconstrained rational” model has signed
free residues, and the “linear SSM” is a diagonal 16-state linear realization. They represent the
rational classes underlying LNO/state-space memory layers but are not claimed to be the authors’
official LNO or S4 implementations. FNO-1D and DeepONet use standard spectral-convolution
and branch–trunk constructions.

8.1
Cohort construction and completeness
For each sequence, the clock is anchored to the reviewed USGS ComCat mainshock origin and events
are selected within 350 km and 365 days after the mainshock. A one-minute exclusion around the
external anchor prevents a catalog representation of the mainshock from being counted twice; the
mainshock is then inserted once into day zero of the history. This convention is particularly useful
for Illapel, whose Mw8.3 mainshock is not present as such in the relocated event file although its
aftershock sequence is. All four extracted cohorts have unique event-level latitude–longitude pairs
for essentially every retained event and non-degenerate depth distributions.
Magnitude is used only to define an occurrence threshold, not as a Hawkes mark. Because the
source file contains several CSN magnitude types, no claim of event-by-event Mw homogeneity is
made. For each sequence we estimate a conservative completeness threshold as the largest of (i)
maximum curvature plus 0.2 magnitude units, (ii) the first 90% Gutenberg–Richter goodness-of-fit
threshold, and (iii) a local b-value stability criterion, rounded upward to 0.1 magnitude units. The
resulting thresholds are Mc = 3.3 (Tocopilla), 3.8 (Maule), 3.1 (Iquique), and 3.7 (Illapel), leaving
909, 1645, 1835, and 1418 aftershocks, respectively. Sensitivity analyses repeat the fit over 180,
365, and 730 day observation windows and at Mc, Mc + 0.25, and Mc + 0.50.

Application II: the renewal equation as a certified layer
The epidemic renewal equation is the intensity block of (1) at daily resolution, and the application
inverts two roles instructively. Normalizing the learned kernel to unit mass makes the branching
diagnostic literally the effective reproduction number, ρk = Rk window by window. And since
epidemics do cross criticality, the certificate is not imposed on estimation; its role is the control one
— margin to criticality per window, and the intervention strength guaranteeing a prescribed margin.
Finally, the rational block of Definition 2.2 earns its keep here: generation-interval kernels are
humped, outside the completely monotone atom class, and we use the block’s minimal nonnegative
humped element wℓ= e−bℓ−e−(b+d)ℓ. The two applications thus exercise complementary stages of
the same architecture.

The structural contrast
The two applications state the identifiability message empirically: the same certified estimator, run
honestly at two information scales, gives at q = 3 with ∼6 × 103 events an identified branching
radius with a partially flat coupling direction reported as such, and at q = 21 with ∼1.2×107 cases,

makes the runs comparable: in both, the stability object is pinned to r(A) = 1 by construction
rather than estimated along an unstable direction.

Discussion and limitations
The main mathematical conclusion is narrower and stronger than a generic claim that neural
operators can perform stability analysis. The fLNO contains the exact fractional Volterra resolvent
on the commuting class, and its trainable gains can be restricted to the exact known stability region.
This complements equation-free neural-operator stability methods [19]: those methods interrogate
a learned time-stepper, whereas the present certificate is an architectural property tied to a specific
hereditary branching threshold.
The rational expressivity result also needs careful interpretation. On a fixed frequency win-
dow, positive rational approximants converge geometrically and can be extremely accurate. The
obstruction concerns exact fractional branch singularities and horizon-uniform critical asymptotics,
not ordinary finite-window interpolation. Moreover, a general signed rational transfer function can
have a multiple critical zero and therefore polynomial terms; the stronger positive-neutral-limit
statement holds only for the positive Stieltjes rational class.
The transfer theorem is an operator statement. Empirical accuracy on a finite collection of
training trajectories is not an operator norm. The benchmark therefore separates what is demon-
20


strated empirically from what is proved analytically. On the common-data task, a positive rational
pole–residue operator can match or exceed fLNO accuracy over a finite window, and at ρ = 0.97 it
even has the smaller doubled-horizon tail error. This is not a failure of the expressivity theorem: the
obstruction is the exact fractional branch singularity and horizon-uniform asymptotics, not finite-
window approximation. Conversely, the fLNO identifies the branching coordinate more faithfully
and does so with three parameters.
The FNO-1D and DeepONet comparisons are benchmark-
specific rather than a general ranking. The main benchmark reports two independent seeds, so
its small error differences should be interpreted descriptively rather than as population-level per-
formance claims. The rational/SSM baselines are canonical pole–residue/state-space realizations
rather than official LNO or S4 code.
The graph experiment tests transfer of size-independent
physical parameters composed with the deployment graph’s known spectral structure; it does not
estimate the operator norm in Theorem 6.1.
The seismic analysis is intentionally conservative.
All four sequences are now derived from
one relocated CSN catalog [17]. The reproducibility package freezes the source DOI and SHA-
256 identifier, the retrieval/extraction code, mainshock anchors, completeness diagnostics, and
fitted outputs; the event-level source table itself is not republished because the current source
record does not display an explicit redistribution license. Magnitude is used only as a sequence-
specific occurrence threshold because the source catalog contains several magnitude types. The 300-
replicate parametric bootstrap is a finite-sample sensitivity analysis, not a validated 95% calibration;
an outer simulation study would be required before making nominal-coverage claims. The catalog of
Candia and Macedo [18] remains a useful independent route for future sensitivity analyses, but any
Hawkes analysis must use a duplicate-resolved, non-declustered event table because declustering
removes the self-excitation signal.
The epidemic results are likewise associational. Learned generation or reporting kernels alter
the estimated Rt trajectory even though the critical normalization is R = 1. The Italian spatial
coupling matrix may absorb common national forcing, reporting synchronization, or policy effects
in addition to physical importation; no causal mobility interpretation is made without mobility
covariates.
Finally, exactness currently concerns linear excitation. Nonlinear or saturating hereditary oper-
ators are the natural setting in which deeper nonlinear fLNO compositions would provide approxi-
mation power beyond the exact linear resolvent. The seismic and epidemic studies use the certified
memory/coupling architecture for structured statistical estimation; they are not end-to-end black-
box neural-operator benchmarks and should not be interpreted as such.
