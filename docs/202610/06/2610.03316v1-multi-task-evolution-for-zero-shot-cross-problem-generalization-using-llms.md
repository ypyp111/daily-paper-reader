## 摘要
为多样化的组合优化问题设计有效的启发式方法需要大量专业知识和反复搜索。大语言模型（LLM）能够自动完成启发式方法的生成与改进，但启发式搜索通常依赖于被优化问题所提供的评估反馈。因此，仅利用源任务反馈泛化到新问题定义仍然是一个核心挑战。我们提出 MECo，一种由 LLM 驱动的多任务进化框架，用于零样本跨问题泛化。MECo 维护以任务为条件的启发式种群，并利用基于跨任务种群性能的迁移差距来指导它们之间的交互。这些交互实现了启发式方法的迁移与重组。随后，一种互补的选择准则通过奖励每个成员对源组合的额外覆盖，构建一个紧凑的启发式集合。所选集合被应用于目标任务，无需进一步搜索或适应。在车辆路径问题（VRP）和柔性作业车间调度（FJSP）的 32 个问题变体上的实验表明，在相同预算下，与八种自动启发式设计（AHD）基线相比，MECo 取得了最低的平均成本。在域外问题上，它在每个问题族中都优于最强基线。此外，将 MECo 框架与不同的 AHD 方法集成，提升了它们在两个问题族中的域内（ID）和域外（OOD）性能，支持其在不同方法上的有效性。

## Abstract
Designing effective heuristics for diverse combinatorial optimization problems requires substantial expertise and repeated search. Large language models (LLMs) automate heuristic generation and refinement, but heuristic search typically depends on evaluation feedback from the problem being optimized. Generalizing to new problem definitions using only source-task feedback therefore remains a central challenge. We introduce MECo, an LLM-driven multi-task evolutionary framework for zero-shot cross-problem generalization. MECo maintains task-conditioned heuristic populations and uses a transfer gap based on cross-task population performance to guide their interactions. These interactions enable the transfer and recombination of heuristics. A complementary selection criterion then constructs a compact heuristic set by rewarding each member's additional coverage of source combinations. The selected set is applied to target problems without further search or adaptation. Experiments on 32 problem variants across vehicle routing (VRP) and flexible job-shop scheduling (FJSP) show that MECo achieves the lowest mean costs compared with eight automated heuristic design (AHD) baselines under the same budgets. On out-of-domain problems, it outperforms the strongest baseline in each family. Moreover, integrating the framework of MECo with different AHD methods improves their ID and OOD performance in both families, supporting its effectiveness across different methods.

## 2. 方法论：MECo（Multi-task Evolution through task Combination）

### 2.1 核心思想

- 为每个已探索的任务 $T_C$ 维护一个**任务条件启发式种群** $P_C$；启发式用 LLM 生成的程序表示，族内共享同一构造式决策接口（VRP 选下一客户，FJSP 选下一工序-机器对）。
- **任务级搜索**：选择两个已有种群，为其属性并集任务 $T_{A\cup B}$ 进化子代种群，子代继承并适配父代启发式；新种群可继续参与后续组合，形成 DAG。
- **程序级进化**：在选定任务内用 LLM 算子生成/筛选候选程序，评估只使用源数据集 $D_{T_j}$。
- **迁移引导**：用"迁移差距"衡量任务兼容性，优先探索未访问组合，其次选择迁移损失小的配对。
- **最终集合选择**：按"对源组合的互补覆盖"挑选紧凑启发式集合 $H$（$K=4$），冻结后零样本评测。

### 2.2 关键技术细节与公式

- **归一化源成本与任务质量**：
  $$f_j(h)=\frac{|D_{T_j}|^{-1}\sum_{x\in D_{T_j}}\ell(h,x)}{b_j},\qquad J_C(h)=\frac{1}{|C|}\sum_{j|c_j\in C} f_j(h)$$
  其中 $b_j>0$ 为简单启发式在 $D_{T_j}$ 上的平均成本，固定不变，使各源维度可比。
- **迁移差距（population-level）**：把 $P_A$ 全体成员在 $T_B$ 的源数据集上的平均表现与 $P_B$ 的本地表现比较：
  $$s(A\to B)=\frac{1}{|P_A|}\sum_{h\in P_A}J_B(h),\quad s(B\to B)=\frac{1}{|P_B|}\sum_{h\in P_B}J_B(h)$$
  $$g(A\to B)=\max\left\{0,\frac{s(A\to B)-s(B\to B)}{\max\{|s(B\to B)|,\epsilon\}}\right\},\quad G(A,B)=\frac{g(A\to B)+g(B\to A)}{2}$$
  只有正部（即发生退化）才计入，$G$ 越小表示双向迁移越兼容。
- **任务配对规则**：候选对 $(A,B)$ 需满足 $A\subsetneq A\cup B$ 且 $B\subsetneq A\cup B$（双方各贡献新属性）；先优先产生**未探索的并集**，再选 $G(A,B)$ 最小者；成功扩展后该对退役，但单任务仍可与其他任务继续交互；同一组合任务多次到达时种群合并。
- **四种提示算子（3 种交叉 + 1 种引导变异）**：
  - $c_1$ **机制组合**：抽取两父代各自的具体决策机制（排序信号、前瞻、路径终止规则等），组合成兼容的新机制。
  - $c_2$ **冲突消解交叉**：识别两父代决策偏置的冲突，用条件/分层规则写成一条连贯启发式，而非分数平均。

  - $m_1$ **迁移导向变异**：保留父代骨架，仅修改某个决策机制以改善源表现。
  - 父代采样按质量概率 $p_C(h)\propto \max_{g\in R_C}J_C(g)-J_C(h)+\eta$，第二父代在剩余候选中重新计算概率。
