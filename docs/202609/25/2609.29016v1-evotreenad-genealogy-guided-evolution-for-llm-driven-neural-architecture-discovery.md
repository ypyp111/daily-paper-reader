## 摘要
AI驱动的科学发现通过自主开发解决方案和设计来加速研究。大语言模型（LLM）智能体通过迭代生成与评估支持这一过程。然而，仅靠这些迭代并不能确保累积性进展，也无法确定下一步应追求哪些方向。高昂的评估成本进一步限制了探索范围。神经架构发现将这些挑战汇集在一起，把开放式设计与资源密集型实验耦合起来。我们提出EvoTreeNAD，一种谱系引导的进化算法，无需提供种子或人工指定搜索空间即可构建可训练架构。它从空根节点开始，生长出一棵持续存在的谱系树，其中每个新节点代表一个完整架构。由每个节点及其后代计算得到的前百分位值指导谱系选择。利用所选设计历史，Idea Agent提出一个变体，Code Agent将其实现。每个经过评估的变体成为一个子节点，扩展谱系，同时为后续谱系选择提供证据。我们的理论分析确立了随着谱系增长而存在的平稳变异机制。在指定的变异假设下，持续的前百分位家族值量化了在这些机制中生成高奖励架构的概率。EvoTreeNAD发现的架构优于所比较的NAS和NAD基线，在CIFAR-10/100上达到$2.05{\pm}0.06\%$和$15.09{\pm}0.22\%$的测试错误率。在所有六个MedMNIST-v2任务上，所发现的架构均超越了所列最强基线。一项受控的CIFAR-10研究进一步表明，EvoTreeNAD优于直接生成、best-of-$N$贪心延续以及全家族均值路由。

## Abstract
AI-driven scientific discovery accelerates research by autonomously developing solutions and designs. Large language model (LLM) agents support this process through iterative generation and evaluation. Yet these iterations alone do not ensure cumulative progress or establish which directions to pursue next. Costly evaluation further constrains the scope of exploration. Neural architecture discovery brings these challenges together, coupling open-ended design with resource-intensive experimentation. We introduce EvoTreeNAD, a genealogy-guided evolutionary algorithm that constructs trainable architectures without a supplied seed or a hand-specified search space. Starting from an empty root, it grows a persistent genealogy in which each new node represents a complete architecture. Top-percentile values computed from each node and its descendants guide lineage selection. Using the selected design history, an Idea Agent proposes a variant and a Code Agent implements it. Each evaluated variant becomes a child node, expanding the genealogy while providing evidence for subsequent lineage selection. Our theoretical analysis establishes the existence of stationary variation regimes as the genealogy grows. Under specified variation assumptions, sustained top-percentile family values quantify the probability of generating high-reward architectures in these regimes. EvoTreeNAD discovers architectures that outperform the compared NAS and NAD baselines, achieving CIFAR-10/100 test errors of $2.05{\pm}0.06\%$ and $15.09{\pm}0.22\%$. On all six MedMNIST-v2 tasks, the discovered architectures surpass the strongest listed baselines. A controlled CIFAR-10 study further shows that EvoTreeNAD outperforms direct generation, best-of-$N$ greedy continuation, and full-family-mean routing.

- **整体含义**：论文主张把架构发现视为**设计谱系的持续发展与再评估**，提出 EvoTreeNAD——一种谱系引导的进化算法，从**空根节点**出发，无需种子架构与手工搜索空间，即可生长出持久谱系树并持续发现高性能架构。

## 2. 方法论

### 核心思想

- 以**持久谱系树** `G_t = ({ρ} ∪ V_t, E_t)` 组织发现过程：根 ρ 为空锚点，每个非根节点代表一个完整可训练架构，边记录父子设计变更。
- 每轮迭代基于**前百分位家族值**从根开始路由，选出一条根到节点的谱系，用该谱系的设计与评估历史驱动下一轮架构变异。

### 关键技术细节

- **节点奖励**：将发现分数 `S(s)` 经 sigmoid 映射为可比奖励，并加入参数量紧凑度项：
  - `R(s) = r(S(s)) + λ_size · g(Params(a_s))`
  - `r(v) = σ( κ·d·(v − v_e) / |v_l − v_e| )`，`d = sgn(v_l − v_e)`
  - `v_e`/`v_l` 为任务级参考值与目标值，`κ` 控制斜率。
- **前百分位家族值**：节点 `s` 的家族 `D_t(s)` 包含自身及全部已进化后代，奖励多重集为 `H_t(s)`。取 `k_t(s) = max{1, ⌈τ·n_t(s)⌉}`，则
  - `V^top_t(s) = (1/k_t(s)) · Σ_{i=1..k_t(s)} x_(s)[i]`（降序奖励的前 k 个平均）
  - 作用：强调高奖励家族成员证据，降低对弱变体的敏感性。
- **谱系选择（路由）**：从 ρ 开始，若当前节点仍有子节点容量则停止；若已饱和，则走向**家族值最高**的子节点。得到的根到节点路径 `L_t` 即选中谱系，其终点为下一个架构的父节点。由于每次从根重新路由，**后续后代结果可把进化重定向回被保留的分支**。
- **双智能体变异**：
  - **Idea Agent**：基于任务需求与所选谱系中近期架构及评估结果，提出互不相同的设计/修改（一般精化、探索性修改、减法式简化三类）。
  - **Code Agent**：将提案实现为满足任务接口的完整可训练架构。
- **评估与失败处理**：先做可执行性与接口兼容性冒烟测试；通过后进行固定短预算训练与验证，采用**基于参考性能轨迹的早停**；无效评分触发有界次数的 Code Agent 重试（`A_max` 次）；每个父节点允许前 `P_tolerant` 次失败不记录子节点，之后失败以固定负奖励记录。
- **最终架构选择**：对最终谱系 `G_H` 施加同一路由规则，提取**主谱系（principal lineage）**，取其中发现奖励最高的三个架构构成固定候选集，再用全保真协议从零训练并在官方测试集评估。

### 理论结果（第 4 节）

- **定理 1（平稳选择—变异）**：任意无限运行都存在可达平稳机制 Q；奖励分布是各谱系条件奖励律的混合，且满足 `Λ_Q(A) = ∫ F(A) ν_Q(dF)`；并给出高奖励概率下界 `Λ_Q([q,b]) ≥ α/(b−q) · (U_{α,Q} − q)_+`。
- **定理 2（前百分位路由与高奖励产出）**：在指定变异假设下，对每个循环家族 v，`lim V^top_t(v) = U_τ(Λ_Q) = r_0 + (μ_+ − r_0)/τ · Λ_Q([q,b])`，即持续家族值**精确刻画**了该机制下生成高奖励架构的概率。
- **命题 1**：最大族路由在路径意义上等价于 **best-of-N 贪心延续**（每代只继续最高即时奖励子节点，未选兄弟不再发展）。
- **命题 2**：前百分位家族值有变分表示 `M_{k,n}(x) = max_{w∈W_{n,k}} Σ w_i x_i`，单点扰动影响 ≤ |δ|/k；且维持高于阈值 q 的家族值需要**非消失比例的高奖励后代**，少量早期成功无法长期支撑。
