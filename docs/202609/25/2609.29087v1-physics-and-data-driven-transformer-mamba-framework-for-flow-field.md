## 摘要
尽管深度学习加速了计算流体力学（CFD）中昂贵的偏微分方程求解，但 PINNs 和 FNOs 等现有方法往往在泛化能力、噪声鲁棒性和物理一致性方面存在不足。我们提出了面向流场的 Transformer-Mamba（TM4FF）框架，这是一种物理约束的算子学习模型，具有三项关键创新：用于特征去噪的残差小波 Mamba（RWM）层、用于增强特征融合的基于 Transformer 的注意力机制，以及利用傅里叶导数施加 Navier-Stokes 方程的物理信息损失。在四个 CFD 数据集上的实验表明，TM4FF 在不同流动条件下实现了高精度和稳健的泛化能力。

## Abstract
While deep learning accelerates expensive partial differential equation solving in computational fluid dynamics (CFD), existing methods like PINNs and FNOs often struggle with generalization, noise robustness, and physical consistency. We introduce the Transformer-Mamba for Flow Field (TM4FF) framework, a physics-constrained operator learning model with three key innovations: a Residual Wavelet Mamba (RWM) layer for feature denoising, a Transformer-based attention mechanism for enhanced feature fusion, and a physics-informed loss using Fourier derivatives to enforce the Navier-Stokes equations. Experiments on four CFD datasets show TM4FF achieves high accuracy and robust generalization across varying flow conditions.

## 2. 方法论
### 2.1 核心思想
- 将流体流动视为时空图像序列，学习算子 \(G:(\Sigma,\Omega)\mapsto u\)。
  - \(\Omega\)：操作参数，如边界条件、粘度等。
  - \(\Sigma\)：\(t-\Delta t\) 时刻的速度场。
  - \(u\)：\(t\) 时刻的流场。
- 通过条件嵌入、残差小波 Mamba 编码器、Transformer 风格跳连和物理信息损失，构建物理约束算子学习模型。

### 2.2 关键技术细节
- **条件嵌入**：
  - 标量操作参数被平铺到输入流场空间分辨率，并与流场拼接。
  - 对拼接张量做全局最大池化和全局平均池化，再经全连接层得到特征向量 \(h\)。
  - 用 Sigmoid 生成注意力权重 \(a=\sigma(h)\)，调制输入流场：\(u_{in}=a\odot u\)，使模型自适应不同物理条件。

- **Residual Wavelet Mamba（RWM）层**：
  - 双分支结构，用于特征提取与噪声解耦。
  - 模型驱动分支：对输入特征图 \(S\in\mathbb{R}^{C\times H\times W}\) 做 2D Haar 小波变换，分解为四个子带：
    - \(S_a=\lambda_a * S,\ a\in\{ll,lh,hl,hh\}\)。
    - 通过频率分离隔离特征，有助于过滤结构化噪声。
  - 数据驱动残差分支：并行处理输入特征。
  - 两分支融合后送入 Visual State Space Module（VSSM），捕捉长程空间依赖。
  - VSSM 核心形式：
    - \(W_1=\mathrm{LN}(\mathrm{SSM}(\mathrm{SiLU}(\mathrm{DWConv}(\mathrm{Linear}(W_{in})))))\)
    - \(W_2=\mathrm{SiLU}(\mathrm{Linear}(W_{in}))\)
    - \(W_{out}=\mathrm{Linear}(W_1\odot W_2)\)

- **Bi-level Skip Connection（BiS）**：
  - 用 Bi-level Routing Attention 替代传统 skip connection，增强编码器-解码器特征融合。
  - 将特征图划分为区域，计算区域级 query-key 邻接矩阵 \(A_r\)。
  - 对每个 query 只选择 top-k 最相关区域：\(I_r=\mathrm{topkIndex}(A_r)\)。
  - 仅在这些选定区域上计算稀疏注意力。
  - 最终输出结合稀疏注意力与局部上下文增强：\(O=\mathrm{Attention}(Q,K_g,V_g)+\mathrm{LCE}(V)\)。

- **物理信息损失函数**：
  - 总损失：\(L=L_{data}+L_{incompressible}+L_{NS}\)。
  - \(L_{data}\)：标准 MSE 数据损失。
  - 不可压缩性损失：\(L_{incompressible}=\|\nabla\cdot u\|^2\)，强制速度场无散度。
  - Navier-Stokes 残差损失：
    - \(L_{NS}=\left\|\frac{\partial u}{\partial t}+(u\cdot\nabla)u-\nu\nabla^2u-f\right\|^2\)。
  - 物理惩罚项使用傅里叶导数高效计算，引导网络输出既准确又物理一致。
