## 摘要
周期性非定常流动在强迫运动和流固耦合问题中十分常见。其参数化分析通常需要反复开展高保真模拟，而现有的降阶模型和代理模型一般依赖预先生成的流场或气动力数据。本研究提出一种纯物理驱动的框架，用于求解参数化周期流动和有限幅值气动弹性响应。首先，发展了周期物理信息神经网络（Periodic Physics-Informed Neural Network, P-PINN），通过在单个运动周期上施加时间周期性约束来直接求解周期流动，从而避免了求解周期状态建立前长时间瞬态演化过程的需要。进一步将流动条件和运动参数作为网络输入，构建周期流场与气动力的连续参数化表示。在此基础上，通过一阶谐波平衡将参数化气动力模型与结构动力学方程耦合，以求解单自由度气动弹性系统的响应幅值和频率。采用圆柱和翼型的强迫运动算例对该框架进行验证，结果表明：与时间推进结果相比，该框架能够准确再现不同流动与运动参数下的周期性气动力、表面载荷分布和瞬时流场。此外，对亚临界雷诺数下弹性支撑圆柱进行了气动弹性分析，所得气动弹性响应与全耦合CFD/CSD结果吻合良好。参数化模型经离线训练后，可针对不同结构参数状态反复评估，从而能够在数秒内在线获得完整的气动弹性响应曲线，而无需反复进行长时间的流固耦合时间推进。

## Abstract
Periodic unsteady flows are common in forced-motion and fluid-structure interaction problems. Their parametric analysis typically requires repeated high-fidelity simulations, whereas existing reduced-order and surrogate models generally rely on pre-generated flow-field or aerodynamic data. This study proposes a purely physics-driven framework for solving parametric periodic flows and finite-amplitude aeroelastic responses. First, a Periodic Physics-Informed Neural Network (P-PINN) is developed to directly solve periodic flows by imposing temporal periodicity over a single motion cycle, thereby avoiding the need to resolve the long transient evolution preceding the establishment of the periodic state. The flow conditions and motion parameters are further incorporated as network inputs to construct continuous parametric representations of the periodic flow field and aerodynamic forces. On this basis, the parametric aerodynamic model is coupled with the structural dynamic equation through first-order harmonic balance to solve the response amplitude and frequency of a single-degree-of-freedom aeroelastic system. This framework is validated using forced-motion cases of a circular cylinder and an airfoil, demonstrating accurate reproduction of periodic aerodynamic forces, surface load distributions, and instantaneous flow fields under different flow and motion parameters compared with time-marching results. Furthermore, aeroelastic analysis is conducted for an elastically mounted circular cylinder at subcritical Reynolds numbers, and the resulting aeroelastic response agrees well with fully coupled CFD/CSD results. Once trained offline, the parametric model can be repeatedly evaluated for different structural parameter states, enabling the complete aeroelastic response curve to be obtained online within seconds, without repeated long-time fluid-structure interaction time marching.

- **传统方法痛点**：
  - 高保真 CFD 或耦合 CFD/CSD 方法通常需要时间推进，必须先求解多个周期的长时间瞬态演化才能建立稳定周期状态，计算代价高昂。

  - 降阶模型（POD、Volterra、ARX、神经网络等）与代理模型虽可降低在线成本，但训练普遍依赖预生成的 CFD 或实验数据，精度与泛化能力受数据量、参数空间覆盖度和数据质量影响。
- **PINNs 的机遇与不足**：物理信息神经网络（PINNs）可直接将控制方程与边界条件嵌入优化过程，无需预生成标签。但现有 PINNs 在处理长时域、运动边界和连续参数变化时仍面临挑战；在流固耦合/气动弹性领域，已有工作多集中于数据辅助的流场重构、结构参数辨识和反问题，**完全物理驱动、无标签的正向气动弹性响应求解仍较少探索**。
- **核心目标**：提出一套纯物理驱动框架，直接求解参数化周期流动与有限幅值气动弹性响应，避免长时间瞬态推进，并支持离线一次训练、在线快速评估不同结构参数状态。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架

- 提出 **Periodic Physics-Informed Neural Network（P-PINN）**：在单个运动周期上施加时间周期性约束，将传统长时初值问题转化为**单周期时间边值问题**，直接求解周期稳态，绕过前置瞬态演化。
- 进一步将流动与运动参数（Re、A、U*、α 等）作为网络输入，构建周期流场与气动力的**连续参数化表示**。
- 将参数化气动力模型与结构动力学方程通过**一阶谐波平衡**耦合，把单自由度流固耦合问题转化为以响应幅值和响应频率为未知量的低维非线性系统，直接求解有限幅值周期气动弹性响应。

### 2.2 P-PINN 关键技术细节

- **控制方程**：二维不可压缩流动统一形式，参数 κ 控制黏性：κ = 1/Re 对应 Navier–Stokes 方程，κ = 0 对应 Euler 方程。
- **时间归一化**：定义 τ = t/T ∈ [0,1]，一个运动周期映射到单位区间，时间导数满足 ∂/∂t = (1/T) ∂/∂τ。
- **周期重叠约束（核心创新）**：不同于传统 PINN 在初始时刻施加初始条件，P-PINN 在周期两端区间 [τ-δτ, τ] 与 [1-δτ, 1+τ] 上施加**有限时间区间重叠约束**，使两端流态在区间上匹配而非仅单点匹配。重叠残差为：
  - q̂(x_i, y_i, τ_i) − q̂(x_i, y_i, τ_i + 1) = 0，τ_i ∈ [−δτ, δτ]，其中 δτ = 0.1（经验选取）。
- **残差向量构成**：PDE 残差、边界条件残差、周期重叠残差，分别由 λ_PDE、λ_BC、λ_OC 加权。
- **运动边界处理**：根据运动参数和时间相位更新每个配置点位置；固体表面位移为 Δx_b，远场位移为零，内部点按到固壁距离 d_b 与远场距离 d_f 的加权线性插值 Δx_i = d_f/(d_b+d_f)·Δx_b 变形，保持域变形光滑单调、点分布规则。
- **TSONN 策略**：引入独立于物理时间的伪时间变量，将原残差方程转化为一系列隐式伪时间子问题（内迭代/外迭代）；每个外迭代重启 L-BFGS 优化器并随机重采样配置点。
- **体积加权 PDE 残差**：对近壁密集网格点的 PDE 残差按配置点体积 v_i 加权并归一化，改善非均匀网格下的训练表现。

### 2.3 参数化求解

- 网络输入包括空间坐标、归一化时间以及问题相关的流动与运动参数；每个外迭代随机采样 30,000 个内部残差点、2,000 个边界点、2,000 个周期重叠点，并随机选取参数空间中的流动与运动参数。
- 每个配置点关联不同的流动条件与运动状态，使每个批次覆盖广泛参数组合，提升参数空间上的表示与泛化能力。

### 2.4 气动弹性耦合（一阶谐波平衡）

- 结构运动方程（弹性支撑圆柱，仅保留横向沉浮自由度）：
  - d²Y/dt*² + 4πζF_n dY/dt* + (2πF_n)² Y − (2/π)(C_L/M) = 0。
- 一阶谐波近似：Y ≈ A sin(2πF_r t*)，A 为响应幅值，F_r 为实际响应频率。
- 将 P-PINN 预测的周期升力展开为 C_L = C_L,s sin(2πF_r t*) + C_L,c cos(2πF_r t*) + …，其中 C_L,s、C_L,c 为傅里叶系数。
- 代入结构方程并分别平衡正弦项与余弦项，得到两个谐波平衡方程：
  - 正弦项（式 4.7）：描述与位移同相的升力分量对等效刚度和响应频率的影响。
  - 余弦项（式 4.8）：描述与速度同相的升力分量所代表的气动能量输入与结构阻尼耗散的平衡。
- 定义两个谐波平衡残差 R_s(A, U*_r)、R_c(A, U*_r)，对给定结构折减速度 U*_n 求解二维非线性系统 R_s = 0、R_c = 0。
- **避免零幅值平凡解**：以参数模型幅值下界作为最小允许响应幅值；并用前一个结构折减速度的收敛解作为下一个的初值。
