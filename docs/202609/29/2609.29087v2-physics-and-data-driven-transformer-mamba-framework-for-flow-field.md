## 摘要
尽管深度学习加速了计算流体力学（CFD）中昂贵的偏微分方程求解，但 PINNs 和 FNOs 等现有方法往往在泛化性、噪声鲁棒性和物理一致性方面存在不足。我们提出了用于流场的 Transformer-Mamba（TM4FF）框架，这是一种物理约束的算子学习模型，具有三项关键创新：用于特征去噪的残差小波 Mamba（RWM）层、用于增强特征融合的基于 Transformer 的注意力机制，以及使用傅里叶导数来强制满足 Navier-Stokes 方程的物理信息损失。在四个 CFD 数据集上的实验表明，TM4FF 在不同流动条件下实现了高精度和稳健的泛化能力。

## Abstract
While deep learning accelerates expensive partial differential equation solving in computational fluid dynamics (CFD), existing methods like PINNs and FNOs often struggle with generalization, noise robustness, and physical consistency. We introduce the Transformer-Mamba for Flow Field (TM4FF) framework, a physics-constrained operator learning model with three key innovations: a Residual Wavelet Mamba (RWM) layer for feature denoising, a Transformer-based attention mechanism for enhanced feature fusion, and a physics-informed loss using Fourier derivatives to enforce the Navier-Stokes equations. Experiments on four CFD datasets show TM4FF achieves high accuracy and robust generalization across varying flow conditions.

    - **W1**：难以建模非定常流场中的复杂时间依赖与多尺度关联。

## 2. 方法论
- **总体框架**：学习算子 \(G:(\Sigma,\Omega)\rightarrow u\)，其中 \(\Omega\) 为运行参数（边界条件、黏度等），\(\Sigma\) 为 \(t-\Delta t\) 时刻速度场，\(u\) 为 \(t\) 时刻流场。网络 \(f_\theta\) 逼近该算子，通过最小化损失 \(L(u,\hat u)\) 获得最优参数。
- **条件嵌入**：
  - 标量运行参数被平铺到与输入流场相同的空间分辨率，并与流场拼接成张量 \(x\)。
  - 对 \(x\) 做全局最大池化和平均池化，再经全连接层得到特征向量 \(h\)。
  - 用 Sigmoid 生成注意力权重 \(a=\sigma(h)\)，调制输入流场：\(u_{in}=a\odot u\)，使模型自适应不同物理条件。
- **残差小波 Mamba（RWM）层**：
  - 输入特征图 \(S\in\mathbb{R}^{C\times H\times W}\)，采用双分支结构。
  - **模型驱动分支**：先做 2D Haar 小波变换（DWT），分解为四个子带 \(S_a=\lambda_a*S\)，\(a\in\{ll,lh,hl,hh\}\)，按频率隔离特征，有助于过滤结构化噪声，尤其是条纹噪声。
  - **数据驱动残差分支**：并行提取残差特征。
  - 两个分支融合后送入 Visual State Space Module（VSSM），捕捉长程空间依赖。VSSM 内部：
    - \(W_1=\mathrm{LN}(\mathrm{SSM}(\mathrm{SiLU}(\mathrm{DWConv}(\mathrm{Linear}(W_{in})))))\)
    - \(W_2=\mathrm{SiLU}(\mathrm{Linear}(W_{in}))\)
    - \(W_{out}=\mathrm{Linear}(W_1\odot W_2)\)
  - 该设计结合小波物理先验与 Mamba 序列建模能力。
- **Bi-level Skip Connection（BiS）**：
  - 用 Bi-level Routing Attention 替换传统跳跃连接，增强编码器-解码器特征融合。
  - 将特征图划分为区域，计算区域级 query-key 邻接矩阵 \(A_r\)，对每个 query 选 top-k 最相关区域：\(I_r=\mathrm{topkIndex}(A_r)\)。
  - 仅在选中区域计算注意力，并加入 Local Context Enhancement（LCE）：\(O=\mathrm{Attention}(Q,K_g,V_g)+\mathrm{LCE}(V)\)。
- **物理信息损失**：
  - 总损失为 \(L=L_{data}+L_{incompressible}+L_{NS}\)。
  - \(L_{data}\) 为标准 MSE 数据损失。
  - \(L_{incompressible}=\|\nabla\cdot u\|^2\)，约束不可压条件。
  - \(L_{NS}=\left\|\frac{\partial u}{\partial t}+(u\cdot\nabla)u-\nu\nabla^2u-f\right\|^2\)，惩罚对 Navier-Stokes 动量方程的偏离。
  - 物理项使用 **Fourier 导数**高效计算，使预测更符合物理规律。
