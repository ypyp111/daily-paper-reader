## 摘要
我们提出了一种用于函数逼近和偏微分方程（PDEs）数值求解的稀疏连接秩启发神经网络（SCRINN）。通过引入结构化稀疏连接架构以及正交性和归一化引导的损失函数，SCRINN 构建了一个近似标准正交的神经基，同时促进其评估矩阵的渐进秩增长并减少可训练参数的数量。我们开发了一个两阶段框架：首先构建近似标准正交的神经基，随后使用最小二乘方法确定输出权重。在函数逼近以及多种稳态、时间相关和非线性 PDE 上的数值实验表明，SCRINN 能够以显著更低的训练成本始终实现高逼近精度。代码已在 GitHub 上公开。

## Abstract
We propose a Sparsely Connected Rank-Inspired Neural Network (SCRINN) for function approximation and the numerical solution of partial differential equations (PDEs). By introducing a structured sparse connectivity architecture and an orthogonality- and normalization-guided loss function, SCRINN constructs an approximately orthonormal neural basis while promoting progressive rank growth of its evaluation matrix and reducing the number of trainable parameters. A two-stage framework is developed, in which an approximately orthonormal neural basis is first constructed, and the output weights are subsequently determined using least-squares methods. Numerical experiments on function approximation and a variety of steady-state, time-dependent, and nonlinear PDEs demonstrate that SCRINN consistently achieves high approximation accuracy with substantially lower training costs. The code is publicly available on GitHub.
