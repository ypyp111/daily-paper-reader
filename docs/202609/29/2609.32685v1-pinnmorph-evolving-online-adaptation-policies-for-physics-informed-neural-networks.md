## 摘要
物理信息神经网络（PINNs）为求解偏微分方程（PDEs）提供了一种基于学习的框架，但其训练行为在优化过程中可能发生显著变化。残差分布、梯度交互、区域学习难度以及模型容量需求可能随时间演化，而网络架构和主要训练机制通常在训练前就已确定。我们提出 PINNMorph，一种基于大语言模型（LLM）引导的策略演化的在线 PINN 自适应框架。PINNMorph 维护一个由状态条件自适应策略组成的种群，这些策略将执行诊断映射为对拓扑修改、加性表示增强、目标平衡、梯度处理、自适应采样和优化器阶段控制的受控干预。在每次干预机会，从当前策略种群中实例化候选程序，根据观测到的训练状态进行选择，并直接应用于训练中的 PINN。所得模型继承其现有参数和训练状态，并沿同一轨迹继续优化。执行结果随后用于评估干预并演化策略种群。与训练前架构搜索或固定自适应规则不同，PINNMorph 利用实际训练的反馈，联合自适应当前 PINN 及其干预所依据的策略。在 13 个 PDE 基准上的实验表明，PINNMorph 在所有评估问题上均比 SA-PINN、ConFIG、RoPINN、HARMONIC 和 PINNsAgent 取得更低的求解误差。消融研究进一步考察了在线自适应、状态条件干预选择和执行反馈驱动策略演化的效果。

## Abstract
Physics-informed neural networks (PINNs) provide a learning-based framework for solving partial differential equations (PDEs), yet their training behavior can change substantially throughout optimization. Residual distributions, gradient interactions, regional learning difficulty, and model-capacity requirements may evolve over time, while the network architecture and major training mechanisms are typically determined before training. We propose PINNMorph, an online PINN adaptation framework based on large language model (LLM)-guided policy evolution. PINNMorph maintains a population of state-conditioned adaptation policies that map execution diagnostics to controlled interventions over topology modification, additive representation augmentation, objective balancing, gradient handling, adaptive sampling, and optimizer-phase control. At each intervention opportunity, candidate programs are instantiated from the current policy population, selected according to the observed training state, and applied directly to the PINN under training. The resulting model inherits its existing parameters and training state and continues optimization along the same trajectory. Execution outcomes are subsequently used to evaluate interventions and evolve the policy population. Unlike pre-training architecture search or fixed adaptation rules, PINNMorph jointly adapts the current PINN and the policies governing its interventions using feedback from actual training. Experiments on 13 PDE benchmarks show that PINNMorph achieves lower solution errors than SA-PINN, ConFIG, RoPINN, HARMONIC, and PINNsAgent across all evaluated problems. Ablation studies further examine the effects of online adaptation, state-conditioned intervention selection, and execution-feedback-driven policy evolution.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：物理信息神经网络（PINNs）通过将 PDE 控制方程与边界/初始条件嵌入神经网络训练来求解偏微分方程，但训练过程高度敏感、不稳定。常见问题包括物理目标失衡、梯度冲突、谱偏差、残差分布不均等，其影响随 PDE 类型和训练阶段而变化。
- **关键观察**：**主导训练瓶颈会在同一条优化轨迹内部发生变化**。早期可能受约束间失衡主导，后期则可能转为梯度冲突、局部残差集中、采样不足或表示容量不足。因此问题不只是"如何自适应"，还包括"在何时自适应什么"。
- **现有方法的两类局限**：
  - 自适应 PINN 方法（如 SA-PINN 损失加权、ConFIG/HARMONIC 梯度协调、RoPINN 区域优化、自适应采样）**只在预先设定的单一自适应族内工作**。
  - 自动化 PINN 设计（Auto-PINN、NAS-PINN、PINNsAgent 等）**在训练前或跨独立运行搜索配置**，不处理同一训练轨迹内的状态依赖干预选择。
- **核心主张**：将在线 PINN 自适应形式化为**序贯决策问题**——在每个诊断点，由当前物理误差、优化行为、模型状态与剩余预算共同决定是否需要干预以及采用哪类干预。由于干预空间横跨拓扑、表示、目标、梯度、采样与优化器等异质结构化变更，论文提出用 LLM 实例化状态条件干预并演化生成这些干预的策略。

## 二、方法论：核心思想与关键技术细节

### 1. 整体思想
PINNMorph 在**不重启训练**的前提下，让一个正在优化的 PINN 被在线"变形"：维护一个由 LLM 引导演化的**状态条件策略种群**，策略把训练诊断映射为结构化干预动作，动作直接作用于当前模型，执行结果（与"无干预反事实延续"对比）再反馈给策略演化，形成闭环。

### 2. 训练状态诊断
- 使用两个固定的留出配点集：**决策集 B_dec**（用于在线诊断与动作选择）和**审计集 B_aud**（用于评估干预物理效果），二者均不参与梯度更新，且不使用参考解。
- 状态构造：`st = D(Ht, Pt, At, Bt)`，其中 Ht 为近期优化与自适应历史，Pt 为物理诊断（PDE/BC/IC 残差、残差集中度、主约束违反、梯度统计、优化停滞），At 为架构信息，Bt 为剩余预算与执行上下文。

### 3. 策略种群与演化模式
- 维护 **K = 5** 个状态条件策略：`Πg = {π_g^(1), …, π_g^(K)}`，每个策略输出动作 `a_t^(k) = π_g^(k)(st)`。
- 初始种群由 PDE 描述、当前状态、架构与受控动作空间生成；后续世代采用五种互补演化模式：**Refinement（精炼）、Physics-Guided（物理引导）、Architecture-Guided（架构引导）、Synthesis（综合）、Novelty（新颖性探索）**。

### 4. 在线干预动作空间
- 六大动作族：**拓扑修改、加性表示增强、目标平衡、梯度协调、自适应采样、优化器阶段控制**。
- 具体实现为 **16 个高层动作 + 23 个原语机制**（含 KEEP 空操作），如 Widen / Regrow / Add layer / Prune / Redistribute / 局部重初始化 / 组件容量重分配；Residual branch / Correction branch / Fourier branch / Gated branch / Localized experts / Adaptive Fourier branch / Component expert / Split conflicting topology；损失权重重平衡、组件梯度平衡、残差区域重加权、约束强调、梯度冲突缓解；采样分布自适应；进入 L-BFGS 阶段等。
- 动作选择：`a*_t = arg max_{a∈Ct} S_φ(st, a, H_exec_t)`，打分函数倾向与当前瓶颈对齐的动作，并纳入历史执行证据；若无合适动作则 KEEP 继续训练。每个诊断点**至多执行一个动作**。

### 5. 函数保持与状态迁移
- 结构干预直接作用于正在优化的 PINN，**保留未变化参数与兼容的优化器状态**，新参数由注册算子初始化并加入优化器。
- 零输出加性分支与 Net2Wider 式增长在插入时**保持模型函数不变**（至浮点误差）；剪枝、重分配、直接加层、局部重初始化等不保证精确函数保持，需经过输出/一阶二阶导数/残差检查，失败则回滚快照。
- 形式化表示为：`(At, θt, St) --T(at)--> (A+_t, θ+_t, S+_t) --next step--> (A+_t, θt+1, St+1)`。

### 6. 执行反馈与策略演化（关键创新）
- **问题**：继续训练本身也会改善 PINN，因此干预后的改善不能直接归因于动作。
- **冻结延续估计**：在干预点 t0，用每个留出集最近 **W = 7** 个干预前观测做鲁棒对数线性拟合（中位数斜率/截距），外推得到"若无干预"的估计轨迹，且在 t0 后**不再重拟合**，也不运行影子训练。
- **噪声控制与置信度**：基于残差中位绝对偏差与时间跨度计算置信度，含裁剪惩罚；直接信用要求两个集合置信度均 ≥ 0.35 且无裁剪预测。
- **效用计算**：按 horizon h 计算延续相对效用 `u^B_{k,h} = (ℓ̂0,B_k(t0+h) − ℓ^B_k(t0+h)) / max{ℓ̂0,B_k(t0+h), ε}`；按物理组（PDE/BC/IC/观测 + 最差区域组）等权平均得 `U^B_h`；集合接受条件为聚合效用 ≥ 0.01 且无单组件/区域相对预测退化 > 0.10；**两集合均接受才给正信用，信用取两者较小值**；方向相反则扣留数值信用。
- **三个反馈事件**：+100、+500、+1000 步分别记录，不跨 horizon 加权求和；每个可信用事件按 `Cn = Cn−1 + (rn − Cn−1)/n` 更新策略信用。
- **策略演化**：`Πg+1 = E_ψ(Πg, H_exec_g, st)`，有益干预提供正经验，无效/窄适用动作约束后续更新。

## 六、主要结论与发现

- **性能**：PINNMorph 在 **全部 13 个 PDE 基准上取得最低平均 MSE**，**Friedman 平均排名 1.00**，显著优于 SA-PINN（3.69）、ConFIG（4.77）、RoPINN（4.08）、HARMONIC（4.92）、PINNsAgent（2.54）。
- **提升幅度**：相对每个 PDE 上最强基线，Heat 2D VC 降低 **67.6%**、NS 2D CG 降低 **66.9%**、Poisson 2D CG 降低 **65.9%**、Gray–Scott 2D 降低 **63.0%**、Poisson 3D CG 降低 **61.0%**；在基线已很强的任务（Burgers 1D、Heat 2D MS、Poisson 5D）上仍保持最优。
- **消融结论**：
  - 移除在线自适应（No Morph）中位误差比 **12.65×**，说明轨迹内自适应至关重要。
  - 随机选择动作（Random Selection）中位误差比 **10.77×**，且在 13 个任务中 8 个劣于 No Morph，说明**脱离训练状态的随机干预不能保证稳定收益**。
  - 随机演化（Random Evolution）中位误差比 **10.30×**，是三个消融中最强的，说明状态诊断 + 状态条件选择本身已带来大部分收益，但**执行反馈驱动的策略演化仍带来约一个数量级的额外提升**。
- **过程发现**：训练损失、决策物理分数与审计物理分数演化非均匀、改善速率不同，表明主导瓶颈会迁移；相同症状（如停滞）在不同诊断状态下需要不同干预（局部专家、Fourier 分支、自适应采样、拓扑分裂等）。
- **成本结论**：相同预算下仅增加约 **4.6%** 墙钟时间，实现"就地变形"而非重启训练。

前或跨独立运行搜索配置"两类局限，把"何时自适应什么"变成可在线求解的决策问题；同时用留出决策集/审计集构建了不依赖参考解的诊断-评估闭环。

- **归因机制严谨**：针对"继续训练本身也会改善"这一根本性归因难题，设计冻结延续估计（鲁棒对数线性外推 + 冻结不重拟合 + 无影子训练），并以双留出集一致性、置信度门槛、组件级退化约束来抑制噪声与虚假信用，方法论上比"干预前后直接比较"更可靠。
- **干预空间异质且可执行**：动作空间横跨拓扑、表示、目标、梯度、采样与优化器六大族，且通过 16 个高层动作 + 23 个原语机制落到具体实现；配合函数保持初始化、优化器状态兼容迁移与失败回滚快照，使"在线变形"在不重启训练的前提下具备工程可行性。
- **闭环设计完整**：从诊断 → 策略种群 → 打分选动作 → 执行 → 信用归因 → 策略演化的全链路闭合，五个演化模式（精炼/物理引导/架构引导/综合/新颖性）在探索与利用间形成分工。
- **成本可控**：就地适配而非重启，使 20,000 步预算下墙钟开销仅增加约 4.6%，LLM 调用次数（38 次）与 token 量均在可接受范围，具备实用价值。
- **实验覆盖面较广**：13 个 PDE 跨越 1D–5D、规则/复杂几何、非线性/多尺度/长时间动力学，5 个种子报告 mean ± std 与 Friedman 排名，主实验与消融均控制变量严格。

## 八、局限与不足

- **算力信息不完整**：未报告 GPU 型号/数量与总训练时长，仅给出墙钟时间与 token 量，难以评估绝对计算成本与可复现的资源门槛。
- **统计检验缺失**：未做配对显著性检验（如 Wilcoxon 或配对 t 检验），"全部 13 个任务最优 + Friedman 1.00"虽强，但缺乏对差异显著性的量化支撑。
- **消融粒度不足**：仅 3 个消融变体，未逐一剥离六大动作族与五种演化模式的独立贡献，也未分析 K=5 的策略数量敏感性。
- **超参数敏感性未探讨**：诊断间隔 200 步、结构干预窗口 400–14,000 步、反馈 horizon（100/500/1000）、延续拟合窗口 W=7、置信度阈值 0.35、接受阈值 0.01/0.10 等关键超参均未做敏感性分析，其取值依据与鲁棒性不明确。
- **基线对比范围有限**：未与 Auto-PINN、NAS-PINN、Lang-PINN 等其他自动化设计方法对比，LLM 自动设计仅以 PINNsAgent 为代表。
- **LLM 依赖与稳定性**：策略生成与打分依赖外部 LLM（DeepSeek-V4-Flash / Qwen3.8-27B），不同 LLM 或版本下的行为一致性、随机性影响与成本波动未讨论；temperature 0.7 的策略生成多样性对结果的影响亦未评估。
- **动作执行风险**：剪枝、重分配、直接加层、局部重初始化等不保证函数保持，虽经输出/导数/残差检查与回滚，但检查成本与回滚频率未报告。
- **适用边界未刻画**：论文未系统说明在何种 PDE 类型或训练阶段下 PINNMorph 收益会显著衰减（例如残差已高度均匀或预算极短的情形）。

## 九、对领域的启示与影响

- **范式转变**：把 PINN 自适应从"预设单一族的静态调度"推进为"轨迹内跨族序贯决策"，为 PINN 训练优化提供了一个新的问题框架——核心问题从"用哪种自适应"变为"在何时对哪个瓶颈做哪类干预"。
- **LLM 的新角色**：LLM 不再仅用于训练前配置搜索或代码生成，而被用作**在线结构化干预的实例化与策略演化引擎**，配合非 LLM 的确定性打分器，形成"LLM 提策略 + 规则做裁决"的混合架构，为 LLM 与数值优化的结合提供了可借鉴的分工范式。
- **归因方法贡献**：冻结延续估计与双留出集信用机制，为任何"在线干预 + 持续训练"场景提供了通用的因果式效果评估思路，可迁移到其他科学机器学习训练流程。
- **瓶颈迁移视角**：实验证据支持"主导瓶颈在同一轨迹内迁移"这一经验观察，提示未来自适应方法应以状态条件而非固定优先级为设计中心。

## 十、可复现性与开放性

- 论文给出了明确的实现细节：基础网络结构（4×128 MLP、tanh）、优化器（Adam lr 1e-3 + L-BFGS lr 1.0）、诊断频率、干预窗口、反馈 horizon、动作空间规模与 LLM 配置，具备较高的方法级可复现性。
- 但缺少 GPU 资源、代码/数据开源状态、参考解生成方式与随机种子具体数值的说明，完全复现仍存在障碍。
- LLM 组件的非确定性（temperature 0.7 生成、0.0 打分）与 API 版本漂移，可能影响结果稳定性，需在复现时加以控制。

## 十一、总体评价

PINNMorph 的核心贡献在于**问题重构而非单点技巧**：它将 PINN 训练中的自适应选择显式建模为同一条优化轨迹内的序贯决策问题，并以"留出诊断-策略种群-结构化干预-冻结延续归因-策略演化"的完整闭环加以求解。其方法设计在归因严谨性、干预异质性与工程可行性三方面均有明显用心，实验在 13 个 PDE、5 个种子上取得一致最优与 Friedman 1.00 的强结果，消融也清晰地区分了"状态条件选择"与"执行反馈演化"两级收益（分别约为 10.77× 与 10.30× 的中位误差比，后者再相对前者带来额外提升）。

其主要短板在于**统计严谨性与超参数分析不足、消融粒度较粗、算力信息缺失以及 LLM 依赖带来的稳定性与成本不确定性**。总体而言，该工作为 PINN 自适应提供了有说服力的新范式与较完整的实证支撑，但其结论的稳健边界、资源门槛与在更广泛 PDE/LLM 条件下的可迁移性，仍有待后续工作验证。
