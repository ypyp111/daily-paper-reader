## 摘要
现有的合成偏微分方程（PDE）求解器的方法主要依赖自回归模型，然而在处理本质上局部化的错误时，其全局从左到右的解码方式会产生大量冗余。在这项工作中，我们挑战了这一低效范式，提出了DiffPDE，一个利用离散扩散语言模型进行针对性代码修复的框架。通过引入局部重新掩码和填充策略，DiffPDE仅重新生成错误区域，同时保留正确的上下文，从而自然地使生成过程与PDE错误的稀疏特性对齐。此外，为了处理需要顺序干预的耦合错误，我们提出了迭代调试GRPO（ID-GRPO），一种强化学习方案，通过中间奖励在单个轨迹内实现多轮调试。在PDEBench上的实验表明，DiffPDE达到了具有竞争力的精度，优于同规模的自回归模型，并显著加速了修复过程。

## Abstract
Existing approaches for synthesizing Partial Differential Equation (PDE) solvers predominantly rely on autoregressive models, yet their global left-to-right decoding incurs substantial redundancy when addressing inherently localized bugs. In this work, we challenge this inefficient paradigm and propose DiffPDE, a framework leveraging discrete diffusion language models for targeted code repair. By introducing a localized re-masking and infilling strategy, DiffPDE regenerates only erroneous regions while preserving correct context, naturally aligning generation with the sparse nature of PDE errors. Furthermore, to handle coupled bugs requiring sequential interventions, we present Iterative Debugging GRPO (ID-GRPO), a reinforcement learning scheme that enables multi-round debugging within single trajectories via intermediate rewards. Experiments on PDEBench show that DiffPDE achieves competitive accuracy, outperforms same-scale AR models, and significantly accelerates repair.

### 核心问题
> 本文尝试解决的核心问题是：能否用扩散语言模型替代自回归模型，在 PDE 求解器生成与修复任务中实现更高效、更精准的局部化调试？

### 整体含义

- 该范式改变了“一犯错就全文重写”的传统修复逻辑，更贴合 PDE 代码错误稀疏、局部性的实际规律，代表了 LLM 驱动科学计算代码生成中一个值得关注的方向。

## 2. 论文提出的方法论

### 2.1 核心思想
DiffPDE 利用离散掩码扩散语言模型的**双向上下文建模**能力，实现两类互补任务：
- **从零生成（from-scratch generation）**：给定 PDE 任务描述，生成 CoT 推理路径和完整可执行求解器代码；
- **局部化填充（localized infilling）**：仅将代码中疑似错误的连续片段替换为 `[MASK]`，在完整左右上下文条件下补全错误区段。

### 2.2 关键技术细节
**（1）局部重新掩码与填充（Localized Re-masking and Infilling）**
- 对原始代码序列 x₀，被修复区间为 `[l, r]`，模型建模条件概率：
  `pθ(x₀,l:r | x₀,<l, x₀,>r)`
- 与自回归模型只能看左侧上下文不同，dLLM 可同时利用左右两侧信息，特别适合 PDE 代码中变量依赖、张量形状关系紧密的场景。

**（2）训练流程**
- 分为两阶段：
  1. **监督微调（SFT）**：优化掩码扩散条件目标
  `L_SFT = -E_{q,x₀} E_t [ ∑_{i∈M_t} log pθ(x₀,i | x_t, q)]`
    噪声水平 t 高的对应于从零生成，t 低的对应局部填充，同一目标同时培养两种能力。
  2. **强化学习（RL）**：使用本文提出的 **ID-GRPO**。

**（3）ID-GRPO（Iterative Debugging GRPO）**
- 设计目标：解决 PDE 求解中**耦合错误**需要多轮顺序修复但反馈稀疏的问题；
- 核心机制：
  - **任务分配与动态缓冲区**：每轮 RL 既做生成式 rollout，又将成功求解器构造为“合成填充任务”、失败代码作为“错误驱动的填充任务”，两者以衰减比例混合，形成从易到难的课程学习；
  - **多轮奖励（Multi-Round Reward）**：基础奖励 r⁺ 根据代码是否可执行且 nRMSE 是否低于阈值给出；额外引入中间奖励 r_inter，当相邻两次执行反馈的错误签名集合出现严格缩减时给分（系数 β），r_MR 取所有尝试中最高奖励加累计中间奖励，以此提供密集的优化信号。

### 2.3 推断阶段流程
生成–执行–调试循环：
1. 由 PDE 描述生成初始求解器；
2. 执行并评估结果；
3. 失败时基于 traceback 自动定位错误代码行及其自然边界；
4. 上屏局部掩码，通过 dLLM 做 infilling 修复；
5. 反复迭代直到满足预算或成功。
