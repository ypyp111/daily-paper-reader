## 摘要
本文重新阐述了数据驱动的非线性常微分方程（ODE）发现这一问题，并提出了一种新的可解释机器学习（ML）方法。该方法旨在仅凭单一状态轨迹的数据，在缺乏系统物理先验知识的情况下，学习非线性动力学的未知向量场。所提方法与现有方法存在两个根本性区别：1）本方法的公式推导基于泛函分析与算子理论；2）代价函数在函数空间中构建，是两个函数之间的距离积分，而非现有机器学习方法中所使用的离散误差和。本文提出了一种增量学习算法，以在线方式处理新的训练样本，从而学习未知向量场。该方法既能从受迫系统也能从无受迫的自治与非自治（或时变）动力系统中发现未知向量场，并能同时发现作为时间函数的未知外部力以及未知底层动力学。最后，通过数值算例验证了所提方法的优势。

## Abstract
In this paper, the problem of data-driven discovery of nonlinear ordinary differential equations (ODEs) is recast, and a new interpretable machine learning (ML) method is proposed. The proposed method aims to learn the unknown vector field of nonlinear dynamics without prior knowledge of the system's physics from only one single state trajectory's data. The proposed method has two fundamental differences with existing methods: 1) the formulation presented in this method is derived based on Functional Analysis and Operator Theory, and 2) the cost function is constructed in the function space as a distance between two functions as an integral, instead of the discrete-sum of errors used in existing ML approaches. An incremental learning algorithm is proposed to learn the unknown vector field to handle new training samples in an online manner. The proposed method can discover the unknown vector field from both forced and unforced autonomous and non-autonomous (or time-varying) dynamical systems. The proposed method is able to simultaneously discover unknown external forces as a function of time and unknown underlying dynamics. Finally, numerical examples are given to demonstrate the advantages of the proposed method.

# 《基于泛函分析的未知非线性微分方程的数据驱动学习》论文详细总结

## 1. 核心问题与研究动机

- **核心问题**：在缺乏系统物理先验知识的情况下，如何仅凭数据来发现（辨识）未知非线性常微分方程组（ODE）的向量场（即底层动力学）。
- **背景与动机**：现实中很多过程（电路、等离子体、流行病学、神经科学、生物系统）由 ODE 描述。传统做法依赖专家知识人工建模，成本高且难以处理强非线性。现有数据驱动方法总体分为两类：
  - **黑箱模型**（如神经 ODE、神经网络算子等）：不可解释、泛化能力有限、需要大量数据、训练不稳定；
  - **可解释模型**（如 SINDy、符号回归、Koopman 算子、EDMD 等）：依赖数值导数近似、需要预先构造合适的基函数/字典，难以同时处理外力与时变系统，且大多不支持增量学习。
- **已有方法的瓶颈**：
  - 离散误差和无法建模样本间时间顺序/连续性关系；
  - 多数方法需要多条轨迹或多组输入-输出数据；
  - 对外部时变输入（尤其是与系统动力学同时未知）的处理能力不够；
  - 缺少增量/在线学习机制，难以适应数据持续到达的实时场景。
- **研究目标**：提出一种可解释、仅需一条状态轨线数据、能同时辨识未知动力学与未知外部激励、支持增量学习的非线性系统辨识框架——FINS（Functional-Analysis-Based Identification of Nonlinear Systems）。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想（两大根本区别）**
  1. 将 ODE 发现问题建立在**泛函分析与算子理论**框架上，而非直接拟合残差或解 IVP；
  2. 代价函数在**函数空间**中构造为**两个函数之间的积分距离**，而非离散误差平方和。
- **问题重构（积分形式与线性算子）**
  - 考虑系统：$\dot{x}(t)=f(t,x(t))+F(t)$，其中 $f$ 未知、$F$ 为外部输入（可采样、可为零）。
  - 将 ODE 化为积分形式：$x(t)=x(t_0)+\int_{t_0}^t f(s,x(s))ds + \int_{t_0}^t F(s)ds$。
  - 定义**线性算子** $T(f)(t)=\int_{t_0}^t f(s,x(s))ds$（其中 $x(s)$ 是已知轨线），从而把“辨识未知向量场”转化为“在函数空间 $L^2_\varphi(\mathbb{R}\times\mathbb{R}^n,\mathbb{R}^n)$ 中最小化 $\|T_k(f)-\text{已知项}\|_{L^2_w}$”的无穷维优化问题。
- **函数空间与基函数**
  - 引入带高斯权重的 Hilbert 空间，状态轨线所在空间带权重 $w(t)$；
  - 使用在 $\mathbb{R}$ 上正交的 **Hermite 多项式**（非有界域上的正交基）对 $f(t,x)$ 展开；
  - 对 $x=[x_1,\dots,x_n,t]^\top$ 各维分别选取最高次数 $N_i$，将 $f$ 近似为有限项：$\hat f(t,x)=C\,H(x,t)$。
- **定理 1（问题等价转换）** ：原始函数空间最小化问题可化为如下的二次优化问题：
  $$\min_{C_k} \; C_k^\top Q_k C_k + P_k^\top C_k + U_k$$
  其中 $Q_k$ 为积分型 Gram 矩阵，$P_k$、$U_k$ 由数据构造；若 $Q_k$ 半正定则归结为求解线性方程 $2\tilde Q_k C^{l*}_k=-P^l_k$。
- **导数近似无关（间接法）** ：方法不需要通过有限差分近似状态导数（不同于 SINDy），降低了采样率和噪声苛刻要求。
- **增量学习（核心亮点）**
  - 利用梯形公式近似积分（对标 NODE 的数值积分器，但**不需要 ODE solver**），将 $Q_k$ 和 $P_k$ 的更新设计成递推式——每新增一个数据点只需基于前一时刻结果做增量更新，适合在线/持续学习场景。
  - 算法以封闭的递推公式维护 $K_k$（积分核）、$\tilde Q_k$ 和 $P^l_k$ 等量；
  - 使用全部到达数据，支持非均匀采样时间。
- **稀疏促进版本 FINS$_s$**：将每个状态分量的参数估计加上 $\ell_0$ 稀疏约束（压缩感知式），得到更简洁的模型。
- **Algorithm 1 总体流程**：
  1. 输入数据集 $D_t$、Hermite 基次数、权函数等；
  2. 初始化 $\tilde Q_0=0$、$P^l_0=0$ 等；
  3. 每个新数据点到达时按递推式更新 $\tilde Q_k$ 和 $P^l_k$；
  4. 解线性方程（或稀疏优化）得到系数矩阵 $C^*_k$；
  5. 输出 $\hat f_k(t,x)=C^*_k H(x,t)$。

## 6. 主要结论与发现

1. **单轨迹可学**：只要未知向量场可用有限次多项式表示，仅用一条状态轨迹数据就能辨识（甚至精确恢复）未知非线性动力学。
2. **同时辨识外力**：可同时发现未知系统动力学和随时间变化的外部激励（如 $0.01\,t^2$ 能精确恢复，见式 (31)）。
3. **适用系统范围广**：同时覆盖自治/非自治、受迫/无受迫和时变系统；对带已知外力的 Duffing 也能正确辨识。
4. **方法对比优势**：
   - 无噪声 Duffing/Van der Pol/Lorenz 预测误差通常比 SINDy 低一个量级以上、远低于 EDMD；
   - 均匀采样下优于/相当于 KLT 与 SINDy；噪声场景（SNR=20）中 FINS 比 SINDy/FINS$_s$ 更稳；
   - 增量更新单条样本仅毫秒级，适合实时/在线学习。
5. **非多项式局限**：FINS/FINS$_s$ 对非多项式向量场/输入无法完全辨识，但能辨识其中多项式部分（如 $\dot x=y$ 的线性部分；Mathieu 部分轨迹拟合）；
6. **多项式阶选择影响显著**：阶数不够则欠拟合，阶数过高则过拟合/数值不稳定（见表 9）；
7. **无需导数近似**：表明其为间接法，对粗糙采样/测量噪声有先天优势。

## 7. 优点与亮点

- **理论新颖且严谨**：以泛函分析与算子理论为框架，将 ODE 发现重塑为函数空间中的线性算子逆问题；有至少两处完整证明支撑（线性算子、二次化约简）。
- **积分误差带来的结构优势**：时间上积分建模能够利用样本的时间先后/连续平滑结构；不需要在训练循环内调用 ODE 解算器。
- **免导数估计**：从根本上绕开 SINDy 等对数值微分的极度敏感问题。
- **增量学习机制**：闭环递推给出数据到达时 O(1) 量级更新，内存占用固定（只需存储当前 $Q$、$P$ 等），支持隐私/可持续 AI 场景部署。
- **“初始条件无关”**：适用于非零初始条件，误差目标中对初始项做了显式补偿。
- **可解释性**：基函数展开得到的模型是显式的低度多项式/显式函数，而非黑箱 NN。
- **稀疏化扩展平滑**：在二次目标上可直接施加 $\ell_0$ 约束得到更紧简洁模型。
- **计算效率高**：比 NN 类方法快约 5 个数量级，且求解并行化容易（每分量独立解方程）。

## 8. 不足与局限性

- **理论/前提限制**
  - 必须提供**全部状态（或全部输入-状态）的采样**，不适用于仅输入-输出数据的场景；
  - Hermite 展开需要预先截断有限次数，非多项式项（正余弦、指数等）不能精确重建；
  - 噪声鲁棒性虽然用单例说明了，但**缺普遍性收敛/复杂度理论证明**；
  - 对增量算法的渐近一致性和有限时间影响也只在数值上说明。
- **维度灾难**
  - 系数数量随状态维数/最高次数指数增长（若 $N$ 相同，则 $\tau\sim N^{n+1}$），高维/大搜索空间不实际；论文只给出分布式求解的展望，未实际实现。
  - 基函数阶数选择没有自动化流程（作者在论文中承认未来将开发自动搜索算法）。
- **实验覆盖不全面**
  - 没有实际测量数据/真实物理平台进行验证；
  - 噪声场景仅一个 SNR=20 固定水平，也没有花较大篇幅对比

- 噪声场景仅设一个 SNR=20 的固定水平，没有对不同信噪比（如 5、10、30 dB）、非高斯噪声或输出噪声做系统性扫描，因此其噪声鲁棒性结论属于单点验证，缺乏统计支持；
- 非均匀采样的实验只在少数算例中展示，未分析采样间隔的随机分布、最大间隔与动力学特征时间尺度的关系；
- 对 Hermite 截断阶数、高斯权重函数宽度等超参数的影响仅做了初步示例，没有系统的敏感性分析与自动选择准则；
- 外部激励 $F(t)$ 虽可未知，但前提是每个时刻的输入值可以采样得到；若外部输入完全不可观测，方法会退化为自治辨识，无法将外力项与自激动力学明确分离；
- 增量学习的收敛速度、数值稳定性以及对数据遍历性的依赖缺少理论刻画，论文只在数值实验上证实“可行”；
- 研究假设状态轨迹 $x(t)$ 连续且足够光滑、可被多项式基在有限时间窗内较好逼近，对于具有滑模、脉冲、迟滞或快速振荡的系统，其适用性仍很有限；
- 论文未明确说明是否开源实现；若要复现并迁移到实际系统，仍有一定工程成本。

## 9. 总体评价与启示

**学术价值**：FINS 是系统辨识领域一篇理论驱动型、方法新意突出的工作。它把泛函分析中的线性算子、再生核 Hilbert 空间思想与数值积分递推结合，为“从一条轨迹学习 ODE”提供了不同于现有黑箱或字典回归的第三条路径，其“增量更新 + 无导数估计 + 显式模型”的组合在实时/在线辨识场景中尤其具有吸引力。

**方法局限性提醒**：该方法的优越性主要面向**可多项式近似、状态全观测、离线或增量采样**的确定性非线性系统；对高维、部分观测、强非多项式、复杂噪声背景以及真正在线流式系统中的表现，仍需更多验证和扩展。所以读者应将其视为一种理论基座坚实的“新技术框架”，而非万能的系统辨识黑盒工具。

**对未来研究的启示**：后续工作可以在三个方向延伸：(1) 自适应选择基函数与截断阶数（如贝叶斯模型选择或嵌套寻优）以消除人为设定；(2) 将算子逆问题推广到随机微分方程、时滞微分方程或偏微分方程，扩展现有框架覆盖范围；(3) 与深度特征或降维方法融合，在潜空间中用该算子方法辨识，以缓解维度灾难并处理部分观测。

总体而言，本文对 ODE 辨识中“利用时间连续性”这一信息做了优雅而有效的建模，取得了精度、可解释性与训练成本上的显著优势，是一篇值得后续研究者深入借鉴的理论驱动型数据科学代表作。
