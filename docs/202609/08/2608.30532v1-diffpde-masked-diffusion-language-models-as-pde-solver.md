## 摘要
现有的偏微分方程（PDE）求解器合成方法主要依赖于自回归模型，然而其全局从左到右的解码方式在处理本质上局部化的错误时会引入大量冗余。在这项工作中，我们挑战了这一低效范式，并提出了DiffPDE，一个利用离散扩散语言模型进行针对性代码修复的框架。通过引入局部重新掩码和填充策略，DiffPDE仅重新生成错误区域，同时保留正确的上下文，使生成过程自然地与PDE错误的稀疏性对齐。此外，为了处理需要顺序干预的耦合错误，我们提出了迭代调试GRPO（ID-GRPO），一种强化学习方案，通过中间奖励在单次轨迹内实现多轮调试。在PDEBench上的实验表明，DiffPDE达到了有竞争力的精度，优于同规模的自回归模型，并显著加速了修复过程。

## Abstract
Existing approaches for synthesizing Partial Differential Equation (PDE) solvers predominantly rely on autoregressive models, yet their global left-to-right decoding incurs substantial redundancy when addressing inherently localized bugs. In this work, we challenge this inefficient paradigm and propose DiffPDE, a framework leveraging discrete diffusion language models for targeted code repair. By introducing a localized re-masking and infilling strategy, DiffPDE regenerates only erroneous regions while preserving correct context, naturally aligning generation with the sparse nature of PDE errors. Furthermore, to handle coupled bugs requiring sequential interventions, we present Iterative Debugging GRPO (ID-GRPO), a reinforcement learning scheme that enables multi-round debugging within single trajectories via intermediate rewards. Experiments on PDEBench show that DiffPDE achieves competitive accuracy, outperforms same-scale AR models, and significantly accelerates repair.

## 1. 核心问题与研究动机

- **背景与动机**：偏微分方程（PDE）是众多物理现象（如流体动力学、反应扩散等）的数学基础，但正确、高效地实现其数值求解器需要深厚的领域专业知识。近年来，利用大语言模型（LLM）自动生成科学代码（特别是 PDE 求解器）成为新兴研究方向。
- **传统范式的局限**：现有 LLM 驱动的 PDE 求解器生成与修复方法几乎都基于自回归（AR）模型。AR 模型本质上是全局从左到右解码。然而，执行错误通常只集中在代码的某个局部片段，AR 模型在修复时必须重新生成全部上下文及后续 token，导致大量冗余计算与高推理时延。
- **核心矛盾**：程序调试行为具有**局部性**，而 AR 模型的**全局解码**在结构上并不适配这种需求。
- **机会点（关键空白）**：离散扩散语言模型（dLLM）具有双向建模能力，能够同时利用掩码 token 左右两侧的上下文，在每一个反向步骤并行地预测所有掩码位置，从根本上为构造"只修复错误片段、保留正确代码"的局部化修复策略提供了可能。

## 2. 方法论

本文提出 **DiffPDE** 框架，以 dLLM 作为骨干模型，绕过 AR 模型的全局解码瓶颈，核心是**局部重掩码 + 填充（infilling）修复**与**面向修复的强化学习**。

- **PDE 任务规范化**：将 PDE 数值求解形式化为代码生成任务，输入 PDE 描述返回可执行的 Python 求解器，并规范训练与评估的输入输出张量形状与接口（如返回 [B, T+1, N] 时空张量）。
- **局部化重掩码与填充策略**：代码"从零开始生成"时采用类似 LLaDA 的半自回归策略（逐块生成与扩散细化相结合），先产生规划数值格式与离散化的 CoT 推理链，再生成代码。**Span 填充**则是核心创新：给定完整序列与待修复的错误区间 [l, r]，通过保留左右上下文并仅将故障代码替换为掩码 token，以双向条件预测修复候选区间的目标文本。
- **统一的两阶段 SFT 训练**：通过在连续长度的代码片段上施加"随机掩码"模拟不同噪声等级（t），
   - 高噪声暴露对应"从零开始生成"；
   - 低噪声暴露对应"局部填充"；
   使得单一目标函数能同时教给模型两种能力：合成全新求解器，以及修复局部的现有缺陷。
- **ID-GRPO（Iterative Debugging GRPO）**——本文的强化学习核心创新：
   - **任务分配与动态缓冲区机制**：RL 每步中，先由生成 rollout 得到候选代码，针对其执行成功与否，分别构造出"合成填充任务"（成功代码随机掩码而成）与"错误驱动的填充任务"（基于执行堆栈定位的错误行上下界，由 traceback、缩进等边界确定修复区间映射而来）。通过随训练动态改变两类任务的采样比例，自然地实现了课程学习。
   - **多轮中间奖励模型**：针对耦合错误标签单一、时序链长的问题，通过对比相邻两次执行的错误信息来判断是否出现严格"误差签名集缩减"或错误消息长度显著缩短，以此给出中间奖励引导策略改进，并在最终累计取最优候选的得分作为总体奖励。奖励计算使用差分加权（能够正确运行且精度超过阈值 nRMSE ≤ τ 得 1.0；运行成功但未达标得 α（如 0.5）；语法错误得 -1.0）。

## 6. 主要结论与发现

- 在 PDE 求解器修复这类真实工作负载上，dLLM 从能力完全对得上错误空间——可以媲美或更优于同规模 AR LLM 完成求解器生成。
- 局部化的双向掩码 "只修复该改的位置"，不仅不牺牲精度（其中 Advection 上反超 GPT-5.2，在 Reaction-Diffusion 匹配大模型最优），而且能使重复调试的时间从通常数十秒级下降到 **不足 1 秒**（0.6~1.0 秒 vs AR 方法的 20→120 秒量级；片段级别约 86× 加速，端到端最坏时间也降一半量级）。
- 强化学习中 "任务分配 + 中间奖励" 的多轮设计可以显著提升错误候选修复的稳定性和有效性正确率（提升平均 Pass@32 到 0.52）。
- **实验获得的额外洞察**：绝大多数初始失败模式是局部性错误（占比 ~76.8%），这反向印证了局部重掩码策略与现实程序缺陷形态的一致性。

## 7. 方法亮点分析

- **以形态驱动范式更替**：从实际问题特征（bug 局部稀疏分布）重构生成架构的定位，而非简单地把新型架构嫁接到旧流程上。
- **统一化训练流程**：巧妙地将从零开始生成与修复两种能力编码成同一个 masked prediction 目标并通过噪声量的自然梯度衔接起来—保持了损失的紧致性。
- **RL 的工程设计**：为解决多轮耦合修复中的稀疏反馈任务，动态缓冲器使构建型任务与真实错误驱动型任务比例可控，以自然形成课程学习，并给强化学习的训练爬坡赋予稳定启动基座。
- **评测聚焦过程成本而不只是精度**：专门区分初始生成效率与修复生成效率，较清晰地揭示了两类非线性加速，对于评估真实交互 Agent 很有意义。
- **充分的负样本报告**：对 AR 修复耗时高、部分 PDE 失败率和全局结构性失败无法修复等现状均展开了坦诚说明。

## 8. 不足与局限

- **从零开始的初始生成仍是效率短板**：即使采用半自回归块级加速，DiffPDE 的首次代码生成仍比同规模 AR 基线更慢（如表 3 中的 CNS 耗时 85.6s），可能不利于第一发成功率过低时的端到端体验。
- **全局结构性错误处理能力有限**：失败分析表明仍有 ~5.4% 的全局错误和 ~17.9% 的格式/无 solver 错误，此类需要跨函数大面积重构的缺陷完全在局部填充方法能力范围之外。
- **只覆盖有限 PDE 家族**：1D/小型 2D 算例（Advection→2D Darcy）为主，缺乏在 3D、多物理耦合、非结构化网格、更高强度的数据驱动 PDE 基准上的扩展表现证据。
- **训练流程依赖于高质量外部可执行的轨迹数据**（由一个较高容量的老师模型生成进行 SFT 与奖励环境），这在高门槛专有环境下不一定可复现。
- **分配机制中还存在启发式成分**：构造型样本与真实错误样本采样比的消融图未进一步探索课程切换长度对收敛的影响，对 RL 中最优启发式的确定更多依赖经验取值。
- **某些极端困难设置的 Pass@32 仍明显偏低**（如 Darcy Flow 0.09、Reaction-Diffusion 0.28），提示整体数值推理正确度的一致性布局仍需突破。
