## 摘要
部署在真实物理系统上的代理模型很少能在固定分辨率下看到数据：传感器配置因部署而异，并可能随着传感基础设施的变化而随时间演变。我们提出潜在孪生算子（Latent Twin Operator, LTO），一种用于时变 PDE 的潜空间代理模型，其编码器和解码器采用卷积条件神经过程（ConvCNP）风格，可接受由 $N$ 个任意放置的传感器观测组成的上下文集，并可在任意分辨率下查询。一个学习得到的潜在演化映射可在任意时间点之间直接推进编码状态，从而将时间演化与观测和查询的离散化解耦。我们推导了在拟一致加密下，空间维度 $D$ 中上下文离散化误差的显式 $\mathcal{O}(N^{-2/(3D)})$ 速率。我们在二维热方程基准上通过实验验证了所预测的衰减。在时变 PDE 基准上，LTO 在单步比较中达到高精度，并能在参数固定的情况下从原生空间分辨率迁移到更粗的空间分辨率。在 Navier--Stokes 方程上，相对于递归评估，其直接潜在演化在更长的预测时域上进一步降低了误差。

## Abstract
Surrogate models deployed on real physical systems rarely see data at fixed resolutions: sensor configurations vary across deployments and may evolve over time as sensing infrastructure changes. We introduce the Latent Twin Operator (LTO), a latent-space surrogate for time-evolving PDEs with a Convolutional Conditional Neural Process (ConvCNP)-style encoder and decoder that accepts a context set of $N$ sensor observations with arbitrary placement and can be queried at any resolution. A learned latent evolution map advances the encoded state directly between arbitrary time points, decoupling temporal evolution from the observation and query discretizations. We derive an explicit $\mathcal{O}(N^{-2/(3D)})$ rate for the context discretization error in spatial dimension $D$ under quasi-uniform refinement. We verify the predicted decay empirically on a 2D heat-equation benchmark. Across time-dependent PDE benchmarks, LTO achieves strong accuracy under one-step comparisons and transfers from native to coarser spatial resolutions with fixed parameters. On Navier--Stokes, its direct latent evolution further reduces error over longer prediction horizons relative to recursive evaluation.

# 《Latent Twin Operator（潜在孪生算子）》论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **现实痛点**：部署在真实物理系统上的代理模型（surrogate model）极少在固定分辨率下获取数据。传感器配置因部署场景而异，且会随传感基础设施变化而演化，导致输入/输出离散化（观测点位置、数量）不断变化。
- **关键概念——离散化不变性（discretization invariance）**：学习型 PDE 代理模型应能在稀疏、密集或非规则观测下输入，并在任意所需分辨率下输出，而不绑定于训练时的离散化。
- **现有架构的局限**：
  - **FNO（Fourier Neural Operator）**：核心操作用 FFT，标准形式要求规则网格；非均匀傅里叶变换或插值需要额外机制。
  - **DeepONet**：trunk 网络允许任意查询位置，但 branch 网络绑定固定的输入传感器位置。
  - 二者在标准形式下均无法直接接受可变大小、非规则放置的上下文集，需重采样或改造。
  - Gao et al. (2025) 指出，在不同离散化上评估会引入**离散化失配误差**；Lanthaler et al. (2024) 从理论上表明 FNO 的分辨率无关性并非自动成立。
- **理论背景**：本文建立在 Latent Twin 框架（Chung et al., 2026; 2027）之上——该框架形式化了 encode → evolve → decode 范式并给出潜空间代理的逼近理论，但其离散化误差项 $\epsilon_{\text{disc}}(N)$ 保持抽象。**LTO 的贡献在于将其具体化为可显式计算的散点数据重构误差，并给出收敛率。**

## 2. 方法论：核心思想、技术细节与算法流程

### 2.1 总体架构（encode → evolve → decode）

- 定义算子：$\Psi_{s,c_{ctx},u_s}(t,c_q) := d\big(m_{s\to t}(e(u_s(c_{ctx}), c_{ctx})), c_q\big)$
  - $e$：编码器，把观测上下文映射到潜状态；
  - $m_{s\to t}$：潜演化映射，直接把状态从时刻 $s$ 推进到 $t$；
  - $d$：解码器，在任意查询点输出物理量。
- **时间演化完全在潜空间进行**，不经过物理坐标的往返，因而与观测/查询离散化解耦。

### 2.2 分辨率无关编码（SetConv / Nadaraya–Watson）

- 用 ConvCNP（Gordon et al., 2020）风格的**集合卷积（SetConv）** 把无序、可变大小的观测集合映射到固定空间网格上的场。
- 高斯核 $\kappa_\ell(x,y)=\exp(-d_\Omega(x,y)^2/(2\ell^2))$，构造：
  - 密度通道 $\rho_{c_{ctx}}(x)=\sum_j \kappa_\ell(x,c_j)$
  - 信号通道 $\nu_{c_{ctx}}(x;u_s)=\sum_j u_s(c_j)\kappa_\ell(x,c_j)$
  - 归一化估计 $\hat u_{c_{ctx}}(x;u_s)=\nu/\rho$（Nadaraya–Watson 核回归）
- 将 $\rho$ 与 $\hat u$（$p$ 个分量）堆叠为 $(1+p)$ 通道场，经卷积网络 $g_\phi$ 编码为潜状态 $z_s \in \mathbb{R}^{H\times W\times k}$。
- **编码步骤本身无学习参数**（仅后续 CNN 可学），潜表示具有规则空间网格结构，因此演化算子可为普通平移等变 CNN。

### 2.3 分辨率无关解码

- 从演化后的潜状态 $z_t$ 出发，最终在空间网格上做**核加权插值**，在任意查询位置 $c_q$ 求值；查询点的数量与位置可独立于上下文与内部网格。

### 2.4 理论结果

- **编码器稳定性（Lemma A.2 / Corollary A.3）**：归一化通道满足
  $\sup_x |\hat u_{c_{ctx}}(x;u)-\hat u_{c_{ctx}}(x;v)| \le \max_j|u(c_j)-v(c_j)| \le \|u-v\|_U$，
  即 **1-Lipschitz，且常数不依赖上下文点数量、位置与带宽**。相比之下原始通道 $\nu$ 的 Lipschitz 常数随 $\sup_x\rho$ 增长，最坏可达 $O(N)$（把 N 个点聚在某点附近）。
- **假设 2.2（正则性）**：(a) $K\subset C^2$ 且 Hessian 一致有界 $M$；(b) $\Omega$ 周期；(c) 上下文点集可划分为等体积单元 $V_j$，$c_j\in V_j$，$\text{diam}(V_j)\le 2\delta(c_{ctx})$，$|V_j|=|\Omega|/N$（$\delta$ 为填充距离 fill distance）。
- **误差分解**：$\|\hat u_{c_{ctx}}-u\| \le \underbrace{\|\hat u_{c_{ctx}}-\bar u_\ell\|}_{\text{有限上下文求积误差 } O(\delta/\ell)} + \underbrace{\|\bar u_\ell-u\|}_{\text{核平滑偏差 } \le \frac{1}{2}DM\ell^2}$
  - 平滑偏差来自二阶 Taylor 展开，一阶项因核对称性消去。
- **定理 2.3**：$\epsilon_{\text{disc}}(N)\le \frac{1}{2}DM\ell^2 + C_K\frac{\delta(c_{ctx})}{\ell}$。
- **推论 2.4**：取最优带宽 $\ell^\star=(C_K\delta/(DM))^{1/3}$，得 $\epsilon_{\text{disc}}\le C\delta^{2/3}$。
- **推论 2.5（离散化不变性）**：当 $\delta=\Theta(N^{-1/D})$ 时，总误差
  $\le O(N^{-2/(3D)}) + C(1+e^{L_KT})\epsilon_{ae}(N) + C L_{d,N}\epsilon_{map}(N)$。
  对 i.i.d. 均匀采样，由 Penrose (2003) 得高概率率 $O\big((\log N/N)^{2/(3D)}\big)$。

### 2.5 训练目标

- $\mathcal{L}(\theta)=\lambda_{\text{evol}}\mathcal{L}_{\text{evol}} + \lambda_{\text{recon}}\mathcal{L}_{\text{recon}}$，分别为演化损失与重构（自编码）损失，均为相对 $L_2$。
- **上下文规模增强**：训练时每步从 $[c_{\min},c_{\max}]$ 均匀重采样上下文比例 $c_{\text{frac}}$，查询与目标保持全原生分辨率。
- Navier–Stokes 上额外使用 **pushforward trick**（Brandstetter et al., 2022）：15% 的训练步先无梯度自回归展开，再对真实目标做一次监督。

## 6. 主要结论与发现

- **理论**：SetConv 实例化下，离散化误差显式化为 $\epsilon_{\text{disc}}(N)=\mathcal{O}(N^{-2/(3D)})$（准一致细化），结合 Latent Twin 逼近理论得到离散化不变性保证；编码器 Lipschitz 常数与 $N$、点位置、带宽无关。
- **热方程**：闭式重构误差与训练后 LTO 预测误差的 log-log 拟合斜率均接近推论 2.5
