## 摘要
神经算子能够以较低成本求解参数化偏微分方程，但在其训练分布之外性能会急剧下降。物理信息神经网络避免了对标注数据的依赖，但其优化可能具有吸引盆脆弱性：当控制方程残差允许多个解时，从头训练的 PINN 尽管残差很小，仍可能收敛到物理上不正确的状态。我们表明，这些失效模式可以被联合解决：不完美的 NO 提供了将 PINN 置于正确解吸引盆所需的结构先验，而 PDE 残差则将解精化到超过该算子精度的水平。我们提出一个三阶段框架：冻结物理信息 NO 的空间基，利用多项式延拓先验将其解分支外推到分布外参数，并将所得场蒸馏到一个全新的 PINN 中。NO 在目标参数处无需准确；它传递解分支信息，而 PINN 中的 PDE 残差最小化主导收敛。我们在三个非线性 PDE 上评估该框架：一维粘性 Burgers 方程、二维定常 Allen-Cahn 方程（在叉式分岔附近）以及二维定常顶盖驱动方腔流。对于 Allen-Cahn，平凡解精确满足 PDE 残差，标准 PINN 会坍缩到平凡的零分支，而从粗糙外推算子蒸馏则能恢复与有限差分参考解一致的非平凡分支。对于顶盖驱动方腔，外推到雷诺数 Re = 3200 可加速收敛到正确的物理状态，并以比近期文献基线更少的参数和优化步数达到有竞争力的精度。这些结果确立了一个简单原则：NO 无需准确预测解才是有用的；它只需识别出 PINN 优化能够从中恢复出该解的正确吸引盆。

## Abstract
Neural operators evaluate parametric partial differential equations cheaply but degrade sharply outside their training distribution. Physics-informed neural networks avoid dependence on labeled data, yet their optimization can be basin-fragile: when the governing residual admits multiple solutions, a PINN trained from scratch may converge to a physically incorrect state despite achieving a small residual. We show that these failure modes can be addressed jointly: an imperfect NO provides the structural prior needed to place a PINN in the correct solution basin, while the PDE residual refines the solution beyond the operator's accuracy. We introduce a three-stage framework that freezes the spatial basis of a physics-informed NO, extrapolates its solution branch to an out-of-distribution parameter using a polynomial continuation prior, and distills the resulting field into a fresh PINN. The NO need not be accurate at the target; it transfers solution-branch information, while PDE residual minimization in the PINN governs convergence. We evaluate the framework on three nonlinear PDEs: 1D viscous Burgers, 2D steady Allen-Cahn near a pitchfork bifurcation, and 2D steady lid-driven cavity flow. For Allen-Cahn, where the trivial solution satisfies the PDE residual exactly, a standard PINN collapses to the trivial zero branch, whereas distillation from the crude extrapolated operator recovers the non-trivial branch that matches the finite-difference reference. For the lid-driven cavity, extrapolating to a Reynolds number of Re = 3200 accelerates convergence to the correct physical state, achieving competitive accuracy using fewer parameters and optimization steps than recent literature baselines. These results establish a simple principle: an NO need not accurately predict the solution to be useful; it only needs to identify the correct basin from which PINN optimization can recover it.

- **核心答案与整体含义**：可以。NO **不需要准确预测目标解**，只需提供**解分支（basin）信息**，把 PINN 放进正确吸引盆；随后 PDE 残差最小化负责把精度提升到**超过教师算子**的水平。

## 2. 方法论

### 2.1 共享架构（强边界约束 ansatz）

- 解场表示为：`s(x;p) = g(x;p) + M(x) · Σ_k b_k(p) φ_k(x)`
  - `g(x;p)`：满足边界条件的 **boundary lift**；
  - `M(x)`：在边界 ∂Ω 上取零的 **distance multiplier**；
  - `{φ_k}`：trunk 网络产生的**空间基**，`b_k(p)`：branch 输出的系数。
- 由于边界被**精确强制**，训练损失中**不含边界损失项**，仅最小化内部 PDE 残差的 L2 范数。
- 精度指标：相对 L2 精度 `Acc = 1 − ε_L2`，`ε_L2 = ||ŝ − s_ref|| / ||s_ref||`。

### 2.2 三阶段框架

**Part 1：基础算子（Base Operator）**

- trunk 与 branch 联合训练后**冻结 trunk**，得到固定函数空间 `{φ_k}`。
- 在基域内一组基点 `{p_i}` 上构造**锚点系数 `{c_i}`**，作为可信参考系数；三个问题形成锚点的方式不同，体现"外部信息依赖度"的递增谱：
  - **Burgers**：直接存下训练好的 branch 输出（无外部数据）。
  - **Allen–Cahn**：在冻结基上用**阻尼高斯–牛顿**迭代细化残差（仅用残差与精确 Jacobian，**无参考场**）。
  - **Cavity**：在 Re ∈ {100,200,…,800} 上做 **8 次有限差分求解**，用 ridge 最小二乘在速度度量下重投影到冻结基——这是主 cavity 流程**唯一消耗的外部数据**。

**Part 2：基域之外的外推（数据无关）**

- 对每个模态独立拟合**低阶多项式延续先验** `c_cont(p)`，作为 continuation prior。
- **有界修正（Bounded correction）**：目标 `p*` 处重新优化 branch 输出修正量 `Δb`，并加在先验上：
  `b_comp(p) = c_cont(p) + α·tanh(Δb(p))`，`α` 是对先验偏离的硬上限；若先验正确，则 `Δb = 0` 最优。
- **Gram 加权延续惩罚**：`L_total = L_PDE(b_comp) + β·||b_comp − c_cont||²_G(H)`
  - `G(H)` 为冻结基在物理几何（纵横比 H）上的**场度量 Gram 矩阵**，保证惩罚的是"物理场的变化"而非裸系数变化；
  - `β` 按"惩罚项占初始总损失固定比例"标定一次，之后保持常数或**指数退火至小非零下限**，让 PDE 残差逐步主导。
- **增量自供给（incremental self-supply）**：当单步跨度太大时，采用多阶段延拓——先外推到中间目标，收敛后把中间解**追加进锚点池**并重拟合先验，再推进下一阶段。
  - Burgers / cavity 几何变体：1 阶段；Allen–Cahn：2 阶段；cavity 主 Re 外推：4 阶段（`1/Re` 上的 1D 先验）。
- 该阶段**目标不是高精度**，而是产生足以初始化 Part 3 的系数场。例如 Allen–Cahn 近分岔处真解幅值按 `√(λ−λ1)` 标度，多项式先验无法表示，因此外推场在近 onset 处会**可预期地退化**。

**Part 3：守卫蒸馏到全新求解器（Guarded Distillation）**

- 在目标 `p*` 处，把 Part 2 的合成场交给一个**从零训练的 MLP-PINN** `u_φ`；学生**放弃** trunk–branch 分解与专用边界 lift。
- 损失：`L(φ;t) = ||R[u_φ]||²_L2 + λ_BC·L_BC + w(t)·||u_φ − u_teacher||²_Γ(x)`
  - `w(t)`：**时间蒸馏调度**；
  - `Γ(x)`：可选的**空间可靠性门**。
- 两种调度策略（体现模块化）：
  - **分段线性调度**（Allen–Cahn、cavity 主 Re 实验）：`Γ ≡ 1`，`w(t)` 在训练末段**严格归零**（如 `w0=0.7`，前 70% 线性衰减到 0）；
  - **物理自适应调度 + 可靠性门**（Burgers、cavity 几何外推）：`w` 跟踪学生 PDE 残差的指数滑动平均；`Γ(x) = max(1 − tanh(τ·r_φ(x)), Γ_floor)`，在高残差处**局部削弱教师影响**（Burgers τ=2.0，cavity H 外推 τ=20.0）。
  - **两者最终都严格归零**，最终收敛完全由 PDE 与边界约束主导。
- 与经典知识蒸馏的本质差异：教师是**粗糙 OOD 估计**，学生被**期望超越教师**，因此蒸馏权重**衰减而非持续激活**；也与"仅初始化/冻结先验"的 warm-start 方法不同，本文把教师保留为**持久但递减的约束**。
