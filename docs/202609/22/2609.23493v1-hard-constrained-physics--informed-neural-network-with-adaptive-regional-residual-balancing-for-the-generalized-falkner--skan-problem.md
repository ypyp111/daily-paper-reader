## 摘要
我们提出了一种用于广义 Falkner--Skan 边值问题的物理信息神经求解器，它将精确的边界容许试探表示与自适应区域残差平衡（ARRB）相结合。三个给定边界条件被解析地嵌入，从而消除了边界条件惩罚项，同时允许有限域流函数值和壁面剪切由控制方程确定。残差被划分为壁面、中部和尾部区域，并利用区域长度分数由各区域均方误差重构物理全局残差。带保护的指数移动平均逆梯度系数在 Adam 优化过程中自适应地平衡各区域贡献。采用确定性的 800 点残差监测器进行检查点选择，随后进行两个确定性的 L--BFGS 阶段以最小化物理全局残差。该方法在 Blasius、顺压梯度 Falkner--Skan 和 Pohlhausen 案例上进行了测试。对于 \((β_0,β_1)=(0.75,0.50)\)，预测的壁面剪切为 \(f''(0)=0.8997161394\)，与有限域参考值 \(0.8997168085\) 相比，绝对误差为 \(6.691\times10^{-7}\)。残差 MSE 为 \(6.357\times10^{-9}\)，而 \(f'\) 和 \(f''\) 的相对 \(L_2\) 误差分别为 \(2.848\times10^{-6}\) 和 \(4.188\times10^{-5}\)。一项匹配的单种子消融实验表明，与全局残差训练相比，ARRB 将残差 MSE 降低了 52.81\%，与等区域加权相比降低了 50.24\%。壁面剪切误差分别降低了 77.30\% 和 72.37\%。这些结果支持将 ARRB 作为一种面向精度的残差调节策略，但仍需要多种子实验来量化优化变异性。

## Abstract
We present a physics--informed neural solver for the generalized Falkner--Skan boundary-value problem that combines an exact boundary--admissible trial representation with adaptive regional residual balancing (ARRB). The three prescribed boundary conditions are embedded analytically, eliminating boundary-condition penalty terms while allowing the finite--domain streamfunction value and wall shear to be determined by the governing equation. The residual is divided into wall, middle, and tail regions, and a physical global residual is reconstructed from regional mean-squared errors using region-length fractions. Safeguarded exponential--moving--average inverse--gradient coefficients adaptively balance the regional contributions during Adam optimization. A deterministic 800-point residual monitor is used for checkpoint selection, followed by two deterministic L--BFGS stages minimizing the physical global residual. The method is tested on the Blasius, favourable-pressure--gradient Falkner--Skan, and Pohlhausen cases. For \((β_0,β_1)=(0.75,0.50)\), the predicted wall shear is \(f''(0)=0.8997161394\), compared with the finite-domain reference \(0.8997168085\), giving an absolute error of \(6.691\times10^{-7}\). The residual MSE is \(6.357\times10^{-9}\), while the relative \(L_2\) errors in \(f'\) and \(f''\) are \(2.848\times10^{-6}\) and \(4.188\times10^{-5}\). A matched single--seed ablation shows that ARRB reduces residual MSE by 52.81\% relative to global--residual training and by 50.24\% relative to equal-regional weighting. Wall--shear errors are reduced by 77.30\% and 72.37\%, respectively. These results support ARRB as an accuracy-oriented residual-conditioning strategy, while multi--seed experiments remain necessary to quantify optimization variability.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究对象**：广义 Falkner–Skan 边值问题——层流边界层相似解的控制方程，形式为三阶非线性 ODE：
  $$f'''(\eta) + \beta_0 f(\eta) f''(\eta) + \beta_1\left[1 - f'(\eta)^2\right] = 0,\ \eta \in [0, L]$$
  边界条件为 $f(0)=0,\ f'(0)=0,\ f'(L)=1$，其中 $f''(0)$ 为壁面剪切（对近壁解极为敏感）。

- **背景痛点**：
  - 传统 PINN 依赖边界条件惩罚项，导致控制方程精度与边界满足之间存在优化竞争。
  - 即使边界条件被精确满足，同一控制方程残差在不同空间区域（近壁、外层）产生的参数梯度量级差异巨大，单一域平均残差无法揭示这种不平衡。
  - Falkner–Skan 问题虽为一维，但非线性三阶结构、半无限物理域、壁面剪切敏感性使其成为非线性数值方法的良好基准。

- **论文定位**：作者明确声明**不主张硬约束嵌入本身的新颖性**（该思想可追溯至 Lagaris 1998、McFall 2009），而是将 **Falkner–Skan 专属的边界容许试探表示** 与 **自适应区域残差平衡（ARRB）** 相结合，后者作用于硬约束消解边界惩罚竞争之后的、另一类优化不平衡问题。

## 2. 方法论

### 2.1 硬约束试探表示（解析嵌入边界条件）

- 对一般三条件边界集 $f(0)=A,\ f'(0)=B,\ f'(L)=C$，构造提升函数：
  $$b_{A,B,C}(\eta) = A + B\eta + (C-B)\frac{\eta - (1-e^{-\eta})}{1-e^{-L}}$$
  可验证 $b(0)=A,\ b'(0)=B,\ b'(L)=C$。
- 对 Falkner–Skan（$A=0,B=0,C=1$）：$b(\eta) = \eta - \dfrac{1-e^{-\eta}}{1-e^{-L}}$。
- 完整试探解：
  $$\hat f_\theta(\eta) = b(\eta) + c_\theta H(s) + G(s) N_\theta(x)$$
  其中 $s=\eta/L$，$x=2s-1$，$H(s)=3s^2-2s^3$（Hermite 端点模式，满足 $H(0)=0,H(1)=1,H_s(0)=H_s(1)=0$），$G(s)=Ls^2(1-s)^2$（神经掩码，$G(0)=G(1)=G_s(0)=G_s(1)=0$）。
- **关键性质**：$G_{ss}(0)=G_{ss}(1)=2/L$，$H_{ss}(0)=6,H_{ss}(1)=-6$，因此壁面曲率
  $$\hat f''_\theta(0) = \frac{1}{1-e^{-L}} + \frac{6c_\theta}{L^2} + \frac{2}{L}N_\theta(-1)$$
  仍为可训练、由方程决定的量；终端流函数值 $\hat f_\theta(L)=b(L)+c_\theta$ 也保持自由。
- 网络结构 $[1,100,100,1]$，tanh 激活，64 位浮点；末层权重与偏置置零，$c_\theta=0$，初始解恰为解析提升剖面 $b(\eta)$。

### 2.2 区域残差分解与物理全局残差

- 区域划分：$\Omega_w=[0,3]$、$\Omega_m=(3,8)$、$\Omega_t=[8,12]$。
- 区域残差 MSE：$L_r = \frac{1}{|C_r|}\sum_{\eta_i \in C_r} R_\theta(\eta_i)^2$。
- 物理区域长度分数：$\omega_w=1/4,\ \omega_m=5/12,\ \omega_t=1/3$。
- **物理全局残差**：$L_g = \frac{1}{4}L_w + \frac{5}{12}L_m + \frac{1}{3}L_t$，其物理权重独立于随机配点数量（这是与"直接对整批求均值"的关键区别）。

### 2.3 分层配点采样

- 每步 Adam 使用 $N_c=500$ 个配点，按最大余数法分配：$N_w=125,\ N_m=208,\ N_t=167$。
- 每区域内均匀独立采样，首点强制 $\eta=0$、末点强制 $\eta=L$。
- `resample_interval=1`，即每次 Adam 更新前重新采样（无累积自适应加密）。

### 2.4 自适应区域残差平衡（ARRB）

- 代理参数集 $\theta_p$：末层权重+偏置与 $c_\theta$。
- 区域代理梯度范数：$G_r = \|\nabla_{\theta_p} L_r\|_2$；无效值用有效范数的中位数替代，全无效则置 1。
- EMA 平滑：$\bar G_r^{(k)} = \rho \bar G_r^{(k-1)} + (1-\rho) G_r^{(k)}$，$\rho=0.90$。
- 归一化逆梯度系数：$q_r \propto (\bar G_r + \varepsilon)^{-1}$，$\varepsilon=10^{-12}$。
- 带保护的混合：$\lambda_r = \gamma q_r + (1-\gamma)/3$，$\gamma=0.80$，故 $\lambda_r \ge 0.0667$，并重新归一化 $\sum_r \lambda_r = 1$。
- Adam 目标：$L_{\text{Adam}} = \alpha L_g + (1-\alpha)L_{\text{reg}}$，$\alpha=0.50$；等价于 $\sum_r w_r^{\text{eff}} L_r$，$w_r^{\text{eff}}=\alpha\omega_r+(1-\alpha)\lambda_r$。
- **重要澄清**：$\lambda_r$ 只是自适应分量，不代表区域物理重要性；$\lambda_r$ 大意味着该区域梯度贡献偏小、需被放大。自适应系数仅在 Adam 阶段于步 1, 51, 101, … 更新；L-BFGS 阶段冻结。

### 2.5 优化流程（混合协议）

- **Phase I（Adam）**：15000 步，初始学习率 $10^{-3}$，全局梯度范数裁剪 ≤ 1。
- **确定性监控**：800 点均匀网格上的物理全局残差 $J_{\text{mon}}$，在第 1 步后、每 100 步、最后一步评估；接入 `ReduceLROnPlateau`（patience 20，factor 0.5）。
- 首次满足 $J_{\text{mon}} \le 10^{-6}$ 时一次性降学习率：$\mu_{\text{new}} = \max(0.2\mu_{\text{old}}, 10^{-5})$。
- 保存最佳监控检查点（含模型状态与自适应权重状态）。
- **Phase II（L-BFGS）**：两阶段，网格点数 $\max(2000j, 4N_c)$，即 2000、4000 点；目标仅最小化 $L_g$。
- **回滚判据**：候选阶段若使独立 800 点监控值非有限或劣化，则恢复阶段前模型。
