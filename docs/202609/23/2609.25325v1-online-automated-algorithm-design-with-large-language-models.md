## 摘要
大语言模型（LLMs）通过推理和代码合成实现了自动算法设计（AAD）。然而，大多数现有的基于LLM的AAD方法将算法设计与目标优化分离，即使优化状态不断演化，仍部署固定的设计。传统自适应优化器可以对此类变化做出响应，但其调整仍局限于预定义的参数、算子或策略。为解决这些局限，我们提出基于LLM的在线AAD，这是一种新颖的优化范式，将算法本身视为依赖状态的决策变量。在每个阶段，LLM智能体根据当前优化状态合成具有新行为逻辑的算法。执行所生成的算法可推进搜索，并为后续设计提供反馈，从而将算法设计与目标优化耦合起来，且无需单独的离线算法预训练阶段。为实现这一范式，我们提出OnDesign，一个多智能体框架，它协调相互竞争的设计视角以合成可执行算法，并利用执行反馈来改进后续设计中对运行时证据的解读方式。我们在三种场景下、跨两个主流黑盒优化范式评估OnDesign：贝叶斯优化、进化连续优化和进化混合变量优化。在六个基准测试套件和一个工程问题上跨多个问题维度进行的大量实验表明，其整体性能优于传统优化器和离线基于LLM的AAD方法。

## Abstract
Large language models (LLMs) enable automated algorithm design (AAD) through reasoning and code synthesis. However, most existing LLM-based AAD methods separate algorithm design from target optimization, deploying a fixed design even as the optimization state evolves. Conventional adaptive optimizers can respond to such changes, but their adjustments remain confined to predefined parameters, operators, or strategies. To address these limitations, we introduce online LLM-based AAD, a novel optimization paradigm that treats the algorithm itself as a state-dependent decision variable. At each stage, LLM agents synthesize an algorithm with new behavior logic from the current optimization state. Executing the generated algorithm advances the search and provides feedback for subsequent designs, coupling algorithm design with target optimization without requiring a separate offline algorithm pretraining stage. To implement this paradigm, we propose OnDesign, a multi-agent framework that reconciles competing design perspectives to synthesize executable algorithms and uses execution feedback to refine how runtime evidence is interpreted for subsequent designs. We evaluate OnDesign across two mainstream black-box optimization paradigms on three scenarios: Bayesian optimization, evolutionary continuous optimization, and evolutionary mixed-variable optimization. Extensive experiments on six benchmark suites and one engineering problem across multiple problem dimensions demonstrate superior overall performance over conventional optimizers and offline LLM-based AAD methods.

## 1. 核心问题与整体含义

- **研究背景**：LLM 已能通过推理与代码合成实现自动算法设计（AAD），但现有方法大多采用**离线范式**——先在训练任务上生成并评估候选算法，再选定一个固定算法部署到目标任务，设计与执行在时间上分离。
- **两个关键问题**：
  - 离线候选评估需要额外目标评估预算，在评估昂贵时成本高；
  - 部署的算法在整个优化过程中保持固定，无法随优化状态演化而重新设计。
- **传统自适应优化器的局限**：虽能动态调整，但调整范围被限制在预设的参数、算子或策略空间内；当搜索需要超出预设空间的机制时，这类自适应往往不足以维持进展。
- **整体含义**：论文提出 **Online LLM-based AAD** 新范式，把**算法本身视为状态依赖的决策变量**，在每个优化阶段由 LLM 依据当前优化状态合成具有新行为逻辑的可执行算法，实现算法设计与目标优化的在线耦合，无需离线算法预训练。

## 2. 方法论

- **核心思想**：将目标优化与元层算法设计建模为两个耦合的序列决策过程。在阶段 t，LLM 依据设计状态 zt = (st, ht) 合成算法 πt；执行 πt 产生搜索动作 at，推进优化并产生执行增益 rt；rt 反过来更新设计历史，形成闭环：
  `zt → πt → at → (st+1, rt) → zt+1`。
- **OnDesign 框架**：由三个交互模块组成。
  - **模块 1：State Analysis（状态分析）**：State Analyst 依据当前 **State Analysis Guideline（SAG）** 将异构运行时观测 ot 组织为结构化、有证据支撑的状态报告 qt，供后续设计使用。
  - **模块 2：Multi-Agent Deliberation（多智能体协商）**：K 个角色专化的 **Proposer**（如探索导向与利用导向）各自提出设计提案，每个提案包含**设计方向 v、理由 e、设计建议 d**；**Arbiter** 综合相互竞争的设计视角，从状态报告与算法设计历史 Ht 中合成一个可执行算法 πt，而非简单选择某一提案。
  - **模块 3：SAG Evolution（SAG 演化）**：SAG Refiner 依据历史 SAG–得分对，周期性（每 LSAG 个设计阶段）更新 SAG，自适应地改变后续状态报告对运行时证据的解读方式。
- **反馈机制**：执行增益 rt 采用归一化相对改进的平方根（式 31），同时用于更新算法档案 Ht 和 SAG 档案；算法档案决定“下一步设计什么算法”，SAG 档案决定“如何解读用于该设计的运行时证据”。

- 案例研究表明，生成的采集函数在整个运行中反复重构后验均值与不确定性的作用方式，在探索与利用之间动态切换，而非遵循预设调度。

## 7. 优点

- **范式创新**：将算法本身提升为状态依赖的决策变量，把算法设计从离线发现拓展为优化过程中的在线程序合成，定位清晰、动机充分。
- **框架设计合理**：三个模块分工明确，多智能体协商通过竞争性提案与仲裁机制显式处理探索–利用权衡，SAG 演化机制使“如何解读运行时证据”本身也可自适应。
- **理论支撑**：提供性能差距上界，将误差分解为设计空间、表示与合成三部分，并与模块功能一一对应，增强方法可解释性。
- **实验全面**：跨三种优化范式、多种变量类型、多个维度与基准套件，并包含昂贵工程问题验证与详细案例追踪。
- **无需离线预训练**：设计与优化在同一运行内完成，避免了离线候选评估的额外目标评估开销。

## 8. 不足与局限

- **问题规模与类型受限**：评估仅覆盖单目标、最多 30 维决策变量的问题，未涉及大规模、噪声、约束及多目标场景，作者亦在结论中承认这一局限。
- **算力与成本未量化**：未报告 GPU 资源、LLM 调用次数或推理成本；在线每阶段多次 LLM 调用可能带来显著的计算开销与延迟，在评估预算极紧或实时性要求高的场景中可能不适用。
- **基线比较的范式差异**：离线 LLM 基线在离线阶段消耗的评估预算与 OnDesign 在线阶段的预算不可直接对齐，可能影响公平性解读。
- **优势并非在所有配置下显著**：部分配置（如 BO 的 CEC2022 D=10）领先幅度较小，且个别函数上 OnDesign 表现劣于基线。
- **SAG 更新间隔缺乏严格控制**：LSAG 的敏感性分析使用“调整后的示意值”，未构成严格的受控对比，默认值 10 的普适性有待进一步验证。
- **可复现性细节有限**：虽声明代码在补充材料中，但正文未给出 LLM 调用温度、提示长度、失败重试策略等关键工程细节。
