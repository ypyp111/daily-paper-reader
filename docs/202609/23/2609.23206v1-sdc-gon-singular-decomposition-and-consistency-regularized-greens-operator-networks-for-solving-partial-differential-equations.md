## 摘要
基于格林函数的算子近似为求解变化边界条件和源项下的线性偏微分方程提供了一条高效途径。一旦学习到格林函数，新配置的解即可通过积分获得，而无需再次求解微分方程。现有的格林函数学习方法面临两个结构性挑战。第一是格林函数在源点附近的奇异行为，这给神经网络带来了困难的逼近负担。第二是学习到的格林函数与其梯度之间缺乏显式一致性，尽管这两个量都直接进入积分解表示。本文提出 SDC-GON，一种奇异分解与一致性正则化的格林算子网络，在统一框架内解决上述两个挑战。格林函数被分解为解析已知的奇异分量和由网络学习的平滑修正项，从而使神经逼近只针对响应核的正则部分。一种自一致性损失强制使梯度与平滑修正项的自动微分梯度保持一致。该方法在二维泊松、三维热传导、非均相反应扩散和 Stokes 基准上进行了评估，在所有情况下均持续优于所比较的基线。在非均相管道基准上，SDC-GON 以更小的网络架构实现了 $3.70\times10^{-4}$ 的测试误差，而相同宽度的基线为 $9.60\times10^{-4}$，更大配置为 $4.63\times10^{-4}$，这表明结构改进比增加模型规模更有效。

## Abstract
Green's function based operator approximation offers an efficient route for solving linear partial differential equations under varying boundary conditions and source terms. Once the Green's function is learned, solutions for new configurations are obtained through integration rather than by solving the differential equation again. Existing Green's function learning methods face two structural challenges. The first is the singular behavior of the Green's function near the source point, which places a difficult approximation burden on neural networks. The second is the absence of explicit consistency between the learned Green's function and its gradient, although both quantities enter the integral solution representation directly. This work proposes SDC-GON, a Singular Decomposition and Consistency-Regularized Green's Operator Network that addresses both challenges within a unified framework. The Green's function is decomposed into an analytically known singular component and a smooth correction learned by the network, so that the neural approximation targets only the regular part of the response kernel. A self-consistency loss enforces agreement between the gradient and the autodifferentiation gradient of the smooth correction. The method is evaluated on two dimensional Poisson, three dimensional heat conduction, heterogeneous reaction diffusion, and Stokes benchmarks, consistently outperforming the compared baselines across all cases. On the heterogeneous pipe benchmark, SDC-GON achieves a testing error of $3.70\times10^{-4}$ with a smaller network architecture, compared with $9.60\times10^{-4}$ for the same-width baseline and $4.63\times10^{-4}$ for a larger configuration, demonstrating that structural improvements are more effective than increasing model size.

## 1. 核心问题与整体含义

- **研究背景**：偏微分方程（PDE）是流体、传热、结构力学、反应扩散等领域的核心建模工具。传统数值方法（有限差分、有限元、有限体积）稳健成熟，但在参数优化、不确定性量化、反问题等需要**反复前向求解**的场景下，每换一组边界条件或源项都要重新完整求解，计算开销大。
- **Green 函数的价值**：对线性 PDE，Green 函数描述算子的脉冲响应。一旦学到 Green 函数，新源项/边界条件只需通过**积分表示**获得解，无需重新求解微分方程——这正是 Green 函数型算子近似的核心吸引力。
- **核心矛盾**：解析 Green 函数仅对简单几何与常系数算子可得，变系数、复杂域几乎无闭式解。
- **两个结构性挑战**：
  - **源点附近奇异性**：3D Laplacian 的 Green 函数在 $x\to\xi$ 时按 $1/\|x-\xi\|$ 发散，梯度按 $1/\|x-\xi\|^2$ 发散，直接让神经网络拟合这种非光滑核负担极重。
  - **梯度一致性缺失**：Green 函数与其梯度都直接进入积分解，但既有方法（如 GON）用两个独立网络分别学习二者，不强制任何一致性，可能导致边界积分贡献不协调。
- **整体含义**：论文提出 SDC-GON，在统一框架内同时处理奇异性与一致性两个问题，把"学习奇异核 + 无约束梯度"转化为"学习光滑修正项 + 一致的光滑梯度"，并验证**结构改进比单纯增大模型规模更有效**。

## 2. 方法论

### 2.1 核心思想
- 将 Green 函数分解为**解析已知奇异分量**与**网络学习的平滑修正项**：
  $$G(x,\xi) = G_{sing}(x,\xi) + G_{sm}(x,\xi),\quad \nabla_\xi G = \nabla_\xi G_{sing} + \nabla_\xi G_{sm}$$
- 网络只负责逼近光滑的正则部分，符合经典数值分析"先解析处理奇异核、再逼近正则余项"的原则。

### 2.2 关键技术细节
- **奇异分量（维度相关）**：
  - 3D 扩散主导：$G_{sing} = \dfrac{1}{4\pi\|x-\xi\|}$，梯度 $\nabla_\xi G_{sing} = \dfrac{x-\xi}{4\pi\|x-\xi\|^3}$。
  - 2D Poisson：$G_{sing}^{2D} = -\dfrac{1}{2\pi}\ln\|x-\xi\|$。
- **近似性说明**：对变系数扩散–反应算子，真实主奇异为 $1/(4\pi a(\xi)\|x-\xi\|)$；当 $a(\xi)\neq 1$ 时，常数系数奇异项无法完全去除奇异，修正项会残留 $O(1/\|x-\xi\|)$ 量级的奇异成分，因此异质情形应视为**近似奇异分解**。
- **网络架构**：
  - 输入为拼接坐标对 $(x,\xi)$（3D 时为 6 维向量）。
  - **单一共享 BsNN 骨干** + **双输出头**：$H_G$ 预测标量修正 $G_{sm}$，$H_\nabla$ 预测向量梯度 $\nabla_\xi G_{sm}$。
  - 对比 GON：GON 用两个**独立** BsNN（Trunk 学 $G$，Branch 学 $\nabla_\xi G$），参数不共享、无一致性约束。
  - BsNN 采用二元结构化连接，第 $i$ 层第 $j$ 个神经元块按 $o_{i,j}=\sigma_{i-1,j}(w_{i-1,j}o_{i-1,\lfloor j/2\rfloor}+b_{i-1,j})$ 传播，降低稠密耦合同时保留局部特征表示能力。
- **积分实现**：将分解式代入 Green 积分表示，得到
  - 体积分中 $G_{sing}$ 用闭式核直接计算，$G_{sm}$ 用高斯积分；
  - 边界分中 $\nabla_\xi G_{sing}$ 用解析式，$\nabla_\xi G_{sm}$ 用梯度头输出 $H_\nabla$；
  - 四面体单元用 4 点高斯求积，三角边界用 3 点高斯求积（与 GON 保持一致）。
- **自一致性损失**：
  - 解重建损失 $\mathcal{L}_{sol}$：预测解与 FEM 参考解的 MSE。
  - 一致性损失 $\mathcal{L}_{con}$：自动微分梯度 $\nabla_\xi H_G$ 与梯度头输出 $H_\nabla$ 的平方差。
  - 总损失 $\mathcal{L}_{total}=\mathcal{L}_{sol}+\lambda(e)\mathcal{L}_{con}$，其中 $\lambda$ 在预热期（$e<E_c$）为 0，之后取常数 $\lambda_c$。由于约束施加在**光滑修正项**上，无需排除近对角样本对。
- **学习率调度**：warmup cosine——前 $E_w$ 轮保持基础学习率，随后余弦衰减至最小值，以稳定耦合优化。

### 2.3 算法流程（文字描述）
1. 生成网格与高斯积分点，采样源项与边界条件；
2. 输入坐标对，经共享 BsNN 骨干得到共享特征；
3. 双头分别输出 $G_{sm}$ 与 $\nabla_\xi G_{sm}$；
4. 用解析奇异项 + 网络修正项构造积分解，计算解重建损失；
5. 预热期结束后加入自一致性损失，联合反向传播；
6. 按 warmup cosine 调度更新学习率，直至收敛。

  - 方法本质依赖**已知的解析奇异核**（$1/4\pi r$、$-\ln r/2\pi$）。对非线性算子、强异质变系数、非局部算子或没有已知基本解的算子，分解式难以直接构造，方法需重新设计。
  - 异质情形下常数系数奇异项只是**近似**分解，修正项中残留 $O(1/\|x-\xi\|)$ 成分，作者未量化该残差对最终精度的影响，也未给出何时可安全忽略的判据。
- **训练范式依赖监督标签**：所有实验的解重建损失均以 COMSOL/FEM 参考解为监督信号，因此并非纯物理驱动；参考解生成成本与网格依赖性会传导到模型，论文未讨论参考解误差对结论的敏感性。
- **一致性的作用范围**：一致性损失只约束**光滑修正项**的梯度，奇异项与修正项之间的过渡区仍无显式耦合约束；此外论文未做 $\lambda_c$、$E_c$ 的敏感性分析，$2\times10^{-5}$ 与 $3500$ 的取值依据主要是经验性的。
- **消融的外部有效性**：8 组消融仅在平板反应扩散一个基准上完成，作者亦承认各组件重要性不可外推到全部几何与算子；缺少跨基准的完整组件消融，使"哪个组件在何种场景下关键"仍不清楚。
- **数值实现细节**：四面体 4 点、三角面 3 点高斯求积在近奇异单元上的精度未做收敛性分析；积分点距源点过近时，即便修正项光滑，整体积分的离散误差仍可能成为瓶颈，论文未报告这部分误差预算。
- **成本报告缺失**：未给出训练时长、能耗、推理阶段相对 FEM 的实际加速比。Green 函数型方法的吸引力之一正是"一次学习、多次复用"，但论文没有量化在多次前向求解场景下相对 FEM 的端到端收益。
- **基线透明度**：PINN、DeepONet、PI-DeepONet、FNO、GON 的超参与训练细节描述有限，复现难度较高，跨方法比较的公平性只能部分验证。
- **矢量情形的理论缺口**：Stokes 案例未使用 Stokeslet 等解析奇异核，因而该案例实际上是"共享骨干 + 一致性正则"的消融式验证，而非完整 SDC-GON；这与论文标题所强调的奇异分解主线存在一定张力。

## 9. 可延伸的方向

- **奇异核的推广**：把解析奇异分量推广到变系数主部（如 $1/(4\pi a(\xi)\|x-\xi\|)$）、各向异性扩散、弹性动力学（Kelvin 解）与 Stokes（Stokeslet/Stresslet），检验分解对残差奇异的鲁棒性。
- **走向无监督/自监督**：用 PDE 残差或边界积分残差替代 FEM 标签，摆脱对参考解的依赖，从而把方法推进到无网格或高维问题。
- **算子化与参数化**：将系数场、几何形状或边界条件作为额外 branch 输入，学习**参数化 Green 算子族**，直接服务于不确定性量化与反问题中的反复求解。
- **理论刻画**：对"近似奇异分解 + 光滑修正"给出逼近误差界，量化残余奇异对网络容量与泛化误差的影响；并分析一致性损失在何种条件下改善优化景观。
- **效率工程**：结合快速多极子、层次矩阵或低秩压缩，评估在大规模网格上积分表示的推理加速比，补齐端到端成本对比。
- **更广的消融与统计检验**：在所有基准上做完整因子消融，并报告置信区间或显著性检验，以支撑"结构优于规模"的强论断。

## 10. 总评

SDC-GON 的核心贡献是把 Green 函数型算子学习中的两个结构性难题——**核的奇异性**与**核与梯度的不一致性**——用同一个设计原则统一处理：解析剥离奇异、网络逼近光滑余项，并以共享骨干加自一致性损失把标量核与其梯度绑定在同一内部表示上。实验在 5 个覆盖 2D/3D、标量/矢量、均质/异质的基准上一致优于 PINN、DeepONet、PI-DeepONet、FNO 与最接近的 GON，且在部分案例中以更小网络取胜，为"结构改进优于规模扩张"提供了有说服力的证据。方法的主要边界在于对已知解析奇异核的依赖、对 FEM 监督标签的依赖，以及消融与成本报告的不完整；这些也正是后续工作最自然的切入点。总体而言，这是一篇方法动机清晰、对比扎实、结论克制且具有明确可扩展路径的工作。
