## 摘要
我们采用方程驱动、物理约束的深度学习来求解固定边界Grad-Shafranov（GS）平衡问题，构建具有托卡马克相关特征的轴对称磁流体力学平衡。利用物理信息Kolmogorov-Arnold网络（KAN）构造线性（Solov'ev）与非线性剖面函数下的平衡，这些网络在满足适当边界条件的同时逼近GS解。还考虑了一种高度非线性的压力剖面，其重现高约束模式现象，例如压力台基和显著的自举电流分量。为实现高效收敛，采用了引导式训练方案，特别是基于同伦延拓的课程学习和通过预训练网络进行的迁移学习。尽管在无引导的物理信息训练下使用标准多层感知机计算非线性平衡仍然是一项难以实现或计算效率低下的任务，我们的框架克服了这一局限。具体而言，我们证明，三个关键要素——KAN架构、引导式训练方案以及自缩放Broyden优化方法——的结合，能够实现稳定、高效且准确的平衡计算，并同时根据平衡约束进行剖面参数辨识。

## Abstract
We employ equation-driven, physics-constrained deep learning to solve the fixed-boundary Grad-Shafranov (GS) equilibrium problem, constructing axisymmetric magnetohydrodynamic equilibria with tokamak-relevant characteristics. Equilibria across linear (Solov'ev) and nonlinear profile functions are constructed using Physics-Informed Kolmogorov-Arnold Networks (KANs) that approximate GS solutions while satisfying appropriate boundary conditions. A highly nonlinear pressure profile recreating high-confinement mode phenomenology, such as pressure pedestals and significant bootstrap current components, is also considered. To enable efficient convergence, guided training schemes are employed, specifically homotopy-based continuation curriculum learning and transfer learning via pretrained networks. While computing nonlinear equilibria employing standard Multi-Layer Perceptrons under unguided physics-informed training remains an elusive or computationally inefficient task, our framework overcomes this limitation. Specifically, we demonstrate that the combination of three key elements, namely KAN architecture, guided training schemes, and the self-scaled Broyden optimization method, enables stable, efficient, and accurate equilibrium computation with simultaneous profile parameter identification in view of equilibrium constraints.

## 1. 核心问题与整体含义（研究动机与背景）

- **物理背景**：磁流体力学（MHD）平衡是磁约束聚变研究的基础，直接决定稳定性、输运、装置设计与实验场景设计。托卡马克等轴对称装置的平衡由静态 Grad-Shafranov（GS）方程描述，即在无流条件下理想 MHD 力平衡的标量形式。
- **核心问题**：固定边界前向平衡问题——给定剖面函数 $P(\psi)$、$H(\psi)$ 及边界条件，求解极向磁通函数 $\psi(r,z)$。传统求解器（HELENA、CHEASE、EFIT 等）存在三大痛点：
  - 网格依赖、离散化误差；
  - 高度非线性剖面（如 H 模台基陡梯度）下收敛困难；
  - 参数灵活性差，参数或边界微调即需重跑整个流程。
- **技术路线选择**：物理信息机器学习（PIML/PINN）提供无网格、连续可微、易适应新参数、易融合物理约束与实验数据的替代方案。但标准 PINN 精度低、开销大，根源在于优化瓶颈（梯度消失/爆炸、深度网络收敛慢）。
- **本文定位**：以 **物理信息 Kolmogorov-Arnold 网络（PIKAN）** 为核心，配合**引导式训练**与**二阶准牛顿优化**，突破标准 MLP-PINN 在非线性 GS 平衡上难以收敛的局限，并同时实现剖面参数辨识。本文仅处理静态 GS 方程，作为后续扩展（流、各向异性压力、Hall 效应等）的起点。

## 2. 方法论

### 2.1 控制方程与剖面参数化
- 无量纲静态 GS 方程：$\Delta^*\psi + r^2 \frac{dP}{d\psi} + \frac{dH}{d\psi} = 0$，其中 $H := F^2/2$，$\Delta^* = r\partial_r(\frac{1}{r}\partial_r) + \partial_z^2$。
- 标准剖面参数化：$\frac{dH}{d\psi}=H_1(1-\psi_n^{a_m})^{a_n}$，$\frac{dP}{d\psi}=P_1(1-\psi_n^{b_m})^{b_n}$，其中 $\psi_n \in [0,1]$ 为归一化极向磁通。
- **Solov'ev 线性情形**（$a_n=b_n=0$）：存在解析解（式 8），可形成单/双 X 点、上下不对称的分离面，用作基准与预训练源。
- **H 模压力台基剖面**：$P(\psi)=P_1(P_2+P_3\psi^2)(1-e^{-\psi^2/\nu})$，$\nu$ 控制边缘陡度，$P_2,P_3$ 控制台基高度相对芯部压力。

### 2.2 PIKAN 算法核心
- **PINN 损失**：$L = w_D L_D + w_{\partial D} L_{\partial D} + \sum_i w_{c_i} L_{C_i}$；$L_D$ 为配点处 PDE 残差 MSE，$L_{\partial D}$ 为 Dirichlet 边界惩罚，$L_{C_i}$ 为物理约束项（正则化）。
- **KAN 架构**：基于 Kolmogorov-Arnold 表示定理，将 MLP 的"边上标量权重 + 节点固定激活"改为"边上学可学习的单变量函数 $\phi_{ij}$ + 节点求和"，即 $x^\ell_i = \sum_j \phi^\ell_{i,j}(x^{\ell-1}_j)$。
- **FastKAN**：以高斯 RBF（式 24）替代 B 样条展开，加速评估与 GPU 实现；网格数 $G=8$，可学习参数由式 (35) 给出。
- **优化流程（两阶段）**：
  - Phase 1：AdamW（可配 CosineAnnealingLR）全局探索；
  - Phase 2：自缩放 Broyden（SSBroyden）二阶准牛顿精修。
- **剖面参数辨识（交替优化）**：网络参数 $p$ 固定 → 用梯度下降更新物理参数 $\mu=(P_1,H_1)^\top$（仅用约束损失）；网络参数更新 → 冻结 $\mu$；循环交替。约束包括环形比压 $\beta_t$、总环向电流 $I_t$（式 25–27），或轴安全因子 $q_a$（式 30–31）。
- **磁轴动态追踪**：每轮用阻尼牛顿–拉夫逊迭代 $x^{(k+1)} = x^{(k)} - \alpha H^{-1}_{\text{reg}}\nabla\psi$，Hessian 病态时加 $\epsilon I$ 正则化，保证 $\psi_n$ 计算准确。
- **引导式训练（两种互补策略，不同时使用）**：
  - **迁移学习**：用同一边界条件下的 Solov'ev 预训练网络初始化，使首轮即满足边界条件；
  - **同伦延拓课程学习**：用 $\lambda\in[0,1]$ 在 Solov'ev 剖面与非线性目标剖面间连续插值，逐步增加非线性，AdamW 阶段在 $\lambda=1$ 后交 SSBroyden 精修。
- **点云生成（附录 A）**：DFT 拟合边界 → 几何感知角度采样（按边界距几何中心距离加权）→ k-d 树最短距离去簇 → 人工势能最小化填隙 → 高曲率 X 点加密；训练中周期性重新生成配点以抗空间过拟合。
