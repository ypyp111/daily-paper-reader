## 摘要
我们提出了内存高效神经算子（MENO），这是一种基于流形函数编码器（Manifold Function Encoder, MFE）的高性能偏微分方程神经求解器。MENO 具有三个主要优势：(1) 与其它流行架构相比，MENO 的内存占用显著更小，训练速度更快，且内存占用与数据分辨率无关，因此具有扩展到大规模模型的潜力。(2) MENO 可以接受任意形式的 PDE 输入，包括任意几何域和任意离散化。特别地，它能够处理跨几何场景，即输入函数和输出解定义在不同流形上的情况。(3) MENO 展现出很强的泛化能力，在我们测试的大多数基准上，与文献中报告的结果相比，取得了最佳精度。代码可在 GitHub 上获取：https://github.com/jpzxshi/MENO，本文中的所有数值示例均可通过单条命令运行，以复现所报告的结果。

## Abstract
We propose the Memory-Efficient Neural Operator (MENO) as a high-performance PDE neural solver based on the Manifold Function Encoder (MFE). MENO features three primary advantages: (1) MENO has a significantly smaller memory footprint and much faster training speed than other popular architectures, with the memory footprint being independent of the data resolution, and therefore holds the potential for scaling up to large-scale models. (2) MENO can accept PDE inputs of arbitrary form, including arbitrary geometric domains and arbitrary discretizations. In particular, it is capable of handling cross-geometry scenarios, i.e., where the input functions and the output solutions are defined on different manifolds. (3) MENO exhibits strong generalization capability, and achieves the best accuracy on most of the benchmarks we tested, compared with the results reported in the literature. The code is available on GitHub at https://github.com/jpzxshi/MENO, and all numerical examples in this paper can be run with a single command to reproduce the reported results.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：神经算子（Neural Operator）为偏微分方程（PDE）的代理建模提供了数据驱动方案，代表性架构包括 DeepONet、FNO 及其后续变体。然而，实际工业场景中 PDE 的计算域往往随系数、源项和边界条件变化，催生了“变域神经算子”的研究需求。
- **现有方法的两条路线**：
  - **形变策略**（如 Geo-FNO、DIMON、D2D&D2E）：将拓扑等价的域形变到同一规范域，但无法处理非拓扑同胚的域。
  - **延拓策略**（如 DAFNO 用特征函数、GINO 用符号距离函数 SDF）：将不同域延拓到更大规范域，不受拓扑限制，但计算涉及整个三维物理空间，内存和计算瓶颈严重。
- **对偶表示方法的优势与不足**：
  - 对偶表示（如 Transolver 系列、PCNO、MFE-MIONet）仅涉及流形本身及其上函数，计算更高效。
  - 但 Transolver、PCNO 每层都需积分操作，训练成本随数据分辨率增长，GPU 内存瓶颈严重；MFE-MIONet 虽无积分、内存低，但泛化能力落后于基于积分的架构。
- **核心问题**：能否设计一种**无积分（integration-free）** 的神经算子架构，同时具备低内存、快训练、强泛化，并能处理任意几何域、任意离散化及跨几何场景？
- **整体含义**：MENO 被提出作为高性能 PDE 神经求解器，旨在突破内存与分辨率耦合的瓶颈，为大规模工业级 PDE 求解提供可扩展方案。

## 2. 方法论：核心思想与关键技术细节

- **核心基础——流形函数编码器（MFE）**：
  - 设定：考虑 d 维盒子 \(V=[0,1]^d\) 中有限个 k 维 Lipschitz 流形的并集 \(M\)，以及定义在其上的 \(L^2(M)\) 函数 \(f_M\)。
  - 编码器：给定固定连续基函数 \(\{\phi_{n,m}\}\)，定义
    - \(\Phi_n^1(M) = \left(\int_M 1\cdot \phi_{n,m}\, dH^k\right)_{1\le m\le \kappa(n)}\)（编码流形形状）
    - \(\Phi_n^2(M,f_M) = \left(\int_M f_M\cdot \phi_{n,m}\, dH^k\right)_{1\le m\le \kappa(n)}\)（编码流形上函数）
    - 最终编码 \(\Phi_n(M,f_M) = (\Phi_n^1(M), \Phi_n^2(M,f_M))\in \mathbb{R}^{2\kappa(n)}\)。
  - 解码器：用同一组基函数线性组合还原为 \(C(V)\) 中的函数，再通过限制算子得到流形上的解。
  - **超代数收敛**：基于 Legendre 或 Fourier 基的 MFE，编解码复合映射 \(\Psi_n\circ\Phi_n\) 超代数收敛到恒等映射，可将流形函数信息压缩到极低维向量。
- **MFE tokens**：将多个不同维度流形及其上多个函数统一编码为 \(n^d\) 个 token，每个 token 维度为输入函数总数（如 Poisson 例子中为 4 或 5 维）。
- **MENO 整体架构**：双分支结构 + 全局到局部的单向信息注入。
  - **全局分支**：
    - 输入 MFE tokens \(Z_{in}\in\mathbb{R}^{n^d\times(l_1+\cdots+l_p)}\)，经 Lift 线性层并加入谱位置偏置 \(B(P_t)\)，得到 \(H_0\)。
    - 堆叠 L 个标准 Transformer 块（MHA + MLP + LayerNorm）。
    - 投影到输出通道数 \(l_{out}\)，经缩放后由 MFE 解码器得到全局初步解 \(\tilde{u}^{global}_i\)。
  - **注入机制**：
    - 从每个全局层 \(H_l\) 经线性层和 MFE 解码器得到空间函数 \(\tilde{T}_l(x)\) 及其一阶导数 \(\tilde{T}_l^i(x)\)。
    - 组合为 \(T_l(x)=\tilde{T}_l(x)+\sum_i W^{grad}_i\cdot\tilde{T}_l^i(x)\)，作为全局到局部的传递信息，所有层共享梯度组合参数。
  - **局部分支**：
    - 对输出流形 \(M_0\) 上的查询点 \(x\)，通过 MFE 解码器跨评估输入信息 \(\tilde{V}(x)\)；若 \(M_0\) 恰为某输入流形，则直接取函数值。
    - 拼接局部位置编码 \(P_t^{local}(x)\)，经 Lift 得到局部初始状态。
    - 逐层计算 \(H_l^{local}(x)=\sigma\left(LL_l^{local}(LN(H_{l-1}^{local}(x)))+T_l(x)\right)\)，最终经投影得到局部修正 \(\tilde{u}^{local}_i(x)\)。
  - **合并输出**：\(\tilde{u}_i(x)=\tilde{u}^{global}_i(x)+\tilde{u}^{local}_i(x)\)。
- **内存高效的关键**：训练阶段完全不含积分算子，GPU 内存占用与数据分辨率无关，避免了对网格/点云全部物理点的积分缓存与计算。
- **可选统计归一化**：对全局分支按模式与通道标准化，对局部分支按通道标准化，输出反归一化在合并后统一进行一次。
- **跨几何能力**：输入和输出可定义在不同流形上，MENO 可统一编码几何、材料属性、力边界、位移边界、接触摩擦等不同维度的流形函数，充当通用 PDE 神经求解器。

## 3. 实验设计

- **数据集与场景**：
  - **Poisson 方程（跨几何）**：来自 MFE-MIONet 论文，9000 训练 / 1000 测试，域包含圆盘状与环状，形变类方法会失效。输入为 \((\Omega, k_\Omega, f_\Omega, g_{\partial\Omega})\)，输出为 \(u_\Omega\)。
  - **Poisson 方程（单几何）**：来自 PCNO 论文，1000 训练 / 200 验证 / 400 测试，\(f\equiv 1, g\equiv 0\)，映射为 \((\Omega, k_\Omega)\mapsto u_\Omega\)。
  - **NASA-CRM**：气动问题，105 训练 / 44 测试，输入为表面 \(\Gamma\)、外法向 \(n_\Gamma\) 和 6 维飞行参数，输出为表面压力系数 \(C_p\) 与摩擦系数 \(C_f\)。
  - **AhmedML**：汽车气动问题，400 训练 / 50 验证 / 50 测试，输入为表面 \(\Gamma\)、外法向 \(n_\Gamma\) 和 8 维几何参数，输出为 \(C_p\) 与壁面剪应力 \(\tau_w\)。另设小尺寸 MENO 版本。
- **Benchmark 与对比方法**：
  - Poisson 跨几何：对比 MFE-MIONet；Transolver-3 和 PCNO 不适用。
  - Poisson 单几何：对比 PCNO。
  - NASA-CRM：对比 Graph U-Net、GINO、MeshGraphNet、GAOT、UPT、AB-UPT、Transolver-3、PCNO。
  - AhmedML：对比上述同类方法，PCNO 因内存超限（>80 GB）失败。
- **评价指标**：相对误差（%）、参数量（M）、峰值 GPU 内存（GB）、训练时间（h）。
- **训练协议**：Legendre-based MFE，AdamW 优化器，GeLU 激活，500 epochs，选验证/测试精度最高的 checkpoint；比较内存时采用相同 batch size 和相同查询点数。

## 6. 主要结论与发现

- **精度**：
  - Poisson 跨几何：MENO 相对误差 **2.07%**，约为 MFE-MIONet（6.49%）的三分之一。
  - Poisson 单几何：MENO 误差 **0.669%**，略优于 PCNO（0.683%）。
  - NASA-CRM：MENO 压力误差 **6.69%**、摩擦误差 **4.79%**，优于所有报告基线（Transolver-3 为 8.71%/5.85%，AB-UPT 为 9.77%/6.43%）。
  - AhmedML：MENO 压力 **3.37%**、摩擦 **4.88%**，为第二好成绩，仅次于 Transolver-3（2.96%/4.81%）；小尺寸 MENO 也取得第二好成绩（3.61%/5.07%），但参数仅 2.40 M、内存 0.425 GB、训练 1.75 h。
- **效率**：
  - MENO 参数量、峰值 GPU 内存和训练时间均大幅低于对比方法。例如 Poisson 单几何中，MENO 仅用 PCNO 的 1.7% 参数、5.1% 峰值内存、8.3% 训练时间。

- **泛化与通用性**：MENO 能处理任意几何域、任意离散化及跨几何场景，具备成为通用 PDE 神经求解器的潜力。

## 7. 优点

- **架构创新**：首次将无积分的 MFE 与双分支（全局 Transformer + 局部 MLP）架构结合，通过单向注入机制实现全局信息到局部查询点的传递，兼顾全局泛化与局部精度。
- **内存效率突出**：训练阶段无积分算子，GPU 内存与数据分辨率解耦，适合大规模问题。
- **跨几何能力强**：可统一编码不同维度、不同流形上的输入函数，支持输入与输出定义在不同流形上的场景。
- **精度与效率兼得**：在多数基准上达到最佳或次佳精度，同时参数量、内存和训练时间显著降低。
- **实验设计较全面**：覆盖二维/三维、单几何/跨几何、气动/汽车气动等多类问题，并与多种主流神经算子对比。
- **开源可复现**：代码已开源，所有数值示例可通过单条命令复现，有利于社区验证与扩展。

## 8. 不足与局限

- **缺少消融研究**：未量化全局分支、局部分支、注入机制、导数信息、位置编码、统计归一化等各组件对性能和效率的单独贡献。

- **理论分析依赖 MFE**：MENO 本身未提供新的收敛性或泛化误差理论保证，主要理论支撑来自已有 MFE 的超代数收敛定理。
