## 摘要
现有的偏微分方程求解器合成方法主要依赖于自回归模型，然而其全局从左到右的解码方式在处理本质上局部化的错误时会产生大量冗余。在这项工作中，我们挑战这种低效范式，提出DiffPDE，一个利用离散扩散语言模型进行针对性代码修复的框架。通过引入局部重新掩码和填充策略，DiffPDE仅重新生成错误区域，同时保留正确的上下文，使生成过程自然契合PDE错误的稀疏特性。此外，为了处理需要顺序干预的耦合错误，我们提出了迭代调试GRPO（ID-GRPO），这是一种强化学习方案，能够在单条轨迹中通过中间奖励实现多轮调试。在PDEBench上的实验表明，DiffPDE达到了具有竞争力的精度，优于同规模的自回归模型，并显著加速了修复过程。

## Abstract
Existing approaches for synthesizing Partial Differential Equation (PDE) solvers predominantly rely on autoregressive models, yet their global left-to-right decoding incurs substantial redundancy when addressing inherently localized bugs. In this work, we challenge this inefficient paradigm and propose DiffPDE, a framework leveraging discrete diffusion language models for targeted code repair. By introducing a localized re-masking and infilling strategy, DiffPDE regenerates only erroneous regions while preserving correct context, naturally aligning generation with the sparse nature of PDE errors. Furthermore, to handle coupled bugs requiring sequential interventions, we present Iterative Debugging GRPO (ID-GRPO), a reinforcement learning scheme that enables multi-round debugging within single trajectories via intermediate rewards. Experiments on PDEBench show that DiffPDE achieves competitive accuracy, outperforms same-scale AR models, and significantly accelerates repair.

# DiffPDE 论文总结

## 1. 核心问题与整体含义

- **研究背景**：用大语言模型（LLM）自动生成偏微分方程（PDE）数值求解器代码，是“AI for PDE/科学计算”的重要方向。现有方法（如 CodePDE）多采用自回归（AR）语言模型，以“逐 token 从左到右”的方式生成和修复代码。
- **核心问题**：实际调试中，绝大多数错误是**局部化的**（如单个变量未定义、一处边界条件写错），但自回归模型修复时仍需重新生成整个代码上下文，造成大量冗余计算和推理延迟。
- **论文主张**：挑战“全局解码=低效修复”的范式，提出基于**离散扩散语言模型（dLLM）** 的框架 DiffPDE，利用其**双向建模**能力只重新生成出错的代码片段，从而显著加速 PDE 求解器的迭代调试。
- **整体含义**：论文验证了扩散语言模型在“代码级科学计算”中的可行性，即不仅可生成完整求解器，还能以更高效的方式进行局部化、执行反馈驱动的代码修复。

## 2. 论文提出的方法论

- **总体框架**：包含“训练”与“推理”两个阶段。
  - **训练阶段**：先进行监督微调（SFT），再执行强化学习（RL），通过统一的目标训练模型同时具备“从零生成求解器”和“局部填充修复”两种能力。
  - **推理阶段**：采用“生成—执行—调试”循环。模型先生成完整求解器；若运行失败，则根据执行反馈定位错误区域，对错误区域施加“局部重掩码”，并在完整上下文条件下进行“填充式修复”。

- **核心技术思想**：
  - **局部重掩码与填充（Localized Re-masking & Infilling）**：仅将错误代码段替换为 `[MASK]`，保留左右正确代码作为上下文，由 dLLM 并行预测被掩码的 token。这比 AR 模型的“整段重新生成”更节省计算，且更贴合 PDE 错误稀疏、局部化的特点。
  - **统一 SFT 目标**：
    \[
    L_{SFT} = -E_{(q,x_0)} E_{t \sim U[0,1]} \left[ \sum_{i\in M_t} \log p_\theta(x_{0,i} | x_t, q) \right]
    \]
    其中高噪声对应“从零生成”，低噪声对应“局部填充”，使单一模型同时掌握两种能力。
  - **ID-GRPO 强化学习方案**：
    - **动态任务分配与缓冲区**：每次 RL 迭代中，先生成多个候选求解器；成功样本构造为“合成填充任务”，失败样本作为“错误驱动的填充任务”，通过动态调节两类任务的采样比例形成从易到难的课程学习。
    - **多轮奖励设计**：针对耦合错误导致的稀疏反馈问题，引入“中间改善奖励”：
      - 基础奖励 \( r_+(c;\alpha) \) 由代码是否执行成功及 nRMSE 是否低于阈值决定；
      - 若相邻两次调试的错误签名集合发生严格缩减，则给予中间奖励；
      - 最终多轮奖励聚合为“历史最优结果奖励 + 累计中间进步奖励”：
        \[
        r_{MR} = \max_{j \in \{1,\dots,R\}} r(c^{(j)}) + r_{inter}
        \]
  - **错误定位**：使用确定性 traceback 定位算法——从报错行向上下扩展到自然边界（空行、注释行或缩进更浅的行），映射成 token 区间并作为待掩码区域。

- **基础模型与解码**：采用 Dream-Coder-7B（基于 Qwen2.5-Coder 初始化的扩散模型）；从零生成使用类似 LLaDA 的半自回归分块生成，推理时用 Fast-dLLM 风格的 KV 缓存和并行解码加速。

## 6. 主要结论与发现

- **扩散模型可用于 PDE 求解器生成与修复**：DiffPDE 在 nRMSE 精度上与大规模 AR 模型可比，在 1D Advection 上优于 GPT-5.2，在 Reaction–Diffusion 上与之持平。

- **ID-GRPO 的有效性**：动态任务缓冲区和中间多轮奖励都有助于提升成功率与精度，缓解多轮调试中奖励稀疏的问题。
