## 摘要
福克-普朗克偏微分方程（FP-PDE）控制着随机动力系统中的不确定性演化。在轨道动力学中，由于非线性运动、高维状态以及大时空域，求解FP-PDE具有挑战性。我们开发了一种物理信息神经网络（PINN）方法，将FP-PDE解近似为单一时空概率密度，同时量化其最坏情况近似误差。该方法原则上与状态坐标的选择和神经网络架构无关。具体地，为了将概率密度函数（PDF）特性嵌入神经网络，我们设计了一种物理信息高斯混合模型（PINN-GMM）。随后，一个伴随误差PINN学习近似误差的动力学，并生成时间相关界，这些界定义了一个PDF的模糊集。该模糊集使得通过易于处理的线性规划能够严格计算事件概率的上界和下界。在说明性一维示例和多个4D--6D轨道测试案例上的数值研究表明，该方法能够实现精确的不确定性传播、正确且信息丰富的误差界，并且相比常见的不确定性传播基线方法（高斯近似、无迹变换和高斯混合模型）具有更高的可靠性。构建PINN-GMM需要离线训练，使其成本高于基线近似方法；然而，一旦训练完成，单次前向传播可在亚毫秒时间（我们实现中为0.16毫秒）内返回任意时刻的密度。

## Abstract
The Fokker-Planck partial differential equation (FP-PDE) governs uncertainty evolution in stochastic dynamical systems. In orbital dynamics, solving the FP-PDE is challenging because of nonlinear motion, high-dimensional states, and large space-time domains. We develop a physics-informed neural network (PINN) approach that approximates the FP-PDE solution as a single space-time probability density, while also quantifying its worst-case approximation error. This approach is, in principle, independent of the choice of state coordinates and neural network architecture. Specifically, to enforce probability density function (PDF) properties into the neural network, we design a Physics-informed Gaussian mixture model (PINN-GMM). Then a companion error PINN learns the dynamics of the approximation error and yields time-dependent bounds that define an ambiguity set of PDFs. This ambiguity set enables rigorous computation of upper and lower bounds on event probabilities through tractable linear programs. Numerical studies on illustrative 1D examples and several 4D--6D orbital test cases demonstrate accurate uncertainty propagation, correct and informative error bounds, and improved reliability over common uncertainty-propagation baseline methods (Gaussian approximation, unscented transform, and Gaussian mixture model). Constructing the PINN-GMM requires offline training, making it costlier than the baseline approximations; once trained, however, a single forward pass returns the density at any time in sub-millisecond time $(0.16~\mathrm{ms}$ in our implementation).

- **现实瓶颈**：传统方法（高斯近似 GA、无迹变换 UT、高斯混合模型 GMM 等）基于参数化传播，虽然计算高效，但缺乏对逼近误差的严谨界定，无法为下游任务（如交会分析、碰撞概率估计）提供可信的可靠性区间。

## 2. 方法论与关键技术

### 2.1 方法总框架
- 目标：学习时空密度逼近器 $`\hat{p}(x,t)`$ 和伴随误差逼近器 $`\hat{e}(x,t)`$，使得：
  - $`\hat p`$ 满足 FP-PDE 残差损失与初始条件损失；
  - 时变误差界 $`B(t)=2\max_x|\hat e(x,t)|`$ 能保证 $`\sup_x|p-\hat p|\le B(t)`$。

### 2.2 坐标选择与预处理
- 提出多种坐标系来压缩状态域，缓解高维稀释问题：
  - **旋转球坐标**（rotating spherical coordinates）可随轨道旋转缩小有效域；
  - **轨道要素坐标**（Equinoctial elements）在无摄情况下使动力学解耦，存在解析解；
  - **参考轨迹偏差坐标**：利用参考轨道将状态集中于原点附近；
  - **广义可逆映射坐标**：利用 Itô 公式推导任意微分同胚下的 SDE 和 FP 算子。

### 2.3 PINN-GMM 密度表征
- 引入**时间条件高斯混合模型**（PINN-GMM）：
  - $`\hat p(x,t)=\sum_{k=1}^K w_k(t)\,\mathcal N(x;\mu_k(t),\Sigma_k(t))`$；
  - 权重、均值、协方差（Cholesky 因子）均由小神经网络以时间 $`t`$ 为输入生成；
  - 采用**固定编码器**（whitening）对状态进行归一化，再用解码器映射回原空间；
  - 通过 Softplus 保证协方差正定，通过权重归一化与混合系数 $`\alpha`$ 保证权重合计为 1；
  - 比起标准 MLP-PINN，GMM 结构天然满足 PDF 归一化与非负性，并支持解析边际分布与高效采样。

### 2.4 误差网络与模糊集
- 对误差 $`e=p-\hat p`$ 建立误差传播偏微分方程，用 PINN 学习 $`\hat e`$（error-PINN）。
- 基于前期理论（Ref.[16]）采用 $`B(t)=2\max_x|\hat e(x,t)|`$ 的经验检验形式，构造含真实 PDF 的模糊集 $`\mathcal{P}(\hat p,B,t)`$。
- 该模糊集与真实 PDF 的隶属关系为事件概率上下界的求解提供了严格前提。

### 2.5 事件概率上下界：线性规划
- 将空间域划分为单元胞 $`c_i`$，利用高斯混合模型的性质（多项式时间可算的每个单元最小/最大值），计算胞内密度上下界；
- 将事件概率的上下界求解转化为**线性规划（LP）**：
  - 上界对应“与事件集合相交胞”的测度最大值；
  - 下界对应“完全包含于事件集合胞”的测度最小值；
  - 最终形成可自动加细的算法（Algorithm 1），理论上界与下界随剖分细化而收紧。

## 6. 方法的创新点与优点

### 6.1 理论层面
- 将“纯数值求解 FP-PDE”重构为“可查询时空密度场 + 误差边界场”的学习任务，为不确定性传播提供在线可计算的概率查询与可靠性区间；
- 明确给出了由误差界派生的事件概率上/下界的构造方式（通过模糊集 + 线性规划），将神经网络的逼近误差纳入概率安全性分析框架，而非仅仅可视化密度图；
- 扩展了可逆坐标变换下的 SDE/FP 算子形式，使方法可在不同轨道坐标系下无缝迁移。

### 6.2 工程实现层面
- PINN-GMM 的结构兼具物理信息约束（满足FP方程弱解与初始条件）和概率结构（非负、归一、可解析求边际与矩），兼顾刚度与灵活性；
- 时间条件式网络参数化允许在训练完成后以 0.16ms 量级代价查询任意时刻的密度与事件概率，优于每次重新求解的高成本蒙特卡洛；
- 开源代码提高了结果的可复现性，且 CPU 训练时间虽长但可接受，便于没有大型 GPU 的研究者使用。

## 7. 局限性与潜在改进方向

### 7.1 局限
- **离线训练成本高**：单组轨道算例常需数小时至十余小时 CPU 时间；与 GA/UT/GMM 的秒级成本不在同一量级；
- **误差界形式具有经验性质**：虽然大量数值验证成功，但 $B(t)=2\max_x|\hat e(x,t)|$ 的适用前提（如误差场光滑性、边界影响）未给出严格收敛证明，缺少理论收敛速率保证；
- **误差网络本身缺乏自适应启发式**：在真实密度具有尖锐峰或临近退化分布时，误差 PINN 的拟合可能不充分，需要人工调节训练参数；
- **维度扩展性仍受限**：虽然解决了 6D 问题，但对更高维（如考虑更完整扰动力的 9D 或 12D）仍需依赖坐标压缩与结构假设，尚无充分证据表明可直接扩展；
- **事件概率界的紧性依赖网格细化**：线性规划中对空间胞的加细虽可收紧界，但会引入额外线性规划规模开销，在实时场景下仍有压力；
- **未与状态转移张量、张量分解等近期专门方法作数值对比**，且参考真值本身通过 MC/GMM 拟合获得，可能引入由拟合过程带来的偏差，尤其是边缘峰或厚尾区域。

### 7.2 改进方向
- 可引入自适应误差边界训练（如以残差修正项驱动误差网络权重分配），弱化对经验形式 $2\max|\hat e|$ 的依赖；
- 结合稀疏网格或张量结构来扩展至更高维状态，并利用区域分解处理强非线性长时传播；
- 在误差界“超集”基础上进一步利用可达集/最优传输工具，将时变界更新为更紧的区间；
- 对误差网络增加理论校正项或后处理校准，以构造有严格最坏情况保证的认证型误差界；
- 在采样阶段结合轨道动力学先验（如周期性、对称性）设计更高效的训练样本，从而降低离线训练成本。

## 8. 总体结论与个人评价

### 8.1 总体结论
本文提出了一种基于 PINN-GMM 的随机轨道不确定性传播框架，可在单个时空神经网络中同时获得密度估计与时变误差界，并进一步导出了事件概率的严格上下界。与其他参数化传播方法相比，其优势在于同时具备“任意时点查询”“概率归一正则”和“误差包络验证”的能力；代价是需要较大离线训练开销和针对误差界的经验验证。在安全关键的航天交会、碰撞概率评估等应用中，这种带误差保证的在线查询模式具有明确的意义与实用性。

### 8.2 个人评价（中立视角）
- **贡献实质且完整**：文章从物理模型定义、网络结构设计、误差源分析到数值验证形成闭环，尤其考虑了轨道力学中特殊的坐标系压缩、多模态现象和工程尺度验证，不是简单套用 PINN 到 FP 方程的“水论文”做法；
- **误差界是最大亮点但也是软肋**：经验上成功，理论上尚不完整；若能在后续工作中补齐严格证明或构造可计算的“上边界网络”，将极大提升方法的可信度；
- **适用对象判断**：该方法更适合需要高精度、长期传播但允许离线准备训练的“一次训练、多次查询”场景；若在线任务要求毫秒级且每次动态配置不同，则仍需配合模型降阶或迁移学习；
- **可复现性取分**：开源和详细超参描述使该方法具有较高的工程可移植性，基线对比方式亦基本公允；劣势在于未与部分专用高精度数值方法同台比较以及参考真值依赖 MC/GMM 拟合。

**总结**：该论文的贡献大于其缺陷，是一种深思熟虑的、面向应用的“可认证神经网络传播器”工作。它并不试图推翻传统采样或解析传播方法，而是为其无法提供可靠性边界的场景提供了一种新范式。建议后续关注作者是否在理论证明、自适应误差界、以及真实星历下的更高维测试上有进一步推进。
