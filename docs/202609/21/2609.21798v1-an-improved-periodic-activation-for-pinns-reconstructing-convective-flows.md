## 摘要
具有周期激活函数的架构已被证明，在物理信息神经网络的广泛应用中，相比单调激活函数的对应架构更具优势。在这里，我们研究了一种网络架构，它使用复指数函数，生成正弦和余弦输出对作为激活函数。在从稀疏速度数据重建立方瑞利-贝纳德对流温度的任务上，将其与可比的、正弦激活的多层感知机进行测试，结果表明重建质量显著提升，而每个训练步的计算成本没有大幅增加。反过来，改进的架构能够以一小部分开销达到相似的重建质量。分析这些网络的数学结构表明，改进根源于同时前向传递正弦和余弦函数的性质。这样，后续层能够调整所提供潜在周期函数的相位，并且对其每个神经元单独进行这种调整。

## Abstract
Architectures with periodic activation functions have already been shown to be beneficial in comparison to monotonic counterparts for a wide range of applications of physics-informed neural networks. Here, we investigate a network architecture which uses the complex exponential function, generating pairs of sine and cosine outputs as activation functions. Testing it against comparable, sine-activated multi-layer perceptrons for the task of temperature reconstruction from sparse velocity data for cubic Rayleigh-Bénard convection reveals significant improvements in the reconstruction quality without a substantial increase in computational cost per training step. Vice versa, the improved architecture enables reaching similar reconstruction qualities for a fraction of the expense. Analyzing the mathematical structure of these networks points to the improvements being rooted in the property of passing both a sine and cosine function forward. This way, the subsequent layer is able to adapt the phase of the provided latent periodic functions, and doing it individually for each of its neurons.

- **研究背景**：物理信息神经网络（PINNs）在流体反问题中受到关注，尤其用于从稀疏观测重建隐藏流场。已有研究表明，周期激活函数（如正弦激活）通常优于单调激活函数（如 tanh、ELU、swish）。
- **核心问题**：传统正弦激活 MLP 虽能引入周期性，但每层只能向前传递单一正弦函数；后续层若想调整潜在周期函数的相位，需要依赖训练反向传播逐步学习，表达效率和训练效率仍有提升空间。
- **整体含义**：本文提出一种基于复指数函数的改进周期激活，使每层同时输出正弦和余弦对。在立方瑞利–贝纳德对流中，从稀疏速度数据重建温度，该架构显著提升重建质量，且单步训练开销基本不增加；达到相近精度所需优化步数大幅减少。作者认为，性能提升的关键在于后续层可以按神经元独立调整上一层潜在周期函数的相位。

## 2. 方法论

- **核心思想**：将复指数函数作为激活函数，使网络层输出同时包含余弦和正弦分量。这样，下一层在实数线性组合中能够把同一潜在周期函数的正弦、余弦重新组合为带可训练相位的周期函数。
- **网络结构**：
  - 使用多层感知机（MLP），但参数和中间输出采用复数形式。
  - 单层可写为：  
    \(g^{(L)}(x^{(L-1)}) = x^{(L)} = \exp\left(i\,\Im(W^{(L)}x^{(L-1)}+b^{(L)})\right)\)。
  - 即只对线性变换的虚部取指数，输出实部为余弦、虚部为正弦。
  - 权重 \(W^{(L)}\) 和偏置 \(b^{(L)}\) 为复数。
  - 最后一层只取实部，并使用实数权重和偏置做线性组合，输出流场量。
- **输入与初始化**：
  - 输入为时空坐标 \(x^{(0)}=[t,x,y,z]\)，为实数，因此虚部为 0。
  - 所有偏置和权重矩阵实部初始化为 0。
  - 权重虚部使用 Glorot 初始化。
  - 第一层采用类似 SIREN 的 adapted Glorot 初始化，从均匀分布 \(U(-w\sqrt{6/N}, w\sqrt{6/N})\) 采样，\(w=3\)。
- **训练设置**：
  - Adam 优化器，学习率固定为 \(10^{-4}\)，训练 \(10^6\) 步。
  - 损失为多项加权和：数据损失、Navier–Stokes 动量损失、能量方程损失、连续性损失、压力中心化损失、边界损失等。
  - 数据损失从稀疏速度数据中采样，PDE 和边界条件在时空域/边界上随机均匀采样。
- **数学解释**：
  - 正弦激活 MLP 层为：  
    \(\tilde g_i^{(L)} = \sin(\sum_j \tilde W_{ij}^{(L)} \sin(\tilde h_j^{(L-1)}) + \tilde b_i^{(L)})\)。
  - 复指数激活展开后，层间组合可写成：  
    \(g_i^{(L)} = \cos(\sum_j W_{ij}^{(L)} \sin(h_j^{(L-1)}+\varphi_{ij}^{(L)}) + \Im(b_i^{(L)})) + i\sin(h_i^{(L)})\)。
  - 其中相位 \(\varphi_{ij}^{(L)} = \arctan2(\Im(W_{ij}^{(L)}), \Re(W_{ij}^{(L)}))\)。
  - 这意味着：上一层提供的同一潜在周期函数，可以被下一层每个神经元以不同相位使用；而传统正弦 MLP 难以在下一层实现这种“单特征、多相位”的灵活复用。
