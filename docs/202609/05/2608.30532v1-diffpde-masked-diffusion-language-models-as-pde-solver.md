## 摘要
现有的偏微分方程（PDE）求解器合成方法主要依赖自回归模型，然而在处理固有的局部化错误时，其全局从左到右的解码方式会造成大量冗余。在这项工作中，我们挑战这种低效范式，提出DiffPDE，一个利用离散扩散语言模型进行针对性代码修复的框架。通过引入局部重新掩码和填充策略，DiffPDE仅重新生成错误区域，同时保留正确的上下文，使生成过程与PDE错误的稀疏性自然对齐。此外，为了处理需要顺序干预的耦合错误，我们提出了迭代调试GRPO（ID-GRPO），这是一种强化学习方案，能够通过中间奖励在单条轨迹内实现多轮调试。在PDEBench上的实验表明，DiffPDE达到了具有竞争力的准确度，优于同等规模的自回归模型，并显著加快了修复速度。

## Abstract
Existing approaches for synthesizing Partial Differential Equation (PDE) solvers predominantly rely on autoregressive models, yet their global left-to-right decoding incurs substantial redundancy when addressing inherently localized bugs. In this work, we challenge this inefficient paradigm and propose DiffPDE, a framework leveraging discrete diffusion language models for targeted code repair. By introducing a localized re-masking and infilling strategy, DiffPDE regenerates only erroneous regions while preserving correct context, naturally aligning generation with the sparse nature of PDE errors. Furthermore, to handle coupled bugs requiring sequential interventions, we present Iterative Debugging GRPO (ID-GRPO), a reinforcement learning scheme that enables multi-round debugging within single trajectories via intermediate rewards. Experiments on PDEBench show that DiffPDE achieves competitive accuracy, outperforms same-scale AR models, and significantly accelerates repair.

针对这一问题，论文提出DiffPDE，一个基于**离散扩散语言模型（dLLM）**的PDE求解器生成与修复框架。核心洞察是：dLLM天然具备双向解码能力，可以同时利用掩码位置左右两侧的上下文进行预测，因此非常适合"只对错误区域进行局部重掩码（re-masking）和填充（infilling）修复"这一范式，从而与PDE代码错误的稀疏性、局部性自然对齐。

整体含义：**将PDE求解器的自动调试从"全量重写"转变为"局部精准修复"**，在保持求解精度的同时大幅降低修复延迟，为LLM驱动的科学计算代码生成提供了一种更高效的范式。

## 2. 论文提出的方法论

### 2.1 核心思想

DiffPDE的核心方法分为三个层面：

1. **从零生成（From-scratch Generation）**：dLLM根据PDE描述，先生成Chain-of-Thought（CoT）推理路径（规划数值格式、时空离散化方案），再生成可执行的PDE求解器代码。采用类似LLaDA的**半自回归解码**策略，分块顺序生成、块内扩散迭代细化，兼顾长代码序列的生成质量与效率。

2. **局部重掩码与填充（Localized Re-masking and Infilling）**：当执行反馈暴露出错误时，不重新生成整个求解器，而是通过确定性traceback定位出错代码区间，仅将该区间替换为[MASK]标记，让dLLM在完整左右上下文条件下进行span-level填充修复。这一操作建立在条件概率公式之上：
   \[
   p_\theta(x_{0,l:r} \mid x_{0,<l},\, x_{0,>r})
   \]
   即利用左右两侧未损坏的上下文预测中间被掩码的错误片段。

3. **两阶段训练管线**：
   - **SFT阶段**：使用掩码扩散目标进行训练，
     \[
     \mathcal{L}_{\text{SFT}} = -\mathbb{E}_{(q,x_0)}\mathbb{E}_{t\sim U[0,1]}\left[\sum_{i\in\mathcal{M}_t} \log p_\theta(x_{0,i} \mid x_t, q)\right]
     \]
     统一覆盖从高噪声级别的"从零生成"到低噪声级别的"局部填充"能力。
   - **RL阶段（ID-GRPO）**：提出Iterative Debugging GRPO，核心设计包括：
     - **动态缓冲与任务分配**：每轮RL先做生成rollout，将成功求解器转化为随机掩码的"构造型填充任务"，将失败求解器转化为"错误驱动的填充任务"，通过动态调节两类任务比例实现从易到难的课程学习。
     - **多轮中间奖励**：针对耦合错误导致二元成功信号过于稀疏的问题，设计中间奖励信号 \( r_{\text{inter}} \)，当连续两次修复的错误签名集合出现严格缩减时给予奖励；最终多轮奖励聚合为：
       \[
       r_{\text{MR}} = \max_{j\in\{1,\dots,R\}} r(c^{(j)}) + r_{\text{inter}}
       \]
       兼顾最终结果与过程性进展。

### 2.2 推理阶段流程

采用"生成→执行→调试"循环：模型生成求解器 → 执行并评估 → 若失败或精度不足，从执行反馈定位问题代码区域 → 重掩码 → 局部填充修复 → 再次执行，直到成功或预算耗尽。

## 6. 论文的主要结论与发现

1. **扩散LM在PDE求解器任务上具备竞争力**：DiffPDE-7B在1D Advection上达到4.5×10⁻³，超过GPT-5.2；在1D Reaction-Diffusion上与SOTA大模型持平（3.0×10⁻²）；在Burgers上显著优于同规模AR基线（9.7×10⁻⁴ vs Qwen3-8B的1.3）。

2. **同规模优势巨大**：在所有任务上，DiffPDE-7B均大幅超过Qwen2.5-Coder-7B和Qwen3-8B（如Burgers精度从O(1)量级降至9.7×10⁻⁴），验证了扩散架构 + 执行反馈RL的有效性。

3. **修复速度提升显著**：在局部填充模式下，每次调试生成从AR的20~120秒降至**0.60~0.99秒**，加速约30×~100×；即使考虑初始生成较慢的代价，DiffPDE的端到端最坏成本仍为55.5s，低于Qwen2.5-Coder-7B（102.1s）和Qwen3-8B（119.3s）。

4. **局部修复确实更优**：在同一DiffPDE检查点下，局部修补在5/5个PDE任务上Pass@32不低于全量重生成（平均0.5063 vs 0.4938），延迟从64.85s降至0.748s，约86×速度提升。

5. **错误形态支持局部化假设**：初始失败中**76.8%为局部错误**，只有5.4%需要全局结构修改，为所提出方法提供了经验依据。

6. **RL各组件均有效**：完整ID-GRPO相较去掉中间奖励或去掉动态缓冲的变体，分别将平均Pass@32从0.37/0.38提升至0.52，说明中间奖励与课程式任务分配均对训练稳定性有实质贡献。

## 7. 优点

1. **范式创新**：将"局部重掩码+填充"引入PDE求解器调试，精确对准了真实调试操作中错误高度局部化的特性，突破了AR模型的全局解码冗余瓶颈，问题定位与生成机制高度自洽。

2. **方法设计完整且自洽**：从从零生成到局部修复的跨度，通过SFT的随机掩码统一目标自然衔接；RL阶段通过"生成rollout衍生构造型填充任务 + 失败输出转为错误驱动填充任务"的机制实现了生成与修复能力的协同优化。

3. **RL奖励工程精细**：ID-GRPO中的中间奖励设计有较强的可实现性——通过错误签名集合的严格子集关系判断"是否在变好"，避免了稀疏二元奖励下多轮耦合错误难以学习的问题，且对无法提取签名的情况提供了文本长度的fallback机制。

4. **对比实验控制在较高水平**：同一候选预算、调试轮次、提示词与执行环境；并在表7中做了严格的"同检查点、同反馈、不同修复方式"的变量隔离实验，论证严谨。

5. **效率证据链完整**：从每次修复延迟、端到端最坏成本到Pass@32，多维度证实了"虽然初始生成略慢，但修复效率优势足以显著摊薄总成本"这一核心论断。

## 8. 不足与局限

1. **全局结构性错误覆盖不足**：论文自身承认，5.4%的初始失败需要全局结构修改（如整体数值格式选择错误、跨函数逻辑重组），这类问题超出当前局部填充框架的能力边界。

2. **初始生成效率仍是短板**：即便使用Fast-dLLM加速，DiffPDE从零生成的平均耗时（53.17s）仍高于同规模的Qwen2.5-Coder-7B（23.8s左右），这限制了其在无调试需求场景下的使用价值。

3. **在小参数模型上的成功率波动明显**：DiffPDE在Reaction-Diffusion上的Pass@32仅0.28，低于Qwen3-8B的0.31；Darcy Flow上仅0.09，远低于Qwen3-8B的0.44。论文将其归因于小参数模型对椭圆型PDE先验缺乏以及采样波动，但这一短板恰好落在最需要鲁棒性的复杂任务上，影响可信度。

4. **测试集多为时间依赖1D问题**：五种PDE中四种是周期边界下的1D问题，2D Darcy是唯一的稳态/椭圆任务且表现最差。对高维、复杂边界、多物理场耦合等更实际场景的覆盖有限。

5. **SFT数据规模和多样性受限**：约1K条由教师模型生成的轨迹，且数据按固定参数集采样，模型是否对训练参数范围外的物理条件具有泛化能力尚不明确。

6. **报告口径偏向乐观**：best-of-32的选择掩盖了候选间的方差；Pass@32为0.28~0.78的小参数模型在真实单次生成的可靠性上仍有较大提升空间。

7. **修复策略依赖执行反馈的可提取性**：错误定位依赖traceback中的行号和自然代码边界，对没有清晰traceback的逻辑错误（代码可运行但数值错误）需要通过nRMSE阈值判断错误区间，机制需进一步研究。

8. **对专业求解器/神经代理不具备全面优势**：论文承认在部分任务上无法普遍超越精细调优的专家求解器（如FNO在多数任务上误差更低），其优势主要体现在"不依赖任务定制、全自动生成且接近大模型效果"这一层面。
