## 摘要
物理信息神经网络（PINNs）通过将物理约束纳入神经网络训练来求解PDE，但大规模问题受限于自动微分内存开销和基于网格的PDE算子执行效率低下。我们提出FlashPDE，一个即插即用的融合算子库，用于基于网格的科学机器学习。FlashPDE用可微分的Triton内核替换了碎片化的PyTorch有限差分执行。每个算子在统一的PyTorch autograd Function接口内集成了融合模板求值、解析离散伴随反向传播和边界梯度校正。该库提供了14个可微分的PDE算子，涵盖1D-3D椭圆、抛物线和Navier-Stokes系统的17种配置，同时保持与神经架构和训练策略无关。在NVIDIA A100 GPU上的实验表明，与基于坐标的自动微分相比，FlashPDE将峰值内存使用量减少了高达37.0倍，与即时PyTorch有限差分实现相比，CUDA内核启动次数减少了高达3.5倍。在六个代表性PDE基准测试中，FlashPDE实现了高达2.30倍的端到端求解时间加速和高达19.2倍的内核级加速，同时保持了与PyTorch有限差分参考的数值一致性。FlashPDE在PyTorch生态系统中提供了一个硬件高效的执行层，桥接了可微分PDE求解器和GPU优化的数值计算。

## Abstract
Physics-Informed Neural Networks (PINNs) solve PDEs by incorporating physical constraints into neural-network training, but large-scale problems are limited by automatic-differentiation memory overhead and inefficient execution of grid-based PDE operators. We present FlashPDE, a drop-in fused operator library for grid-based scientific machine learning. FlashPDE replaces fragmented PyTorch finite-difference execution with differentiable Triton kernels. Each operator integrates fused stencil evaluation, an analytic discrete-adjoint backward pass, and boundary-gradient correction within a unified PyTorch autograd Function interface. The library provides 14 differentiable PDE operators covering 17 configurations across 1D--3D elliptic, parabolic, and Navier--Stokes systems, while remaining independent of neural architectures and training strategies. Experiments on an NVIDIA A100 GPU show that FlashPDE reduces peak memory usage by up to 37.0x compared with coordinate-based automatic differentiation and reduces CUDA kernel launches by up to 3.5x compared with eager PyTorch finite-difference implementations. Across six representative PDE benchmarks, FlashPDE achieves up to 2.30x end-to-end time-to-solution speedup and up to 19.2x kernel-level acceleration while maintaining numerical agreement with PyTorch finite-difference references. FlashPDE provides a hardware-efficient execution layer that bridges differentiable PDE solvers and GPU-optimized numerical computation within the PyTorch ecosystem.

### 1. 核心问题与整体含义

物理信息神经网络（PINNs）通过最小化 PDE 残差将物理约束融入神经网络训练，广泛应用于科学机器学习。然而，当扩展到三维大规模问题时，面临两个关键瓶颈：

- **自动微分内存开销**：标准 PINNs 依赖 `torch.autograd` 计算高阶空间导数，由于需要保持嵌套计算图（`create_graph=True`），中间导数张量造成巨大的 GPU 内存消耗，在三维多场系统中常导致 OOM。
- **内核启动碎片化**：基于输出网格的有限差分（FD）替代方案虽然避免了自动微分的计算图、大幅降低内存，但原生 PyTorch 实现使用张量切片和逐元素操作表达模板，导致大量独立的 CUDA 内核启动和重复的全局内存访问，I/O 和调度开销显著。

FlashPDE 旨在弥合可微求解器与 GPU 优化数值计算之间的鸿沟，提供一种在 PyTorch 生态内硬件高效的执行层。

### 2. 方法论

**核心思想**：将碎片化的 PyTorch 有限差分 PDE 算子替换为通过 Triton GPU 内核实现的可微分融合算子，封装在 `torch.autograd.Function` 中，实现“即插即用”。

**关键技术细节**：

- **融合前向模板**：每个 Triton 程序实例处理一个空间 tile。通过合并内存访问加载所需场值，在片上（SRAM）计算中心差分、非线性项和残差表达式，仅将最终残差写入全局内存。例如 2D Navier-Stokes 残差在一个内核中完成，避免大量中间张量物化。
- **离散解析伴随反向传播**：反向时，接收上游残差敏感性，手动推导离散 Jacobian 的转置运算。以 2D Navier-Stokes 中 $\partial L / \partial u_{i,j}$ 为例，包含局部残差导数、相邻模板依赖和交叉场耦合（如式 (1)）。该解析形式直接在反向 Triton 内核中实现，避免自动微分中间图。
- **边界梯度校正**：为了保持内点内核的高效性，边界特定的梯度项通过独立的一维校正内核处理。因此每个算子共三个 Triton 启动：前向模板、内部解析伴随、边界校正。
- **架构无关性**：算子消费网格对齐的物理场张量，不依赖神经网络内部结构；同一算子可用于 MLP 和 CNN 场生成器，且无需修改算子实现、外部损失或边界条件。

**公式示例**（式 (1) 文字说明）：$u_{i,j}$ 的梯度由自身残差导数、上下左右邻居残差导数、交叉方程 $v$ 和连续性约束的贡献求和得到，每个贡献包含显式的离散系数（如 $2\nu/\Delta x^2$）。手动导出后直接在 Triton 内核中实现。

- **内存节省**：输出网格 FD 相比坐标自动微分，峰值内存降低 5.9×–37.0×（3D TGV 从 >40GB 降至 3.4GB）。FlashPDE 保持此低内存特性。

- **精度可比**：FlashPDE 与 PyTorch FD 的解误差相近，数值验证显示极好的一致性。

### 7. 优点

- **即插即用**：只需将原 PyTorch FD 残差替换为 FlashPDE 算子，无需修改神经架构、损失函数或训练循环。
- **架构无关**：同一算子兼容 MLP 和 CNN，降低迁移成本。
- **手动导出离散伴随**：避免自动微分图，同时保证反向传播正确；所有算子经双精度验证。
- **边界处理分离**：设计高效，避免内部内核分支开销。
- **广泛覆盖**：14 个算子支持 17 种常见 PDE 类型（椭圆、抛物、双曲、守恒律、相场、不可压/可压流）。
- **可复现性**：代码开源。

### 8. 不足与局限

- **网格限制**：仅支持规则 Cartesian 网格，无法直接用于随机配点、不规则几何或非结构网格。
- **手动推导**：每个新 PDE 算子需要手动推导离散伴随并编写 Triton 内核，自动化生成是未来工作。
- **精度局限**：不改善底层 FD 离散化的精度；解质量取决于模板阶数、网格分辨率、边界处理和网络优化。
- **加速上限**：仅加速 PDE 求值部分，当网络计算占主导时全步加速有限（如 3D TGV 仅 1.12×）。
- **对比基线**：未与专家优化的手写 CUDA 模板（如 Devito、STELLA）直接比较，论文承认未来需补充。
- **硬件可移植性**：仅在单张 A100 上测试，多 GPU 及其他架构上的性能未评估。
- **冷启动成本**：Triton 编译和 autotune 约 2–5 秒，在短时间训练中可能影响显著。
