## 摘要
岩土工程中的弹塑性边值问题通常采用有限元法（FEM）求解，但增量-迭代过程导致计算成本高昂。物理信息神经网络（PINNs）提供了一种无网格替代方案，但存在频谱偏差，难以解析弹塑性边界及局部塑性区内出现的陡峭梯度。这一局限对非关联莫尔-库仑模型尤为显著，因其压力相关的屈服面与剪胀流动法则产生的塑性区更窄、应力梯度比压力无关准则更陡。本研究提出一种傅里叶特征物理信息神经网络（FF-PINN），用于求解该模型控制的二维弹塑性问题。将随机傅里叶特征映射嵌入输入层以缓解频谱偏差，并辅以多目标损失函数，该损失函数基于高保真有限元数据强制执行平衡方程、本构关系及Karush-Kuhn-Tucker条件，同时采用应变自适应采样策略。在三个测试案例中，FF-PINN在大多数预测场上实现了更优精度，位移误差降低约66%，应力分量误差降低约27%，且塑性破坏区几何形态与有限元结果匹配度显著更高。敏感性分析证实了其在训练数据规模、配置点密度、损失权重及高达2.0%噪声水平下的鲁棒性。FF-PINN的收敛所需训练轮数仅为传统PINN的一半，将训练时间减半，同时实现更高的预测精度。因此，该框架为岩土弹塑性分析提供了一种计算高效且物理一致且的有限元替代方案。

## Abstract
Elasto-plastic boundary value problems in geotechnical engineering are conventionally solved by the Finite Element Method (FEM), which incurs high computational cost from incremental-iterative procedures. Physics-Informed Neural Networks (PINNs) offer a mesh-free alternative but suffer from spectral bias, failing to resolve the sharp gradients arising at elastic-plastic boundaries and within localized plastic zones. This limitation is particularly consequential for the non-associative Mohr-Coulomb model, whose pressure-dependent yield surface and dilatant flow rule generate narrower plastic zones and steeper stress gradients than pressure-independent criteria. This study proposes a Fourier Feature Physics-Informed Neural Network (FF-PINN) for two-dimensional elasto-plastic problems governed by this model. Random Fourier feature mapping is embedded into the input layer to mitigate spectral bias, supported by a multi-objective loss function enforcing equilibrium, constitutive relations, and Karush-Kuhn-Tucker conditions against high-fidelity FEM data, together with a strain-adaptive sampling strategy. Benchmarked across three test cases, FF-PINN achieves superior accuracy across most predicted fields, with error reductions up to approximately 66 percent in displacement and 27 percent in stress components, and reproduces the plastic failure zone geometry with markedly closer fidelity to FEM. Sensitivity analysis confirms robustness across training data size, collocation density, loss weighting, and noise levels up to 2.0 percent. FF-PINN converges in half the training epochs required by the conventional PINN, halving wall-clock training time while achieving greater predictive accuracy. The framework therefore offers a computationally efficient and physics-consistent alternative to FEM for elasto-plastic geotechnical analysis.

- **传统方法的瓶颈**：岩土工程中的弹塑性边值问题通常依赖有限元法（FEM）求解，但非线性的应力-应变行为要求每个载荷增量步执行增量-迭代过程（如 Newton-Raphson），计算成本高、耗时长。
- **PINNs 的替代潜力与缺陷**：物理信息神经网络（PINNs）通过将控制方程嵌入损失函数，提供无网格替代方案，可绕过迭代求解器和大规模标注数据。然而，标准全连接网络存在**频谱偏差（spectral bias）**——优先拟合低频分量，难以解析弹塑性边界及局部塑性区内的陡峭梯度。
- **非关联莫尔-库仑模型的特殊挑战**：该模型具有压力相关的屈服面和剪胀流动法则，比 von Mises 等压力无关准则产生**更窄的塑性区**和**更陡的应力梯度**，恰好是标准 PINN 结构性最难以解析的区域。
- **研究缺口**：尽管傅里叶特征映射已在其他物理信息学习场景中被证实可缓解频谱偏差，但尚未用于压力依赖、非关联塑性问题；且已有两项莫尔-库仑 PINN 研究（Yuan et al., 2026；Zhang et al., 2026）均未结合任何频谱偏差缓解机制。
- **研究目标**：提出 FF-PINN 框架，首次将随机傅里叶特征映射引入压力依赖、非关联塑性问题的 PINN 求解中，在保持物理一致性的同时，以更低计算成本逼近 FEM 精度。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想

通过改变网络输入的频谱表示，而非增加网络容量或修改优化策略，来缓解频谱偏差——使网络从训练之初即可访问高频基函数，从而解析弹塑性边界处的陡峭梯度。

### 2.2 控制方程与本构模型

- **平衡方程**（忽略体力）：σij,j = 0
- **几何关系**（小变形假设）：εij = ½(ui,j + uj,i)
- **非关联莫尔-库仑模型**：
  - 采用 Menétrey–Willam 屈服函数：F = Rmc·q − p·tanφ − c = 0，其中 Rmc 为偏平面椭圆函数，用于光滑化经典莫尔-库仑六边形的奇异角点。
  - 塑性势函数 G 独立于屈服函数 F，引入剪胀角 ψ；当 ψ = 0 时（本文所有算例），屈服面与塑性势偏离最大，构成**最严苛的非关联流动法则**。
  - 塑性应变：εp = λ·∂G/∂σ，塑性乘子 λ 由一致性条件解析求解。
  - KKT 条件：λ ≥ 0，F ≤ 0，λF = 0 控制塑性流动的激活。

### 2.3 网络架构

- **传统 PINN 基线**：全连接网络，输入空间坐标 (x, y)，输出位移 (u, v) 和四个面内应力分量 (σxx, σyy, σzz, σxy)，tanh 激活函数。
- **FF-PINN 改进**：输入坐标先经随机傅里叶特征映射 γ(v) = [cos(2πBv), sin(2πBv)]ᵀ 投影到高频正弦基函数空间，再送入隐藏层。频率矩阵 B 的条目从高斯分布 N(0, σ²) 采样，训练前固定，不增加可训练参数。
- **关键设计**：修改仅局限于输入层，确保与传统 PINN 的性能差异可归因于编码的频谱特性，而非网络容量或优化设置。

### 2.4 多目标损失函数

总损失为物理损失与数据驱动损失的加权组合：

**物理损失** L_physics = w_eq·L_eq + w_con·L_con + w_KKT·L_KKT + w_bc·L_bc：
- 平衡残差 L_eq
- 本构关系残差 L_con
- KKT 条件残差 L_KKT（分别惩罚 λ < 0、F > 0 和 λF ≠ 0）
- 边界条件残差 L_bc（Dirichlet + Neumann）

**数据驱动损失** L_data = L_u + L_σ + L_ε + L_εp：
- 对比网络预测与 FEM 参考解的位移、应力、总应变和塑性应变场。

**权重配置**：w_physics = 1，w_data = 15（1:15 的经验最优比）。

### 2.5 应变自适应采样（SAS）

- 基于 FEM 参考解计算每个候选点的局部应变幅值 S_i。
- 采样概率正比于应变幅值 P_i = S_i / ΣS_i，使配置点在应变集中的塑性区聚集。
- 与网格采样相比，SAS 在固定总点数下将训练资源从网络易解析的区域重分配到高梯度关键区域。

### 6.4 鲁棒性

- 对噪声不敏感：两模型在 0.5%–2.0% 噪声范围内均无系统性误差增长，但 FF-PINN 的误差带更窄、更稳定。
- 在约 1,237 个训练点和 5,000 个配置点处达到有效收敛，进一步增加边际收益有限。

### 6.5 已知例外

- 少数场变量 FF-PINN 误差略高（Case 3 的 ux、Case 2 的 σzz、Case 1/3 的 εxx^p、Case 3 的 εzz^p、Case 2 的 εxy^p）。
- εzz^p（面外塑性应变）在所有模型和所有案例中持续保持 60–80% 的高误差，被识别为**根本性近似挑战**，数据增加无法解决。

## 7. 优点

1. **问题选择具有针对性**：非关联莫尔-库仑模型是岩土分析中最具实际意义且对频谱偏差最敏感的本构模型之一，研究缺口明确。
2. **消融设计严谨**：仅修改输入层编码，所有其他因素保持恒定，因果归因清晰。
3. **物理一致性**：多目标损失同时强制平衡方程、本构关系、KKT 条件及边界条件，而非纯数据拟合。
4. **系统的超参数分析**：对网络深度/宽度、傅里叶映射大小/尺度参数进行了全面的网格扫描，提供了实用的调参指导（深度 > 宽度；σ 比映射大小更关键）。
5. **全面的敏感性分析**：覆盖数据规模、配置点密度、损失权重、噪声水平四个维度，且噪声实验含 5 次独立运行的标准差，统计严谨。
6. **负面结果透明**：如实报告例外场和 εzz^p 的持续高误差，未选择性筛选结果。
7. **计算成本显式量化**：提供训练时间、轮数、参数数的定量对比，并引入等计算预算视角（683 s 时 FF-PINN 已解析塑性带，传统 PINN 尚未）。

## 8. 不足与局限

### 8.1 实验覆盖的局限

- **仅限二维平面应变**：未扩展到三维几何，而实际岩土工程问题普遍为三维。
- **单一几何构型**：所有案例均为同一矩形域 + 条带加载，缺乏对复杂边界/几何的泛化验证。
- **单调加载**：未考虑循环加载和路径依赖行为，而这些是岩土材料的重要特征。
- **恒定弹性参数**：E 和 ν 在所有案例中固定，未测试弹性参数变化的影响。
- **数据依赖**：需要 FEM 参考数据作为数据驱动损失锚点，并非纯无数据 PINN；在高保真数据稀缺的场景下应用受限。

### 8.2 方法层面的局限

- **εzz^p 的根本性困难**：面外塑性应变分量在所有实验中的误差始终远高于其他场（60–80%），论文承认这是数据无法解决的固有问题，但未提出有效解决方案。
- **个别场变量退化**：少数场景下 FF-PINN 误差略高于基线 PINN（如 Case 2 的 εxy^p），说明傅里叶映射并非普适改进。
- **σ 上限约束**：过大的傅里叶尺度参数（σ ≥ 1.0）会产生空间不连贯的应力场和训练不稳定，需要谨慎选择。
- **参数规模增加**：FF-PINN 可训练参数比传统 PINN 多约 65,000，尽管总训练时间下降，但单轮成本略增。
- **权重比率敏感性**：损失权重比（1:15）需人工调优，且存在"过高数据权重反而导致精度下降"的非单调行为（1:30 时 ux 误差回升）。

### 8.3 偏差风险

- **谱偏差缓解的验证范围有限**：结论建立在单一本构模型和几何配置上，向其他塑性模型（如修正剑桥模型）的迁移效果未经验证。
- **随机性来源**：傅里叶频率矩阵和自适应采样的随机性可能引入运行间波动，尽管噪声实验报告了标准差，但主实验结果未报告多次运行的不确定性。
