## 摘要
从数据中符号发现控制方程不仅受算法设计和数据量的限制，还受吸引子几何的限制：长期动力学允许恢复的内容。通过在Lorenz-84系统内进行设计，其中一个强迫参数驱动不动点、极限环和混沌状态，而控制方程和库保持固定，我们展示了单个数字$λ_{\min}(M)$（不变测度矩矩阵的最小特征值）为稀疏回归（SINDy）和进化符号回归（PySR）设定了可识别性上限。该数字源于Birkhoff遍历定理，并在任何运行之前从短参考轨迹获得，$λ_{\min}(M)$衡量吸引子覆盖函数空间的充分程度：当其消失时，任何算法（无论是稀疏还是组合方法）都无法恢复；当其增长时，两种算法均有所改善。混沌通过扩展吸引子来提高$λ_{\min}(M)$，但同时也会使其放大并放大噪声；由于噪声以线性方式进入SINDy的回归瓶颈，并以超线性方式进入PySR的判别通道，相同的转换可能使两种方法向相反方向推进，因此更深层次的混沌并不总是更好。来自该框架的无参数机制评分无需重新拟合即可转移至保留的Lorenz-96系统，确认了机制而非曲线拟合；从方程中读取的一个标准可预测何时增加的混沌不会改善条件作用。我们还引入了Soft F1，一种系数加权结构度量，可解决二元成功和预测评分无法识别的性能差异。因此，发现的首要问题不是选择哪种算法，而是吸引子允许什么。

## Abstract
Symbolic discovery of governing equations from data is limited not only by algorithm design and data volume, but by the geometry of the attractor: what the long-run dynamics allow to be recovered. Using a within-system design on Lorenz-84, where one forcing parameter drives fixed-point, limit-cycle, and chaotic regimes while the governing equations and library stay fixed, we show that a single number, $λ_{\min}(M)$, the smallest eigenvalue of the invariant-measure moment matrix, sets the identifiability ceiling for both sparse regression (SINDy) and evolutionary symbolic regression (PySR). Derived from the Birkhoff ergodic theorem and obtained from a short reference trajectory before any run, $λ_{\min}(M)$ measures how fully the attractor covers function space: where it vanishes, recovery is impossible for any algorithm, sparse or combinatorial alike; as it grows, both algorithms improve. Chaos raises $λ_{\min}(M)$ by spreading the attractor, but also enlarges it and amplifies noise; because noise enters SINDy's regression bottleneck linearly and PySR's discrimination channel superlinearly, the same transition can push the two methods in opposite directions, so deeper chaos is not uniformly better. Parameter-free mechanistic scores from this framework transfer without refitting to a held-out Lorenz-96 system, confirming mechanism rather than curve-fitting; a criterion read from the equations predicts when added chaos will not improve conditioning. We also introduce Soft F1, a coefficient-weighted structural metric that resolves performance differences invisible to binary-success and predictive scores. The first question of discovery is then not which algorithm, but what the attractor permits.

### 论文提出的方法论

- **核心思想**：利用 Birkhoff 遍历定理，长时间轨迹的字典 Gram 矩阵收敛于吸引子不变测度 $\mu$ 下的矩矩阵 $M = \int \Phi(x) \Phi(x)^\top d\mu(x)$。其最小特征值 $\lambda_{\min}(M)$ 衡量吸引子在函数空间的覆盖度：为零时吸引子退化（如不动点），恢复在信息上不可能；为正时定量地设定了正则化和噪声容忍度的尺度。
- **关键技术细节**：
  - **SINDy 的机制模型**：基于 STLSQ 优化器，识别两个威胁比——假阴性威胁 $T_{FN} = \lambda / (w_{\min} \|\xi_{\text{gt}}\|)$ 和假阳性威胁 $T_{FP} = \kappa_{\text{eff}} \cdot \rho_{\text{EIV}} \cdot \sigma_\varepsilon / \lambda$。组合得分 $F_{\text{SINDy}} = \max(T_{FN}, T_{FP})$。当任一大于 1 时，固定阈值 $\lambda$ 无法同时保留真实项和排除虚假项。
  - **PySR 的机制模型**：包含两个独立瓶颈：
    - 条件瓶颈：$\sigma_{\min, \text{partial}}$ 表征真实项的信号不能被虚假组合复制的程度（通过 Schur 补从过完备字典中提取）。
    - 信噪比判别瓶颈：$Q_{\text{noise}} = \prod_{k=1}^{n_{\text{nc}}} \min\Bigl(1, \sqrt{\varepsilon_{\text{wrong},k}/\sigma_\varepsilon^2}\Bigr)$，衡量每个真实项留下的不可解释部分相对于导数噪声的大小。
  - 组合得分 $F_{\text{PySR}} = \sqrt{\sigma_{\min, \text{partial}}^{1/4} \cdot Q_{\text{noise}}}$，其中幂和几何平均在 Lorenz-84 上选择，在 Lorenz-96 上零参数验证。
- **Soft F1 度量**：针对方程发现，对每个项赋予指数衰减的系数接近权重 $w_j = e^{-\alpha \delta_j}$（$\alpha=3$ 使 2 倍误差对应 1 纳特），然后计算软精度和软召回率的调和均值。解决了结构 F1 忽视系数精度、预测指标忽视结构错误的问题。

### 论文的主要结论与发现

1. **吸引子几何决定可识别性上限**：$\lambda_{\min}(M)$ 是核心量化指标。不动点时 $=0$（Fisher 信息奇异，任何算法无法恢复任何一个项）；极限环时为正但很小，恢复在理论上可能但受正则化和噪声容忍极限限制；混沌时增大，但提升同时放大噪声。
2. **混沌并非总是更好**：混沌提升 $\lambda_{\min}(M)$ 的同时也扩大了吸引子振幅 $\sigma_x$，放大了噪声。SINDy 噪声指数为 1（线性响应），PySR 指数为 $n_{\text{nc}}=3$（超线性响应），导致同一混沌深度可能对 SINDy 有利而对 PySR 不利。当方程中存在**阻尼驱动坐标**且无交换对称性时，更深混沌甚至可能降低该坐标的方差，从而不改善条件（实例：Lorenz-84 的 $x_0$）。
3. **算法独立的极限**：$\lambda_{\min}(M)$ 决定了一个不可能低于的 Cramér–Rao 界：$ \lambda_{\min}(M) \gtrsim \sigma_\varepsilon^2 / (N c_{\min}^2) $，任何无偏估计器都不能超越。
4. **Soft F1 指标**：系数加权的调和均值，能区分仅结构正确但系数偏差很大的结果与完全准确的结果，暴露了二元成功率和预测指标无法察觉的性能差异。
5. **机制指标可迁移**：从 Lorenz-84 推导的 $F_{\text{SINDy}}$ 和 $F_{\text{PySR}}$ 无需重新拟合即可在 Lorenz-96 上保持高 Spearman 相关（平均 $>0.82$），表明是机制而非曲线拟合。
6. **先验质量是强有力的杠杆**：约束字典（如使用 oracle 或过完备库）能大幅提升 PySR 性能，尤其在噪声高时，因为该杠杆不引入噪声项。

### 优点

- **实验设计精巧**：采用 within-system 设计，控制方程和库不变，仅改变参数驱动动态状态，将动态状态作为唯一变量，避免了跨系统比较的混淆。
- **理论深度与可计算性结合**：从遍历理论严格推导出 $\lambda_{\min}(M)$ 与可恢复性之间的数量关系，并展示通过短参考轨迹即可计算该量，从而可**在运行任何发现算法之前**评估系统可行性。
- **双重机制模型**：分别为 SINDy 和 PySR 推导了不带可调参数的机制得分，揭示了两类算法不同的噪声响应通道（线性和超线性），解释了“混沌有时不利”的反直觉现象。
- **新颖的 Soft F1 度量**：填补了现有评估指标的空白，平衡了系数准确性和结构正确性，适合作为标准 benchmark。
- **强化的验证链条**：内部 L84 三大实验 → 迁移到 L96 零调参验证 → 再扩展到非多项式 JERK 系统，显示了框架的鲁棒性和泛化能力。

### 不足与局限

- **全状态观测假设**：框架假设系统所有状态可被直接观测，未考虑部分观测（仅有少量变量、延迟嵌入或降维情况）。对于许多实际应用（如流场中仅测量部分速度分量），如何从部分数据重构不变测度并计算 $\lambda_{\min}(M)$ 仍是一个开放问题。
- **SINDy 机制得分的局限性**：$F_{\text{SINDy}}$ 需要知道哪些库项是真实项（ground-truth），因此只能用作诊断已完成运行的失败原因，而不能用于预先筛选系统（即它不是一个独立的系统可识别性筛查器）。
- **PySR 两通道独立假设**：论文将条件瓶颈和信噪比瓶颈视为独立并取几何平均，该假设在相关噪声下尚未验证。
- **混沌内部分析受限于样本量**：对 Lorenz-84 只取了 5 个混沌点，不足以确定趋势符号（p=0.39）。虽然论文承认这一点并仅作风险标记，但更深层次分析（如按 $\lambda_1$ 梯度建模）需要更多数据点。
- **实验系统多样性不足**：主要结果基于 Lorenz 类多项式 ODE。非多项式 JERK 系统仅在单无噪声条件下验证，缺乏噪声和数据量扫描。未测试偏微分方程、随机微分方程或高维系统（如 $n>10$）。
- **黑箱方法未测试**：论文的结论声称适用于任何算法（包括未来方法），但实验只覆盖了 SINDy 和 PySR。对于神经 ODE、算子学习网络等，是否同样受 $\lambda_{\min}(M)$ 限制仍需直接验证。
- **实用转化限制**：虽然 $\lambda_{\min}(M)$ 可计算，但论文未提供具体的优化算法来指导数据采集（如主动选择控制参数以最大化该量）。文中仅在讨论中提及可扩展为设计算法，但未实现。
