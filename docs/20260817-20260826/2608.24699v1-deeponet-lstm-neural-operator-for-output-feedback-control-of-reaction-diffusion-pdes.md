## 摘要
本文提出了一种基于神经算子的方法，用于反应扩散偏微分方程的输出反馈边界镇定。经典输出反馈反步设计需要针对每个反应系数求解控制核方程和观测器核方程。为避免计算这些核函数，将输出反馈控制律重新表述为因果边界算子，该算子将反应系数和边界测量映射到边界控制输入。提出了一种混合DeepONet-LSTM神经算子来近似该因果算子，其中DeepONet编码空间系数，LSTM捕获测量历史的时间依赖性。我们分析了边界算子的Lipschitz连续性，并证明了所学控制器下的闭环实际稳定性。还引入了一种修改后的损失函数，以提高所学边界输入的时间正则性。数值结果表明，所提出的神经算子控制器能有效镇定该系统。

## Abstract
This paper presents a neural operator-based approach for the output feedback boundary stabilization of reaction diffusion PDEs. The classical output feedback backstepping design requires solving control and observer kernel equations for each reaction coefficient. To avoid computing these kernel functions, the output feedback control law is reformulated as a causal boundary operator that maps the reaction coefficient and the boundary measurement to the boundary control input. A hybrid DeepONet-LSTM neural operator is proposed to approximate this causal operator, where DeepONet encodes the spatial coefficient and LSTM captures the temporal dependence of the measurement history. We analyze the Lipschitz continuity of the boundary operator and prove the closed-loop practical stability with the learned controller. A modified loss is also introduced to improve the temporal regularity of the learned boundary input. Numerical results illustrate that the proposed neural operator controller effectively stabilizes the system.

- **核心问题**：反应扩散偏微分方程（PDE）的边界镇定通常采用反步（backstepping）输出反馈控制设计。经典方法需要针对每个空间变化反应系数 λ(x) 分别求解控制核方程和观测器核方程，在参数变化或实时控制场景下计算成本高昂。
- **研究动机**：
  - 已有神经算子方法（如 [2]、[3]）通过近似反步核函数或全状态反馈算子来降低离线计算，但**直接近似基于观测器的输出反馈算子**仍然缺乏探索。
  - 输出反馈控制中的控制输入由观测器动态生成，因此**依赖过去边界测量的历史**（因果性），这不同于全状态反馈中的瞬时映射，标准 DeepONet 或静态核近似无法直接建模。
- **整体含义**：本文提出一种**混合 DeepONet-LSTM 神经算子**，将输出反馈控制律重新表述为“反应系数 + 测量历史 → 边界控制输入”的因果边界算子，并用单一神经网络离线学习该算子，从而**完全避免在线求解核方程**和分别近似控制器/观测器增益，同时保留闭环稳定性。

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

### 核心思想
- 将经典反步输出反馈控制律 `U(t) = K_λ û(·,t)` 看作一个**因果算子** `T[λ, p_{[0,t]}](t)`，其中 `λ` 为反应系数，`p_{[0,t]}` 为边界通量测量 `p(t) = u_x(0,t)` 的历史。
- 通过 **DeepONet 编码空间系数**（对 λ 函数进行函数空间映射），**LSTM 递归编码时间测量历史**（因果依赖），组合成单一神经算子直接输出控制 `U_N(t)`。

### 关键技术细节
1. **对象系统**：一维反应扩散 PDE
   `u_t = u_xx + λ(x)u`，边界为 `u(0,t)=0, u(1,t)=U(t)`。
2. **经典反步设计**：
   - 控制核 `k[λ](x,y)` 满足双曲型核方程，控制律 `U(t) = ∫₀¹ k[λ](1,y) u(y,t) dy`。
   - 观测器核 `g[λ](x,y)` 满足相应方程，观测器通过输出注入修正状态估计。
3. **算子重定型**：
   - 观测器可写成抽象演化形式 `d/dt û = A_λ û + G_λ p`，其解 `û(t) = e^{A_λ t} û₀ + ∫₀ᵗ e^{A_λ(t-s)} G_λ p(s) ds`，显式表明 `U(t)` 依赖全部过去测量。
   - 定义算子 `T[λ, p_{[0,t]}](t) = ∫₀¹ k[λ](1,y) û_{λ,p}(y,t) dy`。
4. **理论性质**：
   - 命题1：算子单值性（给定 λ、p、固定观测器初值，U 唯一确定）。
   - 引理1：核函数对 λ 的 Lipschitz 依赖（利用 Volterra-Gronwall 估计）。
   - 引理2：观测器状态对 `(λ,p)` 的 Lipschitz 依赖（通过误差方程的连续依赖估计）。
   - 命题2：输出反馈算子是 Lipschitz 连续的，满足
     `‖T[λ₁,p₁] − T[λ₂,p₂]‖_{C([0,T])} ≤ C_T (‖λ₁−λ₂‖∞ + ‖p₁−p₂‖_{C([0,T])})`。
5. **DeepONet-LSTM 架构**：
   - 将 λ 在空间离散点上的值输入 DeepONet 分支网络，结合 trunk 网络得到系数编码 `z_λ`。
   - 在每个时间步将 `z_λ` 与当前测量 `p_j` 拼接，输入 LSTM 更新隐藏状态 `h_j`。
   - 通过输出网络 `Q_θ(h_j)` 生成边界控制 `U_N(t_j)`。
   - 理论保证（定理1）：由算子的连续性和通用逼近性质，存在足够大的网络使 `sup |T − T_N| < ε`。
6. **损失函数改进**：引入修改后的损失
   `L_mod = L_U + α L_ΔU + β L_amp`
   - `L_U`：标准 MSE 控制误差；
   - `L_ΔU`：惩罚相邻时刻控制输入的快速变化（时间正则性）；
   - `L_amp`：惩罚控制输入的大幅值。
7. **稳定性证明**：
   - 将神经近似误差视为目标热方程中的**非齐次 Dirichlet 边界扰动** `w(1,t) = ΔU(t)`。
   - 利用热核边界卷积估计（Dirichlet 热核 `G_D` 的导数界）证明：若 `|ΔU| ≤ ε`，则目标系统的 `L²` 范数满足
     `‖w(·,t)‖² ≤ C₁ e^{-α₀ t} ‖w(·,0)‖² + C₂ ε²`（引理3）。
   - 结合反步变换的等价性，证明闭环系统实际稳定（定理2）：
     `‖u(·,t)‖² ≤ M₁ e^{-α₁ t} ‖u(·,0)‖² + κ₁ ε²`。
