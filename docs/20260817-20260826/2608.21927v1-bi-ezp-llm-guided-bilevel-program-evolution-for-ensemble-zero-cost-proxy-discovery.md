## 摘要
零成本代理使得神经架构搜索（NAS）能够在初始化时根据统计信息对候选网络进行排名，从而避免重复训练。然而，不同的代理捕获不同的属性，并且在不同搜索空间中往往产生不一致的排名。集成代理可以组合互补信号，但自动发现必须同时优化离散的聚合结构及其连续系数，这使得结构质量难以与参数校准分离。我们提出Bi-EZP，一个解耦这些决策的双层框架。在上层，大语言模型在四个互补的基础代理上生成可执行的聚合程序，并带有特定于程序的参数边界。在下层，协方差矩阵自适应进化策略（CMA-ES）在内部训练划分上优化每个固定程序的连续参数。然后，在不相交的验证划分上使用Kendall秩相关对校准后的程序进行评估，使得进化选择能够偏好那些能泛化到其校准数据之外的结构。在NATS-Bench和网络设计空间上的实验评估了跨异构搜索空间的排名性能，DARTS实验评估了下游架构搜索。结果表明，将程序发现与数值校准分离为自动化集成零成本代理构建提供了一种有效方法。源代码可在以下网址获取：https://anonymous.4open.science/r/Bi-EZP-318D

## Abstract
Zero-cost proxies enable neural architecture search (NAS) to rank candidate networks from statistics computed at initialization, avoiding repeated training. However, different proxies capture different properties and often produce inconsistent rankings across search spaces. Ensemble proxies can combine complementary signals, but automated discovery must optimize both discrete aggregation structures and their continuous coefficients, making structural quality difficult to separate from parameter calibration. We propose Bi-EZP, a bilevel framework that decouples these decisions. At the upper level, a large language model generates executable aggregation programs over four complementary base proxies with program-specific parameter bounds. At the lower level, covariance matrix adaptation evolution strategy (CMA-ES) optimizes the continuous parameters of each fixed program on an inner training split. The calibrated programs are then evaluated using Kendall's rank correlation on a disjoint validation split, enabling evolutionary selection to favor structures that generalize beyond their calibration data. Experiments on NATS-Bench and Network Design Spaces evaluate ranking performance across heterogeneous search spaces, and DARTS experiments assess downstream architecture search. Results show that separating program discovery from numerical calibration provides an effective approach to automated ensemble zero-cost proxy construction. ## 一、论文的核心问题与整体含义

- **背景**：神经架构搜索（NAS）的核心瓶颈在于候选架构评估成本过高——训练每个候选网络极为昂贵，而权重共享等方法虽能降低成本，却可能扭曲相对质量。零成本代理（zero-cost proxies）通过初始化时的少量前向/反向传播统计量来估计架构质量，从而避免完整训练。
- **问题**：单个零成本代理只刻画网络的某一类属性（如激活模式、特征相关性、参数显著性、梯度一致性），在不同搜索空间上的排名往往不一致甚至互相冲突；而自动构建集成代理时，需要同时决定“离散的聚合结构”和“该结构对应的连续参数”。这两者耦合会使结构质量难以与参数校准效果区分：一个结构可能只是因初始系数侥幸而显得好，或一个优秀结构因参数未调好而被低估。
- **核心思想**：Bi-EZP 将上述问题建模为**双层优化**——上层用大语言模型（LLM）搜索可执行的符号聚合程序及其参数边界，下层用 CMA-ES 对每个固定程序做内部参数校准。通过“先校准、后比较”，使结构选择真正反映聚合规则本身的泛化能力，而非依赖任意初始系数。
- **整体含义**：该工作提出了“离散结构发现”与“连续参数校准”解耦的自动化代理构建范式，让 LLM 充当灵活的结构生成器，而非最终决策者，为 NAS 中可复用零成本代理的自动发现提供了一条新路径。

## 二、论文提出的方法论

### 1. 总体框架

- Bi-EZP 维护一个由 LLM 生成和变异的程序种群，每个候选表示为三元组：
  - `H`：启发式文本描述（rationale）；
  - `G`：可执行的 Python 聚合程序（计算图）；
  - `B`：程序参数的有界连续域，`B = ∏[L_k, U_k]`。
- 每个候选必须先经过**可执行代码校验门**（检查 AST 语法、函数签名、BOUNDS 字面量等），不合格时进行有限次 LLM 修正，仍失败则插入固定加权和形式的 fallback 程序，保证种群始终可评估。
- 上层（结构层）：LLM 通过初始化、语义交叉、定向变异生成新程序，种群使用锦标赛选择 + 精英 `(P+P)` 替换。
- 下层（参数层）：对每个接受的 `(G, B)`，CMA-ES 在内部训练集上优化连续参数，最大化训练集上的 Kendall 秩相关。
- 上层适应度：使用校准后的程序在内部验证集上的 Kendall 秩相关，该适应度不回流到 CMA-ES 的数值优化中。

### 2. 基础代理池

- 采用四个互补的零成本代理作为固定输入：
  - **NASWOT**：基于激活二值码多样性的表达力度量；
  - **MeCo**：基于特征相关矩阵最小特征值的收敛性/冗余度量；
  - **Sweet-SNIP**：结合 sweet-gradient 机制的参数显著性度量；
  - **SZiCo**：结合梯度一致性（ZiCo 思想）与 sweet 区间的梯度稳定性度量。
- 这四个代理分别从激活、特征、参数、梯度四个层面刻画未训练网络，且可通过一次前向和至多两次反向传播联合计算。

### 3. 双层优化目标（文字描述）

- **下层**：对于固定程序 `(G, B)`，在 `B` 内求解 `θ^*`，使内部训练集上代理分数与真实准确率的 Kendall τ 最大。
- **上层**：在合法候选空间中搜索 `(G, B)`，使校准后的 `θ^*(G,B)` 在内部验证集上的 Kendall τ 最大。
- 内层与外层使用不同的数据划分（80% 训练 / 20% 验证），避免验证信息泄漏到参数校准过程。

### 4. 关键算法要点

- **CMA-ES 初始化**：均值取参数边界几何中心，步长按边界范围尺度设置；采样后对越界向量做 clip；遇到 NaN/Inf 输出时施加大的惩罚值。
- **外层进化**：每代生成 P 个后代，父代选择采用规模为 3 的锦标赛；交叉概率 `P_c` 决定使用 LLM 交叉还是变异操作；交叉/变异提示只提供代码，不直接传递数值适应度；最后将父代与后代合并后截断为最优 P 个。
- **LLM 角色**：仅作为结构提议和变异算子，不直接输出数值参数；结构是否存活完全由外部执行、CMA-ES 校准和验证集适应度决定。

## 三、实验设计

### 1. 数据集与基准（Benchmark）

- **秩相关评估**：
  - NATS-Bench：包含拓扑搜索空间（TSS）和尺寸搜索空间（SSS），在 CIFAR-10、CIFAR-100、ImageNet-16-120 上评估。
  - NDS（Network Design Spaces）：涵盖 DARTS、ENAS、PNAS、NASNet、Amoeba 五个异构架构家族。
- **下游架构搜索**：DARTS 连续松弛搜索空间，在 CIFAR-10、CIFAR-100 和 ImageNet 上评估搜索效果。
- **采样规模**：NATS-Bench 随机采样 1000 个架构，NDS 采样 500 个，DARTS 空间采样 100 个。

### 2. 对比方法

- **单一代价代理**：ZiCo、Zen-Score、SWAP、GradNorm、SynFlow、ePADS、NASWOT、NI、GradSign、NTK、GraSP、SNIP、MeCo、MeCoopt 等。
- **集成/自动代理方法**：AZ-NAS、ParZC、ξ-GSNR、EZNAS-A、ECP、EvoREP 等。

### 3. 实验主要结果

- NATS-Bench 上 Bi-EZP 全面优于其他代理；相比 ECP，TSS 上 CIFAR-10 τ 从 0.782 提升至 0.809，CIFAR-100 从 0.771 到 0.791，ImageNet-16-120 从 0.740 到 0.775；SSS 上也有提升。
- NDS 五个家族上 Bi-EZP 均为最高，例如 DARTS 从 ECP 的 0.568 提升到 0.621，Amoeba 从 0.406 到 0.511。
- 跨数据集/跨搜索空间迁移实验中，冻结程序与参数后，对角线（同源同目标）平均高于非对角线，但差距较小（如 NATS-Bench 对角平均 0.792 vs 迁移平均 0.775），说明代理有一定可迁移性。
- 下游搜索：CIFAR-10 测试错误 2.47%（params 3.3M），CIFAR-100 16.10%，ImageNet Top-1 错误 24.7%（5.3M），搜索成本分别为 0.06 和 0.07 GPU-days（仅包含 DARTS 下游搜索阶段）。

## 六、论文的主要结论与发现

- **分离结构发现与参数校准是有效的**：显式地把符号聚合结构（上层）和连续参数（下层）分开，能让候选程序在“各自最佳参数”下进行比较，避免结构因初始系数偶然优势被误选。
- **LLM 生成 + CMA-ES 校准 + 验证集选择的组合是可行的**：在评估的搜索空间和数据集上，Bi-EZP 比 ECP、AZ-NAS、EZNAS-A 等取得更高的 Kendall 秩相关。
- **冻结程序具备一定的跨数据集/跨搜索空间可迁移性**：虽然匹配源通常最优，但非对角线迁移仍有较好表现；跨空间迁移在类似家族（DARTS/ENAS/PNAS）间较稳定，在 NASNet/Amoeba 等差异较大家族上性能下降。
- **下游架构搜索验证了代理的实际价值**：Bi-EZP 引导的 DARTS 搜索在 CIFAR-10/100、ImageNet 上取得了有竞争力的测试错误率，搜索阶段成本与传统零成本代理相当。
- 作者结论保守，强调结果仅限于所报告协议下，不能外推为全局最优或模型不变性。

## 七、优点

- **问题建模清晰**：将自动代理发现表述为双层优化，准确抓住了“结构 vs 参数”的耦合问题，思想新颖且具有一般性。
- **LLM 角色设计合理**：LLM 只负责提出可执行程序结构与参数边界，不做数值优化，避免 LLM 在连续优化上的不足；同时通过校验/修正/回退机制保证程序可执行性。
- **可执行代码搜索空间灵活**：不依赖预定义符号语法，算子、非线性变换和交互形式可由 LLM 自由生成，扩展了结构多样性。
