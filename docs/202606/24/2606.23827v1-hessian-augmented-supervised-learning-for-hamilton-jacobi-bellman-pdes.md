## 摘要
针对具有非线性控制仿射动力学的确定性最优控制问题，提出了一种数据驱动的方法来近似值函数。通过从多个初始条件求解Pontryagin最大值原理最优性系统，生成包含值函数的值、梯度和Hessian的训练数据，其中Hessian信息通过沿最优轨迹的矩阵Riccati方程获得。这些量增强了基于双曲交叉索引集上的稀疏多项式基的加权最小二乘回归，与仅基于值的回归相比，梯度和Hessian每个样本贡献额外的线性方程，从而显著降低了样本复杂度。反馈律从学习的值函数中解析恢复。在高维情况下，部分Hessian策略控制了数据生成的成本。该方法在状态维度递增的问题上进行了验证，结果表明二阶数据增强可以提高近似精度和闭环性能，与低阶方法相比，所需训练样本数量减少了一个数量级。

## Abstract
A data-driven method is developed for approximating value functions in deterministic optimal control problems with nonlinear control-affine dynamics. The Pontryagin Maximum Principle optimality system is solved from multiple initial conditions to generate training data consisting of values, gradients, and Hessians of the value function, where Hessian information is obtained from a matrix Riccati equation along optimal trajectories. These quantities augment a weighted least-squares regression over sparse polynomial bases on hyperbolic cross index sets, with gradients and Hessians contributing additional linear equations per sample and substantially reducing sample complexity compared to value-only regression. Feedback laws are recovered analytically from the learned value function. In high dimensions, a partial Hessian strategy controls the cost of data generation. The approach is validated on problems of increasing state dimension, where second-order data augmentation is shown to improve approximation accuracy and closed-loop performance, with up to an order-of-magnitude reduction in the number of training samples required relative to lower-order methods.

## 1. 核心问题与整体含义（研究动机与背景）
- **问题**：高维确定性最优控制问题中，Hamilton-Jacobi-Bellman (HJB) 方程的传统网格离散求解面临“维度灾难”；基于值函数的监督学习方法样本效率低，尤其在状态空间维度高时，仅依赖值函数数据需要大量样本来达到可接受精度。
- **背景**：Pontryagin 最大值原理 (PMP) 最优性系统与动态规划之间存在联系，可通过求解 PMP 获得值函数沿轨迹的值、梯度（由协态变量给出），而 Hessian 可通过沿最优轨迹反向积分矩阵 Riccati 方程获得。已有工作利用梯度增强回归（Sobolev 训练）提升样本效率，本文进一步引入 Hessian 数据，期望大幅降低样本复杂度，并提升闭环反馈性能。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：利用 PMP 生成增强数据集，包含每个样本点的值函数值、梯度向量和 Hessian 矩阵；将这些二阶信息整合到加权最小二乘回归中，为每个样本额外贡献 \(n + n(n+1)/2\) 个线性方程，从而显著降低达到给定精度所需的样本数。
- **关键技术细节**：
  - **数据生成**：对每个初始条件求解 PMP 两点边值问题（用 bvp5c 等求解器），获得最优轨迹和协态变量；然后沿该轨迹反向积分矩阵 Riccati 方程（2.9）得到 \(R(0)=\nabla^2 V(x)\)。当共轭点导致 Hessian 奇异时丢弃该样本。
  - **逼近模型**：采用稀疏多项式基，基函数为 Legendre 多项式的张量积，定义在双曲交叉索引集 \(I_{\text{HC}}(s)\) 上，并可额外添加低阶全次数集 \(I_{\text{TD}}(s_{td})\) 以增强低维耦合项。
  - **回归问题**：构造加权最小二乘目标（1.7），包含值、梯度、Hessian 三部分，权重分别为 1、\(\gamma_1\)、\(\gamma_2\)。正则化可加入 \(\ell_2\) 惩罚。设计矩阵 \(\bar{A}_{\gamma_1,\gamma_2}\) 大小为 \(M \times q\)，其中 \(M = N(1+n+n(n+1)/2)\)，\(q\) 为基函数个数。
  - **部分 Hessian 策略**：为控制高维时数据生成和回归系统规模，仅对 \(\rho \in (0,1]\) 的训练样本施加强制 Hessian 方程，其余样本仅使用值和梯度。
  - **反馈律恢复**：由近似值函数的梯度通过公式 \(u^*(x)=-\frac{1}{2\beta}g(x)^\top \nabla \tilde{V}(x)\) 解析计算。

## 6. 主要结论与发现
- **样本效率大幅提升**：在所有实验场景中，二阶回归所需的训练样本数远低于一阶和零阶。例如，2D Van der Pol 问题中，达到 1% 控制误差容限时，二阶仅需 80 个样本，零阶需要 277 个，一阶需要 109 个；19D Allen–Cahn 问题中，二阶在 N=200 时即达到 1% 的 L2 误差，一阶在同样 N 下误差仍大于 80%。
- **二阶信息在高维中成为结构必要性**：对于 n=19，一阶和零阶回归在中等 N 下系统严重欠定（M/q << 1），而二阶提供的 \(n(n+1)/2=190\) 个额外方程使系统很快达到过定，从而产生有意义近似；此时二阶不只是精度优势，而是唯一可行的途径。
- **部分 Hessian 策略有效**：\(\rho=0.3\) 的配置已显著优于纯一阶，在大多数指标上接近全二阶效果，且能大幅降低计算成本。
- **二阶回归允许使用更丰富的基**：由于方程多，二阶可以支持更大的基（如 q 达到 12406 在 n=19 时），从而获得更低的逼近误差。
- **误差特性**：H2 误差在所有方法中相对较大，但论文指出这主要是 Hessian 数据起到正则化作用，H2 误差并非最终控制性能的唯一决定因素。

## 7. 优点
- **方法新颖且机制清晰**：系统性拓展了 PMP 数据生成到二阶信息，并通过 Riccati 方程获得精确 Hessian，而非数值微分，保证了数据质量。
- **样本复杂度理论优势明确**：每个样本的方程数量随 n 二次增长，在维度上升时优势进一步放大，理论上超指数级受益。
