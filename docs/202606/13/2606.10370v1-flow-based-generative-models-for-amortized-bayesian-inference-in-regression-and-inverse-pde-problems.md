## 摘要
贝叶斯推断为科学机器学习中的不确定性量化提供了一个原则性的框架。然而，传统的贝叶斯方法通常需要为每个观测集解决一个新的推断问题，导致巨大的计算成本，阻碍了在线监测和数字孪生等实时应用。此外，在具有变化观测集的无限维函数空间上进行推断对于现有的摊销推断方法构成了重大挑战。在这项工作中，我们提出了Flow-ABI，一个基于流的生成框架，用于回归和逆偏微分方程（PDE）问题中的摊销贝叶斯推断。它由两个部分组成：（i）一个函数先验模型，通过流匹配从历史数据和物理知识中学习表达性先验；（ii）一个集合条件的函数后验采样器，将观测集映射到函数后验分布。学习到的后验模型自然地适应变化的、置换不变的观测集，并且能够泛化到不同的观测离散化。一旦训练完成，Flow-ABI能够对未见过的观测进行近实时后验采样，无需重新训练或迭代优化。所提出的方法可以无缝集成到广泛类别的科学机器学习框架中，包括物理信息神经网络和神经算子，用于不确定性的逆PDE建模。实验表明，Flow-ABI准确地捕获了高斯和非高斯后验分布，同时相对于黄金标准贝叶斯推断方法——哈密顿蒙特卡洛，实现了超过两个数量级的加速。这些结果表明Flow-ABI是科学机器学习中不确定性量化的一种有效、可扩展且计算高效的框架。

## Abstract
Bayesian inference provides a principled framework for uncertainty quantification in scientific machine learning. However, conventional Bayesian approaches usually require solving a new inference problem for each observation set, causing substantial computational costs that hinder real-time applications like online monitoring and digital twins. Furthermore, inferring over infinite-dimensional function spaces with varying observation sets poses major challenges for existing amortized inference methods. In this work, we propose Flow-ABI, a flow-based generative framework for amortized Bayesian inference in regression and inverse partial differential equation (PDE) problems. It consists of two components: (i) a functional prior model that learns expressive priors from historical data and physical knowledge through flow matching, and (ii) a set-conditioned functional posterior sampler mapping observation sets to functional posterior distributions. The learned posterior model naturally accommodates varying, permutation-invariant observation sets, and generalizes across different observation discretizations. Once trained, Flow-ABI enables near-real-time posterior sampling for previously unseen observations without retraining or iterative optimization. The proposed methodology can be seamlessly integrated with a wide class of scientific machine learning frameworks, including physics-informed neural networks and neural operators, for uncertainty-aware inverse PDE modeling. Experiments demonstrate that Flow-ABI accurately captures both Gaussian and non-Gaussian posterior distributions while achieving over two-order-of-magnitude speedups relative to the gold-standard Bayesian inference method, Hamiltonian Monte Carlo. These results show Flow-ABI is an effective, scalable, and computationally efficient framework for uncertainty quantification in scientific machine learning.

  - 观测数据通常以稀疏、含噪且空间位置可变的“集合”形式出现，需要后验推断算子对观测集的顺序和数量保持不变性。
  - 物理定律（PDE）对后验分布施加强约束，现有摊销推断方法难以直接处理。
- **整体意义**：提出一种名为 **Flow-ABI** 的基于流的生成框架，实现回归和逆 PDE 问题中的摊销贝叶斯推断，使得训练后可以在无需重新训练或迭代优化的情况下，对未见过的观测集进行近实时后验采样，为 UQ 的应用提供高效、可扩展的工具。

## 2. 方法论

### 核心思想
- 将贝叶斯推断分解为两个阶段：
  1. 从历史数据或物理知识中学习一个函数空间上的先验分布；
  2. 学习一个将观测集直接映射到后验分布的“集→分布”算子。
- 使用**流匹配（Flow Matching）** 技术，避免了归一化流中的可逆性和雅可比行列式计算约束，可高效地学习运输模型。
- 采用**函数编码器（Function Encoder, FE）** 将无限维函数映射到低维潜系数空间，实现函数空间的离散化表达。

### 关键技术细节

#### 功能先验模型（FPM）
- **函数编码器**：由系数网络 \(NN_C\) 和基网络 \(NN_B\) 组成。系数网络将每个函数实现（如离散点值）映射为潜系数向量 \(\psi \in \mathbb{R}^p\)；基网络输出空间坐标依赖的基函数 \(\phi(t,x)\)。通过低秩展开 \(\hat{u}(t,x) = \sum \psi_j \phi_j(t,x)\) 重建函数。
- **流匹配先验学习**：
  - 在潜空间构造概率路径：\(\xi_\tau = (1-\tau)\xi + \tau\psi\)，其中 \(\xi\sim\mathcal{N}(0,I)\)，\(\psi\) 来自数据集。
  - 训练向量场 \(v_{\theta_{\text{FPM}}}\) 预测目标场 \(\psi-\xi\)，损失函数为 \(L_{\text{FPM}} = \mathbb{E}\|v_{\theta_{\text{FPM}}}(\xi_\tau,\tau) - (\psi-\xi)\|^2\)。
  - 进一步**蒸馏为一步生成器**：训练学生网络 \(G_{\theta_s}\) 直接映射高斯噪声到潜系数，避免 ODE 积分，加速先验采样。

#### 集条件功能后验模型（SFPM）
- **条件流匹配**：给定观测集 \(D_{\text{obs}}\)，训练条件向量场 \(v_{\theta_{\text{SFPM}}}(\epsilon_\tau, \tau, D_{\text{obs}})\) 将基噪声 \(\epsilon\) 运输到后验潜变量 \(\xi\)。
- **条件处理**：
  - 每个观测 token 通过随机傅里叶特征（RFF）编码坐标，与观测值和类别指示器拼接，投影到模型维度。
  - 使用**交叉注意力**：以噪声潜变量 \(\epsilon_\tau\) 为 query，观测 token 为 key/value。
  - 采用**注意力掩码**处理变长观测集，使得模型满足置换不变性（permutation invariance）和离散化不变性。
- **训练损失**：\(L_{\text{SFPM}} = \mathbb{E}\|v_{\theta_{\text{SFPM}}}(\epsilon_\tau, \tau, D_{\text{obs}}) - (\xi-\epsilon)\|^2\)。
- **采样**：后验潜系数 \(\xi_{\text{post}} = \epsilon + \int_0^1 v_{\theta_{\text{SFPM}}}\,d\tau\)，再通过 \(G_{\theta_s}\) 和解码得到函数后验样本。

#### 与 PDE 系统的集成
- 当先验函数样本通过物理约束生成时，可使用自动微分（AD）计算源项、边界条件等；或利用预训练的神经算子（如 FNO）映射不同物理量间的关系，使得后验可以传播到其他未知场。

## 3. 实验设计

- **数据集/场景**：
  1. **1D 函数逼近**：三个子场景（a）高斯过程先验 + 高斯噪声；（b）非高斯先验（指数变换） + 高斯噪声；（c）Matérn 核 GP + 学生 t 分布噪声。
  2. **2D 函数逼近**：各向同性平方指数核 GP 先验，四个不同观测配置的测试案例。
  3. **非线性椭圆逆问题**：方程 \(-\partial_x^2 u + \sin(u) = kf\)，结合 PINNs 从稀疏观测同时推断 \(u\) 和 \(f\)，三个不同观测案例。
  4. **2D 达西流**：方程 \(-\nabla\cdot(K\nabla h)=1\)，由 FNO 作为代理模型，从稀疏的 \(K\) 和 \(h\) 观测推断对数电导率场 \(F=\log K\) 和压头 \(h\)，三个测试案例。

- **基准方法**：
  - 对于高斯先验+高斯噪声情况：**高斯过程回归（GPR）** 可提供精确后验，作为参考。
  - 对于非高斯情况：**哈密顿蒙特卡洛（HMC，具体为 No-U-Turn Sampler, NUTS）** 作为黄金标准参考。
  - 对比指标：后验均值和标准差（通过 10,000 个后验样本估计）、计算时间（wall-clock time）、特征值分解（先验协方差）、置换不变性误差（MAE）。

- **对比结果**：
  - Flow-ABI 的后验均值和不确定性与 GPR 或 HMC 高度一致。
  - 计算速度：在非线性椭圆问题中，Flow-ABI 比单链 HMC 快约 199 倍，比四链 HMC 快约 112 倍；在 2D 达西流中，比单链 HMC 快约 1039 倍，比四链 HMC 快约 393 倍。

  - 主动学习实验成功展示了逐步降低不确定性的能力。
