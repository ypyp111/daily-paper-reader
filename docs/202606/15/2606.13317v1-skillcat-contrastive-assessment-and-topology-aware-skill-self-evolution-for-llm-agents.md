## 摘要
面向LLM智能体的技能自我进化方法旨在将执行轨迹转化为可重用的技能文档，但当前流程通常每个任务仅从一条轨迹学习，在检查候选技能补丁前进行合并，并在推理前加载完整技能库。我们提出SkillCAT，一种无需训练的框架，将该过程分为三个阶段。对比因果提取（CCE）为每个任务采样多条轨迹，并比较同任务的成功/失败对，以识别解释结果差异的证据。评估增强进化（AAE）在源任务克隆上回放每个候选补丁，并在层次化技能补丁合并前仅保留改善或保持任务结果的补丁。拓扑感知任务执行（TTE）将进化后的技能编译成可路由的子技能拓扑，因此推理仅加载与任务相关的能力节点。我们在常见智能体基准上评估SkillCAT，包括SpreadsheetBench、WikiTableQuestions和DocVQA，并进一步测试跨模型和分布外泛化。在这些设置下，SkillCAT将平均得分比基线提升高达40.40%，展示了无需模型训练的可靠技能进化。

## Abstract
Skill self-evolution methods for LLM agents aim to turn execution trajectories into reusable skill documents, but current pipelines typically learn from one trajectory per task, merge candidate skill patches before checking them, and load the full skill corpus before inference. We propose SkillCAT, a training-free framework that separates this process into three stages. Contrastive Causal Extraction (CCE) samples multiple trajectories for each task and compares same-task success/failure pairs to identify evidence that explains outcome differences. Assessment-Augmented Evolution (AAE) replays each candidate patch on source-task clones and keeps only patches that improve or preserve task outcomes before hierarchical skill patch merging. Topology-Aware Task Execution (TTE) compiles the evolved skills into a routable sub-skill topology, so inference loads only the capability nodes relevant to the task. We evaluate SkillCAT on common agent benchmarks, including SpreadsheetBench, WikiTableQuestions, and DocVQA, and further test cross-model and out-of-distribution generalization. Across these settings, SkillCAT raises the average score over baselines by up to 40.40%, demonstrating reliable skill evolution without model training.

## 1. 论文的核心问题与整体含义（研究动机和背景）

LLM 智能体在执行任务时通常依赖外部技能文档（如结构化指令、工具使用规则、任务经验等），现有技能自我进化方法（如 Trace2Skill）虽然能通过离线批量处理从轨迹中提取技能补丁并合并，但存在三个关键问题：
- **单轨迹偏差（Single-Trace Bias）**：每个任务仅从一条轨迹学习，成功或失败的偶然性导致证据弱，无法定位根因；
- **未验证合并（Unvalidated Merging）**：补丁在合并前未经独立验证，低质量或有害补丁可能进入技能库，损害性能；
- **上下文过载（Context Overload）**：合并后的技能不断增长，推理时加载全部技能导致提示长度过长、无关规则干扰规划。

因此，论文旨在设计一种无需模型训练的框架，系统性地解决上述问题，实现可靠的技能自我进化。

## 2. 论文提出的方法论

### 核心思想
SkillCAT 将技能生命周期解耦为三个独立阶段，分别处理证据提取、补丁验证与合并、推理时上下文选择。

### 关键技术细节

#### (1) 对比因果提取 (Contrastive Causal Extraction, CCE)
- 对每个任务通过多种子采样（论文使用 5 个种子）生成多条轨迹；
- 构造同任务的成功/失败对比对（成功轨迹 τ⁺ 和失败轨迹 τ⁻）；
- 定位因果分水岭 wᵢ（第一个动作序列不同的步骤），提取该点附近的局部证据、失败原因和可编辑教训作为候选体验记录 rᵢ；
- 当所有轨迹全成功或全失败时，启用单轨迹提取器作为回退机制。

#### (2) 评估增强进化 (Assessment-Augmented Evolution, AAE)
- 将每个候选补丁视为假设，先在源任务克隆上回放，记录基线结果 yⱼ 和回放结果 ŷⱼ；
- 根据结果转移打分（4 个等级）：失败→成功 3.0，成功→成功 2.0，失败→失败 1.0，成功→失败 0.0；
- 仅保留得分 ≥ 阈值 θ（设为 2.0）的补丁，排除破坏已成功行为的补丁；
- 按得分层级从低分到高分依次合并（层次化合并），最终输出进化后的技能 S*。

#### (3) 拓扑感知任务执行 (Topology-Aware Task Execution, TTE)
- 离线将 S* 解析为路由拓扑：一级内容为核心技能 S◦，二级章节为可路由节点集合 V；
- 构建拓扑摘要 Σ（包含标题、关键词、摘要、依赖关系）；
- 推理时，LLM 路由器 ρ 根据任务描述从 Σ 中选择 ≤ k 个相关节点，经确定性扩展（依赖边、锚点等）后，将对应节点内容与核心技能拼接成精简的路由技能 S_c。

### 算法流程概述（文字描述）
1. **CCE 阶段**：对每个进化任务，用多个种子运行智能体，收集轨迹。若存在混合结果，构造对比对，提取因果分水岭附近的证据；否则启用回退。将证据转换为候选补丁。
2. **AAE 阶段**：对每个候选补丁，在源任务克隆上回放，根据结果转移打分，保留高分补丁；按得分层级合并到最终技能 S*。
3. **TTE 阶段**：离线构建拓扑；在线对每个测试任务，用路由器选择节点，组装精简技能，再执行智能体。

1. **整体性能**：SkillCAT 在 SpreadsheetBench 上平均得分比 Trace2Skill + Combined 基线提升高达 40.40%（Qwen3.5-35B-A3B Skill Deepening 场景）。
2. **模块有效性**：三个模块均贡献显著。去除 CCE 后 Vrf 从 55.50% 降至 32.50%；去除 AAE 后降至 26.00%（低于基线）；去除 TTE 后降至 46.50%。
3. **跨模型与分布外泛化**：用 Qwen 作者技能测试 gemma 和 gpt 用户，且 OOD 的 WikiTQ 上 SkillCAT 最高达 84.47%。
4. **多模态适用性**：DocVQA 上 SkillCAT 全管道最佳（ANLS 0.9159），而 Trace2Skill +Error 反而低于无技能基线，说明未验证合并的危险性。
5. **CCE 种子数**：5 个种子是最优折中（55.50% Vrf），更多种子带来噪声且采样成本剧增。
6. **AAE 分数校准**：回放结果转移与下游性能单调相关，失败→成功最佳，成功→失败应拒绝。
7. **TTE 上下文压缩**：LLM 图路由器在 top_k=7 时实现 55.50% Vrf 且上下文减少 41.6%。

## 8. 不足与局限

- **计算开销仍在**：CCE 需对每个进化任务运行多次轨迹（5 种子），采样时间随任务数线性增长，未报告大规模任务时的总耗时。
- **回放依赖源任务克隆**：AAE 需要在克隆环境上执行，对于无法轻易克隆的环境（如实时 API、物理环境）适用性受限。
- **对比构造依赖混合结果**：若任务所有种子全成功或全失败，只能回退到单轨迹提取，效果可能下降。
- **路由器的 LLM 调用成本**：TTE 的图路由器仍需一次 LLM 调用进行选择，对极小任务可能不划算。
- **泛化范围有限**：仅测试了电子表格、表格、文档问答，未涉及更通用的 Agent 任务（如网页导航、编程、交互式对话）。

- **种子数扫掠的泛化性**：5 种子在 SpreadsheetBench 上最优，但在其他任务上是否适用未知。
