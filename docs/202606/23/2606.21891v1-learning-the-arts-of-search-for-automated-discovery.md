## 摘要
科学发现可以表述为在假设和实验空间上的迭代搜索过程。当代方法使用诸如MCTS等启发式方法导航该空间。这些算法将假设的价值与其实验执行的质量混为一谈。因此，一个有前景但初步执行的假设排名低于一个执行精炼但平庸的假设。此外，随着搜索的进行，先前方法会剪枝搜索日志，因为累积的历史超出了上下文窗口。我们提出了树搜索的代理推理（ARTS），其中我们部署一个推理语言模型来导航该空间。该模型检查先前的执行日志，诊断早期失败是由于错误实现还是糟糕假设，并选择接下来要构建的假设。为了缓解上下文长度带来的挑战，ARTS使用测试时训练将搜索树的知识注入模型权重。在来自MLGym和MLEBench的22个任务上，我们表明ARTS优于领先算法，归一化分数相对提升超过15.3%。通过测试时训练，我们表明Qwen3-4B代理可以匹配如Gemini-3 Pro和GPT o3推理等闭源前沿模型的性能，同时推理成本降低高达5倍。我们进一步观察到，在部分可观测的强化学习任务上，经过测试时训练的Qwen3-4B科学家通过重新发现启发式方法剪枝掉的人类最佳循环记忆解决方案，超越了使用o3科学家的ARTS。

## Abstract
Scientific discovery can be formulated as an iterative search process over the space of hypotheses and experiments. Contemporary methods navigate this space using heuristics such as MCTS. These algorithms conflate the merit of a hypothesis with the quality of its experimental execution. A promising hypothesis with preliminary execution is therefore ranked below a modest hypothesis whose execution is refined. Moreover, prior methods prune the search logs as the search progresses because the accumulated history outgrows the context window. We propose Agentic Reasoning for Tree Search (ARTS), where we deploy a reasoning language model to navigate this space. The model inspects prior execution logs, diagnoses whether earlier failures arose from faulty implementations or bad hypotheses, and selects the hypothesis to build on next. To mitigate challenges with context length, ARTS uses test-time training to instill the knowledge of search tree in the model weights. Across 22 tasks from MLGym and MLEBench, we show that ARTS outperforms leading algorithms, with over 15.3% relative improvement in the normalized score. With test-time training we show that a Qwen3-4B agent can match performance with closed-source frontier models like Gemini-3 Pro and GPT o3-reasoning with upto 5x lower inference cost. We further observe that on partially observable RL tasks, the test-time trained Qwen3-4B scientist surpasses ARTS with the o3 scientist by rediscovering the human-best recurrent-memory solution that heuristic methods prune away.

### 论文核心问题与整体含义（研究动机和背景）

论文聚焦于 **自动化科学发现** 这一前沿领域。其核心问题在于，当前将科学发现建模为假设-实验迭代搜索过程的主流方法存在两大严重缺陷：

1.  **假设价值与执行质量混淆**：现有的树搜索（如MCTS）和进化搜索算法，通常基于分数启发式（如UCT）来选择哪个假设（节点）值得进一步探索。这会导致一个逻辑正确、有前景但实现初级的假设（如代码Bug、欠训练），其分数低于一个经过精细调优但本质平庸的假设。算法会因此错误地放弃前者，陷入局部最优。
2.  **搜索历史上下文溢出**：随着搜索的深入，累积的实验代码、日志结果会迅速超出大语言模型（LLM）的上下文窗口限制。现有方法要么被迫进行信息丢失的文本摘要或剪枝，要么在超长上下文中性能急剧下降，导致无法有效利用早期的探索经验。

论文的整体目标是提出一种新的搜索范式，能够智能地分离“假设的质量”和“实现的质量”，并优雅地处理长上下文问题，从而显著提升自动化科学发现引擎的效率和最终性能。

### 论文提出的方法论：核心思想、关键技术细节

该方法名为 **ARTS (Agentic Reasoning for Tree Search)**，其核心是 **用推理语言模型（LRM）驱动搜索过程**，而不是依赖盲目的分数启发式。

**核心思想**：将搜索过程分解为“科学家”和“执行者”两个角色，并让“科学家”通过推理来指导搜索方向。

**关键技术细节：**

1.  **科学家和执行者解耦**：
    *   **科学家 (Scientist)**：一个强大的推理模型（如OpenAI o3），负责分析历史实验、诊断失败原因、选择下一个要探索的节点和假设。它具备多步推理能力。
    *   **执行者 (Executor)**：一个高效的编码模型（如Gemini 3 Flash），负责根据科学家的指令编写代码并执行实验。这种分工解耦了“想”和“做”的能力。

2.  **科学家驱动的搜索流程**：
    *   **节点检查**：科学家可以“检查”（`INSPECT`）树上任意节点的日志、代码和训练曲线。这使其能够区分“**假设本身错误**”（IDEA-WRONG）和“**实现错误**”（IMPLEMENTATION-WRONG）。
    *   **基线审计**：搜索初期，科学家的前几轮调用被保留为“审计”（AUDIT），只允许其阅读数据和基线代码，以理解任务的结构化偏差和潜在瓶颈。
    *   **言语化采样**：为防止多样性崩溃，科学家被要求列出 `K` 个候选假设，并赋予每个假设一个概率。系统根据这些概率进行随机采样，而不是总是选择概率最高的那个。
    *   **持久化记忆**：随着搜索树扩大，科学家维护一个外部“记忆模块”。每次扩展后写入一条简短洞察，帮助科学家在后续步骤中快速回顾关键信息。

3.  **ARTS\*：测试时训练应对上下文溢出**：
    *   当搜索树非常大时，即使有记忆模块，整个上下文仍然可能超出模型限制。
    *   论文提出 **ARTS\***，这是一种 **测试时训练（Test-Time Training, TTT）** 机制。它使用 **GRPO** 算法对科学家模型（如Qwen3-4B）进行微调。
    *   **算法流程**：从当前搜索树状态 `Gt` 出发，科学家采样 `N`个动作 `(父节点，假设)`。每个动作被执行后得到奖励，奖励函数基于新节点的分数在历史分数中的百分位（如超过70%则奖励+1）。GRPO利用这批动作的奖励来更新模型的LoRA适配器。这样，搜索树的知识被“内化”到模型权重中，有效缓解了对超长上下文的依赖。

**算法流程**：
*   **ARTS**: 科学家审计->循环（检查日志->选择父节点和假设->言语化采样->执行者实现并运行->将新节点加入搜索树）。
*   **ARTS\***: 在ARTS基础上，增加一个GRPO训练内循环：批量采样动作 -> 执行并获取奖励 -> 用GRPO更新科学家模型的LoRA权重。
